# 미분못하는점수

*Evolution Strategies*

> 진화 전략 Evolution Strategies, 미분할 식이 없는 게임 점수로 AI가 어떻게 오르막을 찾는지 막대 세우기 게임으로 직접 돌려 봤어요

## 영상 내용

- 막대 세우기(CartPole) 게임: AI가 수레를 좌우로 밀고, 막대가 버틴 시간(최대 10초)이 점수예요. 지도학습은 오차 식을 미분하면 갈 방향이 나오지만, 여기선 가중치를 넣으면 게임이 점수만 돌려주는 블랙박스예요
- 그럼 직접 해 보면 돼요. AI의 가중치 θ를 오른쪽으로 살짝(+0.3) 바꾸니 4.4초, 왼쪽으로 살짝 바꾸니 2.1초. 오른쪽이 오르막이에요
- 식으로 쓰면 기울기 ≈ (R(θ+ε) − R(θ−ε)) ÷ 2ε. "+로 해 본 점수 − −로 해 본 점수"를 흔든 거리로 나눈 값이에요. (4.4 − 2.1) ÷ (2 × 0.3) ≈ 3.8
- 가중치가 여러 개면 갈 방향이 끝없이 많아서, 주변을 20번 한꺼번에 흔들어 점수가 오른 방향은 더하고 내린 방향은 빼 평균 방향으로 한 걸음 가요. 가중치 2개 지도에서 4걸음에 1.1초 → 10초 (끝까지 버팀)
- 2017년 OpenAI 논문은 이 방법으로 3D 사람 모형 걷기를 배웠어요. 18코어로 약 11시간(657분), 1,440코어(컴퓨터 80대)로 나눠 돌리니 10분. 일꾼끼리 점수 하나씩만 주고받으면 되기 때문이에요
- 여기서 쓴 건 GPU가 아니라 CPU예요. 신경망은 층 2개 · 64칸짜리로 작아서 GPU가 할 일이 적고, 게임 한 판은 CPU에서 도는 물리 계산(MuJoCo)이라 코어마다 한 판씩 맡겼어요. 요즘은 Brax · Isaac Gym처럼 게임까지 GPU에 올려 수천 판을 한꺼번에 돌려요
- REINFORCE나 PPO 같은 정책 경사 방법도 비슷한 생각이에요. 가중치 대신 행동을 흔들어 보고, 평균보다 점수가 높았던 행동을 더 자주 하게 바꿔요

**참고**: 게임은 Gym CartPole과 같은 물리식을 numpy로 직접 돌린 값이에요. AI = 선형 정책 (수레 쪽 가중치 2개는 0.5로 고정, 막대 쪽 2개만 학습), 점수 = 고정한 시작 5판 평균, 흔들기 = 거울 쌍 10쌍 (σ 0.4, 학습률 0.6). 출처: Salimans et al., 2017, "Evolution Strategies as a Scalable Alternative to Reinforcement Learning" (arXiv:1703.03864) 4.1절 그림 1. 이모지: Twemoji (CC BY 4.0) · 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 게임: 막대 세우기 (CartPole) — src/sim.py 에서 numpy 로 직접 (OpenAI Gym CartPole-v1 과 같은 물리식, Barto, Sutton & Anderson 1983: 힘 10 N, 0.02초 간격, 막대 12도 · 수레 ±2.4 m 에서 끝, 최대 500칸 = 10초).
  - AI = 선형 정책: w · (수레 위치, 수레 속도, 막대 기울기, 기울기 속도) > 0 이면 오른쪽. 수레 쪽 2개는 0.5 고정, 막대 쪽 2개 (w1, w2) 만 움직임 (화면 아래 작은 글씨로 표시).
  - 점수 = 버틴 시간 (초), 고정한 무작위 시작 5개 (시드 0, ±0.05) 의 평균.
  - 1차원 (표지 · s3 · s4): w2 = 0.8 단면. θ = 0.4, ε = 0.3 → 4.4초 vs 2.1초 → (4.4 − 2.1) ÷ 0.6 ≈ 3.8.
  - 2차원 (s5 · s6): es_run() 직접 실행 (거울 쌍 10쌍 = 흔든 점 20개, σ 0.4, 학습률 0.6, 시드 2, 출발 (−1, 0.8)) → 걸음마다 1.1 · 2.6 · 3.5 · 5.5 · 10.0초. 지도 그림 = 240 × 240 격자 실제 점수 (make_figs.py).
  - s2 한 판 = 출발 가중치 · 시작 4번째 (54칸 = 1.08초), s6 한 판 = 마지막 가중치 (3.1, 2.2) · 시작 1번째 (500칸 = 10초, 2초에 빨리 재생).
- s7b: 정책 신경망 = '64-unit hidden layers' 2개 (논문 4.2절 MuJoCo), 환경 = MuJoCo 물리 시뮬레이터, 코어 칸의 점수 숫자는 장식용 예시. GPU 시뮬레이터 예: Brax (Google, 2021) · Isaac Gym (NVIDIA, 2021) — 게임 수천 판을 GPU 하나에서 동시에.
- s8 행동 점수 40 · 55 · 70 과 확률 33 · 34 · 33% → 24 · 31 · 45% 는 예시 (화면에 '예시').
- 논문: Salimans, Ho, Chen, Sidor, Sutskever (OpenAI), 2017, "Evolution Strategies as a Scalable Alternative to Reinforcement Learning", arXiv:1703.03864 v2.
  - 4.1절 · 그림 1: 3D Humanoid 점수 6000 도달 시간 중앙값 (7번 반복). 18 cores 657분 ('about 11 hours'), 80대 · 1,440 CPU cores 10분.
  - 2.1절: 일꾼끼리 주고받는 것은 점수 (scalars) 뿐. 2.2절: 거울 쌍 (antithetic / mirrored sampling) 사용.
  - 3절: 정책 경사는 행동 공간에, ES 는 파라미터 공간에 잡음을 넣는다 ('Policy gradient methods add the noise in action space … Evolution strategies, on the other hand, add the noise in parameter space').
- 이모지: Twemoji (CC BY 4.0) — 🎮 🚶
