# 미분못하는점수

*Evolution Strategies*

> 진화 전략 Evolution Strategies, 미분할 식이 없는 게임 점수로 AI가 어떻게 오르막을 찾는지 지렁이 게임으로 직접 돌려 봤어요

## 영상 내용

- 지렁이 게임: 먹은 사과 수가 점수예요. AI의 가중치는 2개, 사과 쪽으로 가려는 정도(w1)와 곧장 가려는 정도(w2)예요. 지도학습은 오차 식을 미분하면 갈 방향이 나오지만, 여기선 가중치를 넣으면 게임이 점수만 돌려주는 블랙박스예요
- 그럼 직접 해 보면 돼요. AI의 가중치 θ를 오른쪽으로 살짝(+0.25) 바꾸니 사과 8.1개, 왼쪽으로 살짝 바꾸니 5.8개. 오른쪽이 오르막이에요
- 식으로 쓰면 기울기 ≈ (R(θ+ε) − R(θ−ε)) ÷ 2ε. "+로 해 본 점수 − −로 해 본 점수"를 흔든 거리로 나눈 값이에요. (8.1 − 5.8) ÷ (2 × 0.25) ≈ 4.6
- 가중치가 여러 개면 갈 방향이 끝없이 많아서, 주변을 20번 한꺼번에 흔들어 점수가 오른 방향은 더하고 내린 방향은 빼 평균 방향으로 한 걸음 가요. 실제 점수 지도는 울퉁불퉁하지만 흔든 점수의 평균 J는 매끈한 산이 돼요. 가중치 2개 지도에서 4걸음에 사과 1.4개 → 17.1개
- 2017년 OpenAI 논문은 이 방법으로 3D 사람 모형 걷기를 배웠어요. 18코어로 약 11시간(657분), 1,440코어(컴퓨터 80대)로 나눠 돌리니 10분. 일꾼끼리 점수 하나씩만 주고받으면 되기 때문이에요
- 여기서 쓴 건 GPU가 아니라 CPU예요. 신경망은 층 2개 · 64칸짜리로 작아서 GPU가 할 일이 적고, 게임 한 판은 CPU에서 도는 물리 계산(MuJoCo)이라 코어마다 한 판씩 맡겼어요. 요즘은 Brax · Isaac Gym처럼 게임까지 GPU에 올려 수천 판을 한꺼번에 돌려요
- REINFORCE나 PPO 같은 정책 경사 방법도 비슷한 생각이에요. 가중치 대신 행동을 흔들어 보고, 평균보다 점수가 높았던 행동을 더 자주 하게 바꿔요

**참고**: 지렁이 게임(10×10)은 직접 만들어 돌린 값이에요. AI = 가중치 2개 확률 정책 (사과 쪽으로 · 직진, 부딪히는 칸은 −6 고정), 점수 = 정해 둔 16판 평균, 흔들기 = 거울 쌍 10쌍 (σ 0.5, 학습률 0.1). J 지도 = 실제 점수 지도를 σ 0.5 가우시안으로 흐리게 한 것. 출처: Salimans et al., 2017, "Evolution Strategies as a Scalable Alternative to Reinforcement Learning" (arXiv:1703.03864) 4.1절 그림 1. 이모지: Twemoji (CC BY 4.0) · 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 게임: 지렁이 게임 — src/snake_es.py 직접 (10×10 격자, 길이 3 시작, 벽 · 몸에 부딪히면 끝, 사과 없이 200칸 가면 끝).
  - AI = 가중치 2개 확률 정책: 직진 · 왼쪽 · 오른쪽 칸마다 w1 · (사과에 가까워지면 +1, 아니면 −1) + w2 · (직진이면 1) − 6 · (부딪히는 칸) → softmax 로 고름 (화면 아래 작은 글씨로 −6 고정 표시).
  - 점수 R = 먹은 사과 수, 정해 둔 난수 16판 (시드 0~15) 평균 → 같은 가중치면 같은 점수.
  - 1차원 (표지 · s3 · s4): w2 = −1 단면 (가로 w1 −1.5~5, 0.125 간격). θ = 0.5, ε = 0.25 → 8.1개 vs 5.8개 → (8.1 − 5.8) ÷ 0.5 ≈ 4.6.
  - 2차원 (s5 · s6): 지도 R = 105 × 105 격자 실제 점수 (w1 −1.5~5, w2 −3~3.5), J = R 을 σ 0.5 가우시안으로 흐리게 (= 흔든 점수의 평균, 논문 3절 'Gaussian blur'). 색은 높은 곳 대비를 키운 PowerNorm (R 1.6 · J 2.5), J 에 사과 2개마다 등고선 (make_figs.py).
  - es_run() 직접 실행 (거울 쌍 10쌍 = 흔든 점 20개, σ 0.5, 학습률 0.1, 시드 1, 출발 (0, −1)) → 걸음마다 사과 1.4 · 6.3 · 13.7 · 16.0 · 17.1개, 끝 가중치 (1.62, −0.34).
  - s2 한 판 = 출발 가중치 · 4번째 판 (사과 2개, 위 벽에 부딪힘), s6 한 판 = 끝 가중치 · 12번째 판 (사과 28개, 2.4초에 빨리 재생).
- s7b: 정책 신경망 = '64-unit hidden layers' 2개 (논문 4.2절 MuJoCo), 환경 = MuJoCo 물리 시뮬레이터, 코어 칸의 점수 숫자는 장식용 예시. GPU 시뮬레이터 예: Brax (Google, 2021) · Isaac Gym (NVIDIA, 2021) — 게임 수천 판을 GPU 하나에서 동시에.
- s8 행동 점수 40 · 55 · 70 과 확률 33 · 34 · 33% → 24 · 31 · 45% 는 예시 (화면에 '예시').
- 논문: Salimans, Ho, Chen, Sidor, Sutskever (OpenAI), 2017, "Evolution Strategies as a Scalable Alternative to Reinforcement Learning", arXiv:1703.03864 v2.
  - 4.1절 · 그림 1: 3D Humanoid 점수 6000 도달 시간 중앙값 (7번 반복). 18 cores 657분 ('about 11 hours'), 80대 · 1,440 CPU cores 10분.
  - 2.1절: 일꾼끼리 주고받는 것은 점수 (scalars) 뿐. 2.2절: 거울 쌍 (antithetic / mirrored sampling) 사용.
  - 3절: 정책 경사는 행동 공간에, ES 는 파라미터 공간에 잡음을 넣는다 ('Policy gradient methods add the noise in action space … Evolution strategies, on the other hand, add the noise in parameter space').
