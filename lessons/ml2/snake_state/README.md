# AI가보는것

*State*

> 상태 State, 강화학습 AI가 행동을 고를 때 보는 정보. 상태에 없는 건 아무리 연습해도 배울 수 없어요

## 영상 내용

- 지렁이 게임 AI가 사과를 24개 먹은 뒤, 제 몸으로 둘러싸인 닫힌 방에 스스로 들어가 버렸어요
- 그 방의 빈칸은 18칸, 몸은 27칸이에요. 들어가는 순간 이미 빠져나올 수 없는 판이에요
- 이 AI가 보는 건 다섯 가지뿐이에요. 앞 · 위 · 아래 칸이 막혔는지, 그리고 사과가 어느 쪽인지. 앞은 막혔고 사과는 아래쪽이라 아래로 꺾었어요. 그 아래가 닫힌 방이라는 건 다섯 가지 어디에도 없어요
- 강화학습에서 AI가 보고 고르는 이 정보를 상태(State)라고 해요. 상태에 없는 건 5000판을 연습해도 배울 수 없어요
- 상태에 '그쪽으로 가면 갇히는지' 세 가지를 더했더니, 같은 순간에 이번엔 위로 빠져나가 그 판에서 사과를 43개까지 먹었어요
- 따로 다섯 번 학습시켜 시험 1000판을 평균 내면 사과가 19.5개에서 33.1개로 늘었어요

**참고**: 직접 만든 실험: 10×10 격자, 길이 3에서 시작, 사과 +10점 · 부딪히면 −10점, Q-러닝 5000판 학습, 시험은 탐색 없이 학습마다 200판. '갇히나' = 그쪽으로 갔을 때 닿을 수 있는 빈칸이 몸 길이보다 적은지. 상태를 늘려도 결국 제 몸에 부딪혀 끝나는 판이 대부분이라 완벽해지진 않아요. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작) · 이모지: Twemoji (CC BY 4.0)

## 출처

- 슬라이드 없음 (쇼츠 전용, ML2 3주 MDP '상태').
- 실험: 직접 (src/snake.py · sim.py · make_frames.py, 수 분). 10×10 지렁이 게임, 길이 3 시작, 사과 +10 · 부딪히면 −10, 표 Q-러닝 (α 0.1, γ 0.95, ε 0.5 → 0 을 3000판에 걸쳐), 5000판 학습, 시험은 탐색 없이 200판 (rng 100).
  - 상태 A (5개): 앞 · 왼 · 오른 칸이 막혔나 + 사과 앞/뒤 · 왼/오른 → 시드 0~4 평균 사과 19.5개, 죽음의 94% 가 제 몸.
  - 상태 B (8개): A + 앞 · 왼 · 오른으로 가면 닿는 빈칸 < 몸 길이 (꼬리 끝은 비킨다고 봄) → 평균 33.1개.
  - 보여 준 판: A 시드 0, 시험 11번째 판. 228걸음째 (사과 24개, 몸 27칸) 앞 막힘, 아래로 꺾으면 빈칸 18칸 방 → 241걸음에 죽음. B 는 같은 228걸음 장면에서 이어 둠 (사과 위치 rng 7) → 위로 빠져 사과 43개.
  - 화면의 '위 · 아래' = 오른쪽으로 가던 중이라 AI 기준 왼쪽 · 오른쪽.
