# MCTS틱택토

*Monte Carlo Tree Search*

> 몬테카를로 트리 탐색 MCTS, 틱택토에서 꼭 이기는 칸 하나를 AI가 어떻게 찾는지 직접 돌려 봤어요

## 영상 내용

- 틱택토는 끝까지 가는 판이 255,168가지라 다 따질 수 있지만, 바둑은 10의 170제곱 가지라 다 못 따져요. 그래서 AI는 머릿속으로 둬 보고 정해요
- 가장 쉬운 방법(몬테카를로): 칸마다 남은 수를 아무렇게나 끝까지 1,000판씩 둬 봐요. 이긴 비율 1등은 가운데 66%, 구석은 60%
- 그런데 끝까지 다 따져 보면 꼭 이기는 칸은 왼쪽 위 구석이에요. 상대가 오른쪽 위를 막으면 가운데에 둬서 이길 줄이 두 개가 돼요. 가운데는 상대가 잘 막으면 비기는 수예요
- 아무렇게나 두면 내 다음 수도 아무렇게나라서 이런 작전을 못 봐요
- MCTS는 둬 본 수를 나무로 기억하면서 고르기 → 새 수 붙이기 → 끝까지 둬 보기 → 결과 올려 적기를 반복해요. 고를 땐 이긴 비율에 덜 둬 본 수 가산점(1.4 × √(ln N ÷ n))을 더해요. 실제 16번째 반복에선 한 번 둬서 졌던 구석이 가산점 덕에 다시 골라졌어요
- 3,000번 반복하니 2,298번을 구석에 썼고, 구석의 이긴 비율은 87%가 됐어요. 아무렇게나 7,000판보다 적게 두고 이기는 수를 찾았어요
- 알파고도 이 나무 탐색으로 바둑을 둬요. 정책망이 둘 만한 수를 추려 주고, 가치망이 승률을 바로 내다봐요

**참고**: 틱택토는 직접 만들어 돌린 값이에요. 판 = X 위 가운데 · O 왼쪽 아래, X 차례. 이긴 비율 = X가 이긴 판 비율(비기면 0). 아무렇게나 1,000판씩은 시드 20개 중 18개에서 가운데가 1등, MCTS(UCT, c 1.4) 3,000번은 시드 20개 모두 구석을 골랐어요. 바둑판 그림은 예시예요. 출처: Silver 외 (2016) Nature 529 · DeepMind AlphaGo 공개 글. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 게임: 틱택토 — src/ttt.py 직접 (minimax · 아무렇게나 끝까지 두기 · UCT MCTS). 숫자는 모두 src/data.py 에서 assert.
  - 판 '.X....O..' (X 위 가운데, O 왼쪽 아래), X 차례, 빈칸 7개. 끝까지 다 따지면 (minimax) 왼쪽 위 구석만 꼭 이김, 가운데 · 오른쪽 아래는 비김, 나머지는 짐.
  - 이기는 수순: X 구석 → O 오른쪽 위로 막기 → X 가운데 = 이길 줄 두 개 (대각선 · 가운데 세로).
  - 틱택토 전체 경우의 수: 빈 판부터 끝날 때까지 모든 판 255,168가지 (직접 셈).
  - 아무렇게나 끝까지 (flat Monte Carlo): 칸마다 1,000판 (시드 1), 이긴 비율 (비기면 0) 가운데 66% · 구석 60% · 56 · 55 · 50 · 46 · 43%. 시드 20개 중 18개에서 가운데가 1등.
  - MCTS (UCT, c = 1.4, 이기면 1 · 아니면 0, 시드 0) 3,000번: 구석 2,298번 · 이긴 비율 87%, 가운데 303번 · 67%. 시드 20개 모두 구석. 가장 많이 둔 수순 구석 2,298 → 막기 551 → 가운데 487.
  - s4 네 단계 = 실제 16번째 반복 (구석 → O 오른쪽 위 → 아무렇게나 X 오른쪽 아래 · O 오른쪽 가운데 · X 가운데 → X 승). 직전 구석은 1번 둬 0% 였지만 고르는 점수 2.30 으로 1등 (다른 칸 2.13 · 2.15 · 1.63) = 덜 둬 본 가산점.
  - s6 칸 숫자 = 25번마다 기록한 실제 둔 수.
- 바둑 경우의 수 10의 170제곱: DeepMind AlphaGo 공개 글 (ml1/alphago 편과 같은 숫자). 알파고 = MCTS + 정책망 (둘 만한 수) + 가치망 (승률): Silver et al. 2016, Nature 529 "Mastering the game of Go with deep neural networks and tree search" — 2016 판은 잎 평가에 끝까지 두기와 가치망을 반씩 섞음, AlphaGo Zero (2017) 는 가치망만.
- s7 바둑판 돌 배치는 그림 (화면에 '그림').
- 음성: Typecast 필재. 배경음: Suno "Curious Groove".
