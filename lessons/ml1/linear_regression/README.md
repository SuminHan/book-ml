# 선형회귀

*직선 하나로 예측하기 · 다항 · 로그 변환*

> 7시간 공부하면 몇 점? 선형회귀 1분 컷 📈

## 영상 내용

- ① 직선 h = w₀ + w₁x 를 긋고
- ② 오차² 평균 = 비용 J 를 재고
- ③ 경사하강법으로 J의 바닥까지 → 7시간이면 약 75점

- 곡선 데이터도 x²을 특징으로 넣으면 선형회귀!
- '선형'은 x가 아니라 w에 대해 선형이라는 뜻이에요.
