# SVM학습

*Support Vector Machine*

> SVM 학습, 서포트 벡터 머신이 점 20개 중 경계를 정하는 3개를 어떻게 찾아내는지 실제 학습을 걸음마다 따라가 봤어요

## 영상 내용

- 경계선은 w1·x1 + w2·x2 + b = 0 인 곳이에요. 점의 좌표 x1, x2는 주어져 있으니, 학습으로 찾는 건 숫자 세 개(w1, w2, b)뿐이에요. 처음엔 셋 다 0에서 출발해요
- 점을 식에 넣은 값이 점수예요. 빨간 점은 점수 +1 이상, 파란 점은 −1 이하면 안전하고, 그보다 경계에 가까운 점만 경계를 밀어내요
- 1걸음엔 숫자가 모두 0이라 점수도 다 0, 20개가 전부 밀어서 w = 0.02 × (−44.1, 39.2) = (−0.88, 0.78), 대충 맞는 첫 선이 생겨요
- 그다음엔 길 안에 점이 없어서 숫자를 줄이기만 해요. 숫자가 작아지면 점수가 천천히 변해서 점수 ±1 선이 멀어지고, 길의 폭이 1.69 → 2.74로 넓어져요
- 176걸음에 빨간 점 (3.5, 6), 278걸음에 파란 점 (5, 3), 7,567걸음에 빨간 점 (2, 4.5)이 길 가장자리에 닿아 밀기 시작해요. 세 점이 번갈아 밀면서 20,000걸음에 폭 3.18에서 멈추고, sklearn SVC가 낸 답과 같아요
- 나머지 17개 점은 1걸음 뒤로 한 번도 밀지 않았어요. 끝까지 민 세 점이 서포트 벡터예요

**참고**: 점 20개는 손으로 고른 예시 좌표. 학습 = 힌지 손실 경사하강 (C = 1, 학습률 0.02/√걸음, 20,000걸음). 실제로 쓰는 sklearn SVC는 SMO라는 다른 풀이법을 쓰지만 같은 답이 나와요 (w = (−0.44, 0.44), b = −0.11). 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드: slides/ml1/week02/2_svm (11~15쪽 '직선 찾기 · 학습') 과 같은 점 20개 · 같은 학습 실행.
- 점 20개: 손으로 고른 예시 좌표 (0~10), 빨강 10 · 파랑 10.
- 학습 (src/data.py 에서 직접 실행, assert): 힌지 손실 경사하강, C = 1, 학습률 0.02/√t, (0, 0, 0) 에서 출발 20,000걸음.
  - 1걸음: 모든 점 여유 0 → Σ y_i x_i = (−44.1, 39.2) → w = (−0.88, 0.78), 폭 1.69.
  - 2~175걸음 미는 점 없음, 폭 2.74 (176걸음 직전). 처음 미는 걸음: (3.5, 6) 176 · (5, 3) 278 · (2, 4.5) 7,567. 나머지 17개는 1걸음 뒤로 0번.
  - 20,000걸음: w = (−0.45, 0.44), b = −0.10, 폭 3.18. sklearn SVC (선형, C = 10⁶) 답 w = (−0.44, 0.44), b = −0.11, 서포트 벡터 같은 3개.
- 예시 선 (s3): w = (−0.5, 0.5), b = −0.5 — 점수 표시용으로 고른 선 (학습 결과 아님, 화면에 '예시 선').
- 음성: Typecast 필재. 배경음: Suno "Curious Groove".
