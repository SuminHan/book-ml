# 노름과거리

*Norm*

> 노름(norm)과 거리, 직선의 식에 점을 넣은 값이 왜 거리가 아닌지, 그리고 SVM 식에 왜 β1² + β2² = 1 조건이 붙는지

## 영상 내용

- 직선 x1 + x2 − 3 = 0 에서 정확히 거리 1 떨어진 점을 식에 넣으면 1.41이 나와요. 식의 값은 거리가 아니에요
- 식의 앞 숫자 둘을 화살표 w = (1, 1)로 보면, 이 화살표의 길이가 노름이에요. ‖w‖ = √(1² + 1²) = 1.41
- 같은 직선을 2x1 + 2x2 − 6으로 쓰면 직선은 그대로인데 값은 2.83, 노름도 2.83으로 둘 다 2배가 돼요
- 점을 옮겨 봐도 값은 늘 거리 × 노름이에요. 그래서 거리 = |값| ÷ 노름, 점과 직선 사이 거리 공식이에요
- 식을 노름으로 나눠 노름을 1로 맞추면(0.71x1 + 0.71x2 − 2.12) 값이 바로 거리가 돼요
- SVM의 최대 마진 식에는 β1² + β2² = 1, 노름 1 조건이 붙어요. 그래야 "모든 점의 값 ≥ m"이 "모든 점이 m 이상 떨어져 있다"가 돼요. 예시 점 20개에서 서포트 벡터 3개의 값이 모두 1.59 = 마진 m이에요. 노름을 묶지 않으면 숫자만 2배 해도 값이 3.18로 커져요

**참고**: SVM 장면의 점 20개는 손으로 고른 예시 좌표, 최대 마진 답은 sklearn SVC로 확인 (β = (−0.71, 0.71), β0 = −0.18, m = 1.59). 식은 James et al., ISL 9장 (9.9)–(9.11). 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 장면별 자막과 대사

| # | 화면 자막 | 대사 |
|---|---|---|
| 1 | 거리 1인 점, 식에 넣으면 1.41 / 식의 값은 왜 거리가 아닐까? | 이 점은 직선에서 딱 일만큼 떨어져 있어요. 그런데 직선의 식에 넣으면 일 점 사일이 나와요. 식의 값은 왜 거리가 아닐까요? |
| 2 | w = (1, 1) 화살표의 길이 = 노름 / ‖w‖ = √(1² + 1²) = 1.41 | 답은 노름에 있어요. 식의 앞 숫자 둘을 화살표로 보면, 일, 일이에요. 이 화살표의 길이를 노름이라고 해요. 루트 일 제곱 더하기 일 제곱, 일 점 사일이죠. |
| 3 | 2x1 + 2x2 − 6: 같은 직선 / 값 2.83 · 노름 2.83, 둘 다 2배 | 같은 직선을 숫자만 두 배로 써 볼게요. 직선은 그대로인데, 값은 이 점 팔삼, 노름도 이 점 팔삼, 둘 다 두 배가 돼요. |
| 4 | 값 = 거리 × 노름 / 거리 = \|값\| ÷ 노름 | 점을 옮겨 봐도 똑같아요. 값은 늘 거리 곱하기 노름이에요. 그래서 거리는 값을 노름으로 나눈 것, 점과 직선 사이 거리 공식이죠. |
| 5 | 식을 노름으로 나눠 노름 = 1 / → 값 = 거리 | 그러면 처음부터 식을 노름으로 나눠서, 노름을 일로 맞춰 두면 어떨까요? 값이 바로 거리가 돼요. |
| 6 | SVM: 노름 = 1 로 묶으면 / 모든 점의 값 ≥ m = m 이상 떨어짐 | SVM이 바로 이걸 써요. 가장 가까운 점까지 거리, 마진을 최대로 하는 식에 노름이 일이라는 조건이 붙어요. 그래야 모든 점의 값이 m 이상이면, 모든 점이 m 이상 떨어져 있다는 뜻이 되죠. 노름을 안 묶으면 숫자만 키워도 값이 끝없이 커지고요. |
| 7 | 노름 = 화살표의 길이 / 노름 1 로 맞추면 값 = 거리 | 노름은 화살표의 길이, 식의 값은 거리 곱하기 노름이에요. 노름을 일로 맞추면 값이 곧 거리예요. |

## 출처

- 슬라이드: slides/ml1/week02/2_svm 8~10쪽 (최대 마진 식 말풍선 · 점과 직선 사이 거리 · 참고: 점곱과 코사인) 과 같은 예.
- 앞 장면 (src/data.py, assert): 직선 x1 + x2 − 3 = 0, 경계 위 점 (2.2, 0.8) 에서 w 방향으로 거리 d 인 점의 값 = d × ‖w‖. 거리 1: 1.41 (‖w‖ = √2), 2배 식 2.83, 노름으로 나눈 식 (0.71, 0.71, −2.12) 1.00.
- SVM 장면: 덱과 같은 손으로 고른 점 20개, sklearn SVC (선형, C = 10⁶) 로 확인한 최대 마진 β = (−1, 1)/√2, β0 = −1/(4√2), m = 9/(4√2) = 1.59, 서포트 벡터 3개의 값 = m. 노름 2배면 값 3.18.
- 식: James et al., An Introduction to Statistical Learning, 9장 (9.9)–(9.11) · S. Wang, CME 250 Lecture 5 (Stanford, 2019).
