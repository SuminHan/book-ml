# XOR과 역전파

*퍼셉트론의 한계, AI 겨울, 그리고 역전파*

> AI를 얼어붙게 한 문제, XOR 🧊

## 영상 내용

- XOR: 두 입력이 다를 때만 1
- 퍼셉트론(1958)은 직선 하나로 분류 → XOR은 어떤 직선으로도 못 나눈다
- 1969 민스키 & 페퍼트 《Perceptrons》 → 신경망 연구의 겨울 (1970년대 ~ 1980년대 중반, 약 15년)

- 층을 쌓으면 직선 두 개로 풀리지만: h = σ(W₁x + b₁), y = σ(W₂h + b₂)
- 숨은 층의 W₁을 학습할 방법이 없었다
- 1986 역전파: 오차 L을 연쇄법칙으로 거꾸로 전달
- 출력층 ∂L/∂W₂ = ∂L/∂y · ∂y/∂W₂
- 숨은 층 ∂L/∂W₁ = ∂L/∂y · ∂y/∂h · ∂h/∂W₁
- → 정확도 50% → 100%, 딥러닝의 출발점
