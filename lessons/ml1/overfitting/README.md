# 과대적합과 과소적합

*Overfitting · Underfitting · 교차 검증*

> 과대적합(Overfitting)은 가진 데이터의 점을 외워서 새 데이터를 틀리는 것, 과소적합(Underfitting)은 너무 단순해서 가진 데이터도 못 따라가는 것이에요. 둘 사이에서 고르는 방법이 교차 검증(Cross Validation)이에요.

## 영상 내용

- 제동거리 = 브레이크를 밟고 멈출 때까지 가는 거리. 제동거리는 속도의 제곱으로 늘어나요. 속도가 2배면 제동거리는 4배 (예시 데이터: 50km/h 14m → 100km/h 59m)
- 직선으로 예측하면 시속 10km에서 실제 2m를 −5m로 예측해요. 제동거리가 음수? 명확히 틀린 예측이에요
- 오차 = 실제와 예측의 차이. 2m와 −5m의 차이 7m가 오차이고, 점 10개의 오차를 평균 내면 5m → 너무 단순한 과소적합
- 구불구불한 곡선은 측정한 점을 모두 지나 오차 0m. 그런데 새로 잰 데이터에서는 3m를 33m로 예측하고(오차 30m) 음수 구간까지 내려가요. 평균 오차 9m → 점을 외운 과대적합
- 2차 곡선은 측정 데이터 2m, 새 데이터 3m. 제곱 법칙과 같은 모양이에요
- 새 데이터는 미리 없으니, 가진 데이터를 5조각으로 나눠 한 조각씩 돌아가며 숨겨 두고 맞혀 본 뒤 5번 오차를 평균내요 = 5겹 교차 검증(k-fold)
- 교차 검증 오차: 직선 7m, 구불구불 121m, 2차 곡선 3m → 가장 작은 2차 곡선을 골라요

**참고**: 제동거리는 물리 법칙(d = v²/2μg, 마찰계수 0.7 가정)에 측정 오차를 더한 예시 데이터예요 (곡선 = 1·2·9차 다항식, 오차 = 평균 절대 오차).
