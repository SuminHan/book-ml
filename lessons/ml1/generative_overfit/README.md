# 생성모델의 오버피팅

*생성 모델 · 판별 모델 · 외우기(Memorization)*

> 생성 모델(Generative Model)은 데이터 분포를 통째로 배우니 판별 모델(Discriminative Model)보다 오버피팅이 덜할까요? 답은 아니요. 생성 모델의 오버피팅은 '외우기(Memorization)'로 나타나요.

## 영상 내용

- 판별 모델: 고양이와 강아지 사이에 경계선만 긋는다, P(y|x). 예: 고양이·강아지 사진 분류 AI
- 생성 모델: 데이터가 생긴 모양(분포) 자체를 배워 새 데이터를 뽑는다. 예: 그림 생성 AI, GPT
- 고양이 몸무게 언덕(밀도)이 적당하면 처음 보는 고양이를 새로 뽑지만, 너무 뾰족하면 뽑은 5마리가 전부 학습 데이터와 0.05kg 안, 즉 복사본
- 뾰족한 언덕은 학습 고양이에는 꼭 맞지만, 숨겨 둔 진짜 새 고양이(5.1kg)의 높이는 거의 0, "이런 고양이는 없다"
- 실제로 2021년 연구에서 GPT-2가 학습 데이터 속 이름·연락처를 그대로 출력했어요
- 막는 법: 중복 데이터 제거(여러 번 본 데이터일수록 더 외움), 숨겨 둔 데이터로 점수 재기, 규제(드롭아웃·가중치 감쇠·조기 종료)

**참고**: 고양이·강아지 몸무게는 예시 데이터이고, 언덕은 가우시안 커널 밀도 추정(폭 0.5kg vs 0.05kg)으로 직접 계산했어요.

**참고**: 사례: Carlini et al., Extracting Training Data from Large Language Models (USENIX Security 2021) · 중복과 외우기: Kandpal et al. (ICML 2022), Lee et al. (ACL 2022)

**참고**: 이모지: Twemoji (CC BY 4.0)

## 출처

- 개념: ~/book-ml/slides/kor/ml1/week03/pages/p02.tex · p03.tex · p04.tex (판별 P(y|x) vs 생성 P(x|y)), week08/pages/p50.tex (kNN = 전량 암기)
- 데이터: **예시**(손으로 만든 몸무게, kg). 고양이 12마리 [3.0…8.0], 강아지 8마리 [10.5…17.5], 숨겨 둔 새 고양이 5.1kg, 실제 통계 아님
- 계산: 가우시안 커널 밀도 추정(폭 0.5kg 적당 / 0.05kg 뾰족), 표본 = 학습 고양이 하나 + 폭만큼 잡음. src/data.py assert: 뾰족 표본 5개 모두 학습 고양이와 0.05kg 안, 새 고양이 높이 2e-8 vs 0.17, 4.3kg 고양이 5번 중복이면 뽑은 5마리 모두 그 근처(±0.6kg)
- 사례: Carlini et al., "Extracting Training Data from Large Language Models", USENIX Security 2021 (GPT-2에서 이름·전화번호·이메일 등 학습 문장 추출). 화면의 "이름 ○○○ / 전화 010-…" 카드는 가린 예시 그림
- 중복과 외우기: Kandpal et al., "Deduplicating Training Data Mitigates Privacy Risks in Language Models", ICML 2022; Lee et al., "Deduplicating Training Data Makes Language Models Better", ACL 2022
