# ROC와 AUC

*커트라인을 바꿔 가며 본 성적*

> ROC 곡선과 AUC: 정확도 90% AI, 믿어도 될까요? 커트라인을 바꿔도 거의 그대로인 정확도 대신, 모든 커트라인의 성적을 보는 ROC와 AUC를 학교 100명 중 독감 10명 예시로 정리했어요.

## 영상 내용

- 정확도의 함정: 모두 건강이라고만 해도 정확도 90%. 찾은 독감은 0명
- AI는 학생마다 독감 점수(0~100점)를 매기고, 커트라인을 넘으면 독감 판정
- 커트라인 50점: 재현율(독감 중 찾은 비율) 8/10, 헛짚은 비율(건강 중 헛짚은 비율) 4/90
- 커트라인을 100점 → 30점으로 움직이면 찾은 독감은 0명 → 10명으로 바뀌는데, 정확도는 90~95%로 거의 그대로
- 커트라인을 위에서 아래로 내리며 (헛짚은 비율, 재현율)을 찍은 곡선이 ROC 곡선
- 곡선 아래 넓이가 AUC = 0.98. 모두 건강 AI는 정확도 90%여도 AUC 0.5(동전 던지기)
- AUC의 뜻: 독감 학생과 건강한 학생을 한 명씩 뽑으면, 900쌍 중 883쌍(98%)은 독감 학생 점수가 더 높아요

**참고**: 100명·독감 10명과 점수는 설명을 위한 예시 데이터예요. 모든 수치는 그 예시에서 직접 계산했어요.
