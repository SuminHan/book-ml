# 정밀도와 재현율

*정확도 90%의 함정*

> 정밀도와 재현율(Precision · Recall): 정확도(Accuracy)만 보면 쏠린 데이터에서 속아요. 두 원(AI가 고른 학생 · 진짜 독감 학생) 그림으로 학교 100명 중 독감 10명 예시를 쉽게 정리했어요.

## 영상 내용

- 100명 중 독감 10명이면, 모두 건강하다고 찍기만 해도 정확도 90%. 독감은 한 명도 못 찾았는데도요
- 진짜 AI가 12명을 독감이라고 골랐어요. 진짜 독감 10명과 겹치는 건 8명
- 정밀도 = AI가 고른 12명 중 진짜 8명 = 67% → AI 말이 맞았나?
- 재현율 = 독감 걸린 10명 중 잡힌 8명 = 80% → 놓치지 않았나? (2명 놓침)
- 둘 다 위(분자)는 같은 8, 아래(기준)만 달라요: 정밀도는 AI가 고른 학생 기준, 재현율은 진짜 독감 학생 기준
- 모두 독감이라고 하면 재현율은 100%가 되지만 정밀도는 10% → 둘을 같이 봐야 해요
- Recall(재현율)은 원래 '기억해 내기'라는 뜻: 찾아야 할 것 중 얼마나 불러냈나

**참고**: 100명·독감 10명은 설명을 위한 예시 데이터예요.
