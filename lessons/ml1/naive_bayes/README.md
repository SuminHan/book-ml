# 나이브 베이즈

*베이즈 정리로 확률을 뒤집어 분류하기*

> '무료'가 든 메일, 스팸일 확률은? 📩

## 영상 내용

- 메일 1000통 중 스팸 300통 → 그중 무료 180통
- 정상 700통 → 그중 무료 35통
- 무료 메일 215통만 남기면 스팸은 180통 ≈ 84%

- 이 세기를 식으로 쓰면 베이즈 정리
- P(스팸|무료) = 0.6 × 0.3 ÷ 0.215 ≈ 0.84 → 직접 센 값과 같다!
- P(스팸) 30% → P(스팸|무료) 84% → P(스팸|무료,당첨) 99%
- 단어별 확률을 곱하는 게 나이브 베이즈예요.

## 장면별 자막과 대사

| # | 화면 자막 | 대사 |
|---|---|---|
| 1 | 무료가 든 메일 / 스팸일 확률은? | 메일에 무료라는 단어가 있어요. 이 메일이 스팸일 확률은 얼마일까요? |
| 2 | 스팸 300통 중 / 무료 180통 | 메일 1000통 중 스팸은 300통, 그중 180통에 무료가 있어요. |
| 3 | 정상 700통 중 / 무료 35통 | 정상 메일 700통 중에도, 35통에는 무료가 있어요. |
| 4 | 무료 메일 215통 중 스팸 180통 / ≈ 84% | 무료가 든 메일만 남기면 215통. 그중 스팸은 180통, 약 84퍼센트예요. |
| 5 | 센 것을 식으로 쓰면 / = 베이즈 정리 | 이 세는 과정을 식으로 쓴 게 베이즈 정리예요. |
| 6 | 0.6 × 0.3 ÷ 0.215 ≈ 0.84 / = P(스팸\|무료) 84% | 숫자를 넣으면, 스팸 비율 0.3, 스팸 중 무료 0.6, 무료 메일 0.215. 계산하면 약 0.84, 직접 센 84퍼센트와 똑같아요. |
| 7 | P(스팸) 30% → P(스팸\|무료) 84% / → P(스팸\|무료,당첨) 99% | 아무 단어도 안 봤을 때 스팸일 확률은, 메일함의 스팸 비율인 30퍼센트. 무료가 있으면 84, 당첨까지 있으면 99퍼센트. 단어별 확률을 곱하는 게 나이브 베이즈예요. |
