# 행렬곱의바닥2.25

*Matrix Multiplication Exponent · Lower Bound*

> 행렬 곱셈 지수(Matrix Multiplication Exponent ω)의 바닥: 지난달 천장이 2.25까지 내려왔고, 이번엔 OpenAI 논문이 어떤 방법도 2.25보다 빠를 수 없다고 증명했다고 밝혔어요.

## 영상 내용

- 교과서 방식: 칸 하나 n번 × n² 칸 = n³ 번
- 1969년 슈트라센: 2×2 곱셈 8번 → 7번, 지수 3 → 2.81
- 천장 낮추기 경쟁: 1990년 2.376, 2026년 8월 2.371, 2026년 10월 OpenAI 2.25
- 바닥: 답 칸만 n² 개라 적어도 2. 그동안 사람이 증명한 바닥은 지수 2 (약 3n²)
- 2026년 11월 24일 논문: 곱셈·나눗셈이 최소 n의 2.25제곱의 절반 → 가로세로 1만 칸이면 최소 5억 번 (교과서 1조 번)
- 증명은 귀류법: 더 빠르면 여러 명단에서 겹치는 이름을 찾는 계산이 증명된 최소 비용보다 싸져 모순
- 111쪽 중 나눗셈 없는 경우는 Lean으로 확인했다고 밝혔고, 동료 심사는 아직이에요

**참고**: 출처: github.com/openai/math 'The matrix multiplication exponent is nine fourths' (2026.11.24, 논문과 README), 'An Upper Bound of 9/4 for the Matrix Multiplication Exponent' (2026.10.2), arXiv 2608.16884 (2.371177). 명단 이름은 예시예요. 이모지: Twemoji (CC BY 4.0) · 음성: Typecast (필재) · 배경음: Suno

## 출처

- 논문: OpenAI, "The matrix multiplication exponent is nine fourths" (2026-11-24, 111쪽), github.com/openai/math preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026 (사본 assets/openai_matmul_9-4_lower_2026-11-24.pdf). 초록: 모든 체에서 ω = 9/4, n ≥ 2 이면 곱셈·나눗셈 ≥ ⌈n^(9/4)/2⌉ (선형 연산은 공짜로 쳐도). 증명 줄거리 1.2절: 더 빠르면 '여러 명단의 단어가 모두 다른지 검사' 텐서 네트워크가 증명된 하한(정리 2.2)보다 싸져 모순.
- Lean: 저장소 README 'The Lean development proves the square exponent 9/4 for division-free circuits … over every field' → 영상 '일부 (나눗셈 없는 경우) Lean 확인'. 동료 심사 전.
- 천장 기록: 슈트라센 1969 log2 7 ≈ 2.81 (논문 [50]), 코퍼스미스·위노그라드 1990 2.376, 2026.8 2.371177 (arXiv 2608.16884, 지난 편 matmul_omega 에서 확인), OpenAI 2026.10.2 9/4 (복소수, 논문 [41]) → 모든 체 (Amanov · van den Berg · Zuiddam [5], Lü [39]).
- 사람이 증명한 바닥: 블레저 (5/2)n² − 3n (모든 체), 랜즈버그 3n² − o(n²) (복소수), 논문 1.5절 → 지수 2.
- 1만 칸 숫자 (src/data.py assert): (10⁴)³ = 1조, ⌈10⁹/2⌉ = 5억, 10⁸ = 1억 (로그 눈금 막대).
