# 행렬곱의바닥2.25

*Matrix Multiplication Exponent · Lower Bound*

> 행렬 곱셈 지수(Matrix Multiplication Exponent ω) = 9/4: OpenAI가 2026년 11월 24일 논문에서 행렬 곱셈은 n의 2.25제곱보다 빠를 수 없다고 증명했다고 밝혔어요. 왜 하필 2.25인지 실제 계산으로 따라가 봤어요.

## 영상 내용

- 교과서: 2×2 행렬은 칸마다 2번, 모두 8번 곱셈 (19 = 1×5 + 2×7 …)
- 1969 슈트라센: 먼저 더하고 빼서 묶은 뒤 곱하면 7번 (M1 = (1+4)×(5+8) = 65 …).
- 왜 같은 답? 글자로 펼치면 M1 + M4 − M5 + M7 = (ae + ah + de + dh) + (dg − de) − (ah + bh) + (bg + bh − dg − dh), 항 12개 중 10개가 지워지고 ae + bg 만 남아요. 크기 2배마다 8배 대신 7배 → 지수 2.81
- OpenAI의 천장(2026.10): 다항식 곱셈 (1+2x)(3+4x) 는 4번 대신 x = 0, 1, −1 에 넣고 3번 곱한 뒤 거꾸로 풀면 끝. 길이 a면 a² 번 → 2a − 1 번
- 행렬 곱셈을 다항식 곱셈 속에 넣어 점수를 매기면 위로는 기울기 3 ÷ ω, 아래로는 새 쪼개기로 기울기 4/3 → 3 ÷ ω ≥ 4/3 → ω ≤ 9/4
- OpenAI의 바닥(2026.11): Y자 길 세 끝에 A, B, C → 번호 i, j, k 길이 2 × 3 = 6, 곱셈 r번 방법의 같은 번호 값 8/3 → 8/3 · log r ≥ 6 · log n → r ≥ n^(9/4)
- 1만 칸 행렬이면 어떤 방법도 최소 5억 번 (교과서 1조 번). 증명 일부(나눗셈 없는 경우)는 Lean 확인, 동료 심사 전

**참고**: '점수'는 논문의 슈트라센 점수표(asymptotic spectrum, tensor character)를, '길이·값'은 논문의 price를 쉽게 줄여 말한 거예요. 2×2 숫자와 다항식은 예시예요. 출처: github.com/openai/math 'The matrix multiplication exponent is nine fourths' (2026.11.24, 1.3절 · 8절), 'An Upper Bound of 9/4 for the Matrix Multiplication Exponent' (2026.10.2), Strassen (1969). 이모지: Twemoji (CC BY 4.0) · 음성: Typecast (필재) · 배경음: Suno

## 출처

- 논문: OpenAI, "The matrix multiplication exponent is nine fourths" (2026-11-24, 111쪽), github.com/openai/math preprints/The-matrix-multiplication-exponent-is-nine-fourths-November-24-2026 (사본 assets/openai_matmul_9-4_lower_2026-11-24.pdf). 초록: 모든 체에서 ω = 9/4, n ≥ 2 이면 곱셈·나눗셈 ≥ ⌈n^(9/4)/2⌉ (선형 연산은 공짜로 쳐도). 증명 줄거리 1.2절: 더 빠르면 '여러 명단의 단어가 모두 다른지 검사' 텐서 네트워크가 증명된 하한(정리 2.2)보다 싸져 모순.
- Lean: 저장소 README 'The Lean development proves the square exponent 9/4 for division-free circuits … over every field' → 영상 '일부 (나눗셈 없는 경우) Lean 확인'. 동료 심사 전.
- 천장 기록: 슈트라센 1969 log2 7 ≈ 2.81 (논문 [50]), 코퍼스미스·위노그라드 1990 2.376, 2026.8 2.371177 (arXiv 2608.16884, 지난 편 matmul_omega 에서 확인), OpenAI 2026.10.2 9/4 (복소수, 논문 [41]) → 모든 체 (Amanov · van den Berg · Zuiddam [5], Lü [39]).
