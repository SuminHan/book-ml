# EM과 강화학습

*EM 알고리즘 · 강화학습 · 우도 vs 보상*

> EM 알고리즘과 강화학습(Reinforcement Learning)은 둘 다 반복할수록 점수가 오르지만, 점수와 데이터가 달라요.

## 영상 내용

- EM은 모델이 아니라 학습 방법이에요. 혼합 분포(키 → 두 무리)도, 번역 모델(단어 짝 찾기)도 EM으로 배워요
- EM: 안 보이는 값을 확률로 채우고(E) 모델을 다시 맞춰요(M). 점수 = 데이터를 얼마나 잘 설명하나(우도)
- 강화학습: 직접 해 봐요. 사탕 기계를 누르고(행동), 나온 사탕(보상)으로 고르는 법(정책)을 고쳐요
- 공통점: 둘 다 '평가 → 고치기'를 번갈아 해요. 그래서 EM으로 강화학습을 푸는 연구도 있어요 (Dayan & Hinton 1997, DeepMind MPO 2018)
- 차이: EM은 정해진 데이터로 계산해서 50번 동안 점수가 한 번도 안 떨어져요. 강화학습은 탐험하며 데이터를 모아서 39번 중 20번 떨어지지만, 결국 평균 사탕 4.2개 → 6.6개로 올라가요

**참고**: EM 곡선: 번역편(IBM Model 1) 로그 우도 직접 계산 · 강화학습 곡선: 예시 사탕 기계 5대 + REINFORCE 직접 계산

## 출처

- EM 곡선: ml1/em_translation (번역편 v3) IBM Model 1 의 로그 우도, 50번 반복 (-53 → -35.5, 한 번도 안 떨어짐). src/data.py 가 번역편 data.py 를 경로로 불러와 계산
- 강화학습 곡선: **예시** 사탕 기계 5대(평균 2·4·6·3·5개, 잡음 표준편차 2), softmax 정책 + REINFORCE(평균 기준선, 학습률 0.15), 라운드마다 20번, 40라운드, seed 0. assert: 평균 사탕 4.2 → 6.6, 39번 중 20번 하락, 6개 기계 선택 확률 84%
- EM 으로 강화학습: P. Dayan & G. E. Hinton, "Using Expectation-Maximization for Reinforcement Learning", Neural Computation 9(2), 1997 · A. Abdolmaleki et al. (DeepMind), "Maximum a Posteriori Policy Optimisation (MPO)", ICLR 2018
- EM 일반: week04 p60·p65–p66·p69 (우도가 매 반복 줄지 않음)
