# 커널트릭

*Kernel Trick*

> 커널 트릭(kernel trick), 점을 높은 차원으로 옮기지 않고도 옮긴 점끼리의 점곱을 구하는 지름길, 그리고 SVM이 이걸로 휘어진 경계를 만드는 방법

## 영상 내용

- 빨강이 가운데, 파랑이 바깥을 둘러싼 점 120개. 직선으로 가르는 SVM은 59%밖에 못 맞혀요
- 점마다 높이 x1² + x2² 를 붙이면 가운데 빨강은 낮고 바깥 파랑은 높아져서, 평평한 판 하나로 갈라져요. 원래 자리로 내려 보면 경계는 원, 120개 모두 맞혀요
- SVM 식 f(x) = b + Σ αᵢ (x · xᵢ) 에는 점 두 개의 점곱만 나와요. 그래서 옮긴 점끼리의 점곱만 알면 돼요
- 먼 길: x = (1, 2), xᵢ = (3, 1) 을 φ(v) = (v1², √2·v1·v2, v2²) 로 옮기면 (1, 2√2, 4) · (9, 3√2, 1) = 9 + 12 + 4 = 25
- 지름길: 옮기지 않고 원래 점곱 1·3 + 2·1 = 5 를 제곱하면 똑같이 25. 이 지름길 K(x, xᵢ) = (x · xᵢ)² 가 커널, 점곱 자리에 커널을 넣는 게 커널 트릭이에요
- 28×28 손글씨 그림(숫자 784개)이면 두 개씩 곱한 숫자는 307,720개, 세 개씩 곱하면 80,622,640개. 커널은 그래도 원래 784개로 점곱 한 번, 거듭제곱 한 번이면 끝이에요

**참고**: 원 데이터는 sklearn make_circles (120개, random_state 1), 정확도는 sklearn SVC로 계산 (직선 59%, 커널 (x · x′)² 100%). 높이 장면은 φ의 첫 칸 + 셋째 칸을 높이로 그린 그림. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드: slides/ml1/week02/3_svm_kernel '오늘의 질문' · '특징 늘리기' · '분류기를 점곱으로 다시 쓰면' · '커널: 점곱 자리에 K 를 넣는다' 쪽과 같은 예.
- 원 데이터 (src/data.py, assert): sklearn make_circles(120, factor = 0.4, noise = 0.06, random_state = 1), 덱과 같은 데이터. 직선 SVM (SVC linear, C = 1) 정확도 59%, 커널 (x · x′)² SVM (SVC poly degree 2, coef0 0, C = 1) 100%, 경계 = 타원 −2.79x1² + 0.14x1x2 − 3.06x2² + 1.64 = 0 (반지름² ≈ 0.56).
- 높이 장면: 높이 = x1² + x2² 를 붙인 그림 (평평한 판 높이 0.56). 실제 커널의 φ 는 (x1², √2x1x2, x2²) 세 칸이고, 높이는 그중 첫 칸 + 셋째 칸.
- 커널 계산: 덱과 같은 두 점 x = (1, 2), xᵢ = (3, 1). φ(x) = (1, 2√2, 4), φ(xᵢ) = (9, 3√2, 1), 점곱 9 + 12 + 4 = 25 = (3 + 2)².
- 특징 수: 28×28 손글씨 그림 (숫자 784개), (x · x′)^d 의 φ 칸 수 = C(784 + d − 1, d) → 2차 307,720 · 3차 80,622,640.
- 음성: Typecast 필재. 배경음: Suno "Curious Groove".
