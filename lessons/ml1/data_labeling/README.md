# 데이터 라벨링

*ImageNet의 이름표는 누가 붙였나*

> 데이터 라벨링(Data Labeling)은 AI가 배울 사진·글에 정답 이름표를 붙이는 일이에요. 딥러닝 시대를 연 ImageNet의 1400만 장도 사람이 직접 붙였어요.

## 영상 내용

- ImageNet(2009): 범주 2만 개 이상, 사진 1400만 장. 2012년 AlexNet이 이 데이터로 학습했어요
- 한 사람이 쉬지 않고 해도 19년 걸릴 양 → Amazon Mechanical Turk로 일을 잘게 쪼개 167개국 4만 9천 명이 나눠 맡았어요 (2008–2010)
- 이름은 1770년 '체스 두는 기계(The Turk)'에서 왔어요. 사실은 상자 안에 사람이 숨어 있었죠
- 사람은 틀리기 때문에 같은 사진을 여러 명(적어도 3명)이 따로 보고 다수결로 정해요
- 헷갈리는 범주일수록 더 많은 사람이 필요해요: '고양이'는 적은 수로 충분했지만 '버마고양이'는 5명쯤. 그렇게 정확도 99.7%
- Amazon Mechanical Turk는 2026년 9월 30일 서비스를 종료했어요

**참고**: 출처: Deng 외 2009 "ImageNet: A Large-Scale Hierarchical Image Database" (CVPR) / 위키백과 ImageNet 항목

**참고**: 그림: Joseph Racknitz 1789, 체스 기계 작동 추정도 (퍼블릭 도메인 · 위키미디어 공용)

**참고**: 3명 투표(2:1) 장면은 예시 그림이에요. 실제 ImageNet은 범주 난이도에 따라 투표 인원을 늘렸어요.

## 출처

- Deng, Dong, Socher, Li, Li, Fei-Fei (2009), "ImageNet: A Large-Scale Hierarchical Image Database", CVPR
  - §3.2: Amazon Mechanical Turk로 후보 사진을 검증. 여러 사용자가 같은 사진을 따로 판단 → "convincing majority"일 때만 채택
  - 범주마다 필요한 합의 수가 다름: "Burmese cat"은 5명쯤 필요, "cat"은 훨씬 적은 수로 충분. 처음엔 범주별 표본을 10명 이상에게 보여 신뢰도 표를 만들고, 기준 신뢰도에 닿을 때까지 사람을 추가 (동적 합의)
  - 80개 범주 표본의 평균 정밀도 99.7%
- Wikipedia "ImageNet": 1400만 장 이상, 2만 개 이상 범주 / 2008.7–2010.4, 167개국 4만 9천 명이 1억 6천만 장 후보를 거름 / "사진마다 3번씩 라벨링할 예산" / 학생 인력만으로는 19인년(쉬지 않고) 추정
  - 쇼츠의 "적어도 3명"은 이 '3번씩'과 다수결 원리(홀수, 2:1)를 합친 표현. 실제 ImageNet은 범주 난이도에 따라 인원이 달라짐 (s7에서 설명)
- Amazon Mechanical Turk: 2005년 공개, 2026-08-25 공지 → 2026-09-30 서비스 종료 (TechSpot, TechTimes 2026-08)
- 이름: Wolfgang von Kempelen의 체스 자동기계 "The Turk" (1770). 사람이 안에 숨어 조종
- 그림: Wikimedia Commons "Racknitz - The Turk 3.jpg", Joseph Racknitz 1789 (작동 방식 추정도), **Public domain** → `racknitz.jpg` (1000px 축소)
