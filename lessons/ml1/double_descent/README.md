# 이중하강

*Double Descent*

> 이중 하강 Double Descent, 과대적합이 된 뒤에도 모델을 계속 키우면 시험 오류가 다시 줄어드는 현상 (2019년에 이름이 붙음)

## 영상 내용

- 손글씨 숫자 200장으로 학습하고, 처음 보는 1797장으로 시험했어요. 모델 크기는 특징 수로 정했어요 (무작위 특징 + 선형 모델)
- 특징 100개면 시험 오류 20%. 특징 200개, 학습 데이터 수와 같아지면 83%로 치솟아요. 학습 200장은 전부 맞히는데 시험은 거의 찍는 수준이에요
- 그런데 4000개까지 키우면 오류 10%. 처음 바닥 20%보다도 좋아요. 내려갔다, 올라갔다, 다시 내려가서 이중 하강이에요
- 200개가 최악인 이유: 특징 수와 데이터 수가 같으면 200장을 모두 맞히는 가중치가 딱 하나예요. 그 하나로 사소한 차이까지 억지로 맞추느라 가중치 크기가 9에서 294로 커져요
- 특징이 더 많으면 모두 맞히는 가중치가 무수히 많고, 그중 크기가 가장 작은 걸 고르면 다시 잘 맞혀요 (4000개에서 크기 1). 경사하강법을 0에서 출발시키면 저절로 이 답에 도착해요

**참고**: 데이터: UCI optdigits (8×8 손글씨 숫자). 오류율과 가중치 크기는 무작위 첫 층 5가지의 평균, 화면의 숫자 18장은 그중 하나의 실제 예측이에요. 이름은 Belkin et al. (2019, PNAS), 딥러닝에서는 Nakkiran et al. (2019, Deep Double Descent). 가로축을 '유효 파라미터 수'로 바꾸면 고전적인 U자와 비슷하다는 반론(Curth et al., 2023, NeurIPS)도 있어서 해석은 아직 논쟁 중이에요. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드: slides/ml1/week15/2_double_descent (15-2 이중 하강). 숫자는 그 덱 data.py 의 손글씨 숫자 실험 (assert 로 확인한 값)
- 데이터: UCI optdigits (8×8, 밝기 0~16). 학습 = optdigits.tra 앞 200장, 시험 = optdigits.tes 1797장
- 모델: 무작위 ReLU 특징 p개 (첫 층 무작위 고정, 입력은 학습 평균을 뺌) + 선형, 원-핫 최소제곱. 특징이 200보다 많으면 lstsq 가 최소 노름 해
- 결과 (seed 5개 평균): 오류율 p 100 → 20%, 200 → 83%, 4000 → 10%. 가중치 크기 9 · 294 · 1
- 화면 그리드 18장 = 시험 세트 1~18번 (0부터 셈), seed 0 의 실제 예측 (make_grid.py → assets/grid.json). 틀린 수 4 · 15 · 2장. 이 구간은 평균 오류율과 비슷한 곳으로 고름. seed 0 학습 정확도는 세 경우 모두 100%
- 가중치 2개 그림 (w1 + w2 = 3 위의 점은 모두 정답, 가장 작은 답 (1.5, 1.5), 0 에서 출발한 경사하강법은 대각선을 따라 도착) = 덱 문제풀이 2·3번과 같은 단순화 예시
- 이름과 역사: Belkin et al. (2019) PNAS; Nakkiran et al. (2019) 'Deep Double Descent'; 반론 Curth et al. (2023) NeurIPS 'A U-turn on Double Descent'. 피크 자체는 1990년 전후 통계물리 학습 곡선 연구에서 이미 보고됨 → 영상은 '2019년에 이름이 붙은'
- 이전 판 (v1~v3) 은 제동거리 다항식 예시. 보통 다항식 (x, x², …) 으로는 두 번째 하강이 안 나오고 (16차 18.1 m, 40차 561.8 m) 르장드르 기저에서만 나와서 사용자와 상의해 손글씨 숫자로 바꿈 (shorts_v3_제동거리.py · data_v3_제동거리.py)
- 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (사용자 생성)
