# 이중하강

*Double Descent*

> 이중 하강 Double Descent, 과대적합이 된 뒤에도 모델을 계속 키우면 새 데이터 오차가 다시 줄어드는 현상 (2019년에 이름이 붙음)

## 영상 내용

- 제동거리 점 10개에 다항식 곡선을 맞추고, 새로 잰 데이터 6개로 오차를 쟀어요. 1차 직선은 6.4 m, 3차 곡선은 2.9 m로 가장 좋아요
- 9차가 되면 곡선이 점 10개를 모두 지나지만 새 데이터 오차는 9.1 m. 15 km/h에서 실제 3 m를 33 m로 예측해요. 점을 외운 과대적합이에요
- 그런데 계속 키우면 10차 9.0, 13차 4.5, 16차 3.9 m로 다시 내려가요. 내려갔다, 올라갔다, 다시 내려가는 이 모양이 이중 하강이에요
- 9차가 최악인 이유: 계수가 10개, 점도 10개라 모든 점을 지나는 곡선이 딱 하나예요. 30 km/h에서 0 m 같은 잡음 점까지 지나려고 크게 휘어서 계수 크기가 130까지 커져요 (3차는 39)
- 16차는 계수가 17개라 점을 다 지나는 곡선이 무수히 많고, 그중 계수 크기가 가장 작은 곡선(38.6)을 고르면 얌전해져요. 경사하강법을 0에서 출발시키면 저절로 이 곡선에 도착해요
- 손글씨 숫자 200장으로 무작위 특징 수를 늘려 보면 100개 오류 20%, 200개 83%, 4000개 10%. 피크는 특징 수가 학습 데이터 수와 같은 자리예요

**참고**: 출처: 제동거리는 수업용 예시 데이터, 손글씨 숫자는 UCI optdigits (학습 200장, 시험 1797장, seed 5개 평균). 이름은 Belkin et al. (2019, PNAS). 이 곡선을 '유효 파라미터 수'로 다시 그리면 고전적인 U자와 크게 다르지 않다는 반론(Curth et al., 2023, NeurIPS)도 있어서 해석은 아직 논쟁 중이에요. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드: slides/ml1/week15/2_double_descent (15-2 이중 하강). 숫자는 그 덱의 data.py (assert 로 확인한 값) 를 그대로 옮기고 이 폴더 data.py 에서 다시 확인
- 제동거리 점 10개 (속도 10~100 km/h, 측정 잡음 있음) = 3주차 과대적합 덱과 같은 예시 데이터. 새 데이터 = 다른 속도 6개, 오차 = 평균 절대 오차 (m)
  - 다항식은 르장드르 기저, 10차부터는 계수가 점보다 많아 최소 노름 해 (numpy lstsq). 1차 6.4 · 3차 2.9 · 9차 9.1 · 16차 3.9 m
  - 계수 크기 (제곱합의 제곱근) 3차 39.0 · 9차 130.0 · 16차 38.6. 9차는 15 km/h 에서 32.9 m 예측 (실제 3 m)
  - 16차 회색 곡선 3개 = 최소 노름 해 + 영공간 방향 (점 10개를 모두 지남, 그림용). 경사하강법 1000번, 0 에서 출발 → 최소 노름 해와 거리 0.0 (모든 계수 3 에서 출발하면 11.6)
- 손글씨 숫자: UCI optdigits (8×8, Alpaydin & Kaynak), 학습 앞 200장 · 시험 1797장, 무작위 ReLU 특징 p개 + 선형 (최소제곱), seed 5개 평균. 오류율 p 100 → 20%, 200 → 83%, 4000 → 10%. 화면의 숫자 그림 5개 = optdigits.tra 앞쪽 이미지
- 이름과 역사 (캡션): Belkin et al. (2019) PNAS 'Reconciling modern machine-learning practice and the classical bias–variance trade-off' 가 double descent 이름을 붙임. 해석 반론: Curth et al. (2023) NeurIPS 'A U-turn on Double Descent'
- 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (사용자 생성)
