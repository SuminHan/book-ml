# AlexNet 이야기

*딥러닝 시대를 연 2012년*

> 2012년, 딥러닝 시대를 연 AlexNet 이야기 🏆

## 영상 내용

- 이미지 인식 대회 오류율: 1위 AlexNet 15.3% vs 2위 26.2%
- 예전엔 사람이 규칙을 만들었지만(귀가 뾰족하고 수염이 있으면 고양이), AlexNet은 사진만 보고 스스로 배웠다

- 비결 셋
- ① 데이터: 페이페이 리(Fei-Fei Li, 스탠퍼드 교수) 팀의 ImageNet, 사진 120만 장 · 1000개 카테고리
- ② 계산력: 엔비디아 게임용 그래픽카드 GTX 580 두 장, 5~6일 학습 (당시 엔비디아 주가 약 400원, 액면분할 반영)
- ③ 사람: 토론토 대학교 크리제프스키(제1저자) · 수츠케버 · 힌턴 교수
- 구조: 합성곱 5층 + 완전연결 3층, 파라미터 약 6천만 개, GPU 2장에 나눠 학습

- 수츠케버는 훗날 OpenAI를 공동 창업한 'ChatGPT의 아버지'가 되었고,
- 스승 힌턴은 2024년 노벨 물리학상을 받았어요.
