# 그래프과녁맞히기

*Gradient Descent*

> 경사하강법 Gradient Descent, 함수 그래프로 과녁을 맞히는 게임에서 AI가 맞히는 법을 어떻게 배우는지 직접 돌려 봤어요

## 영상 내용

- Graphwar는 함수 식을 써 넣으면 총알이 그 그래프를 따라 날아가 상대를 맞히는 게임이에요. 저도 비슷한 게임을 만들어 직접 쏴 봤어요. S자 곡선 하나로 벽을 넘고, 하나를 빼서 한 번 더 꺾으니 명중. 이번엔 AI에게 S자 곡선 3개를 주고 숫자를 스스로 고르게 했어요
- 대포는 원점에 있고, 총알은 함수 그래프를 따라 날아가요. 벽에 닿으면 막힘, 과녁에 닿으면 명중이에요
- AI의 함수는 S자 곡선(sigmoid) 3개를 더한 거예요. 곡선 하나가 신경망의 뉴런 하나고, 높이 · 가파름 · 위치 숫자가 모두 9개예요
- 먼저 얼마나 틀렸는지 숫자 하나로 매겨요. 손실 = (과녁 높이와의 차이)² + 10 × (벽에 파고든 깊이)². 처음 랜덤 AI는 손실 129, 벽에 막혔어요
- 숫자 하나만 보면: 높이 a를 아주 조금(0.0001) 올려 다시 재니 손실이 줄었어요(기울기 −55). 그럼 a를 올리는 쪽이 내리막이에요. 그쪽으로 조금씩 옮기니 6번 만에 명중
- 실제로는 숫자 9개를 하나씩 이렇게 재 보고 한꺼번에 고쳐요. 반복할수록 손실이 줄어 34번째에 명중했어요
- 이렇게 손실이 줄어드는 내리막으로 조금씩 내려가는 게 경사하강법이에요. 맵 12개에서 맵마다 처음부터 학습하니 11개 명중, The Wall 맵만 막혔어요

**참고**: Graphwar를 본떠 직접 만든 게임(Graph Shooter)과 학습 코드로 돌린 값이에요. 뉴런 = sigmoid 3개, 시드 1, 학습률 0.01. 실제 딥러닝은 숫자를 하나씩 바꿔 보는 대신 역전파로 기울기를 한 번에 구해요. 앞부분 Graphwar 플레이 화면: youtu.be/We4mI_a1WhI. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 게임: KSA CS2 (2026-2) L13 "Graph Shooter" 수업 게임 (Graphwar 를 본뜬 수업용 게임, 직접 만든 코드). src/game_levels.py = 수업 L13_game.py 복사, src/gs.py = 수업 엔진 (touchesCircle · shoot) + L13_AI.py 의 network · loss · train 과 같은 코드.
  - 대포 원점 (0, 0), 총알 = 함수 그래프 f(x) − f(0), 화면 0 ≤ x ≤ 20 · −10 ≤ y ≤ 10. 판정 HIT · MISS · BLOCKED · OUT (원마다 점 10개).
  - 맵 = Step Up (LEVELS[5]): 벽 (5, 4.8, r 4.2) · (12.5, −0.5, r 3.5), 과녁 (18, 7, r 0.7).
  - 손실 = (과녁 높이와의 차이)² + 10 × Σ (반지름 1.1배 안으로 파고든 깊이)² + 10 × (화면 밖 정도), 막혀도 그래프를 끝까지 그려서 잼.
  - 숫자 하나 (슬라이드 37~38): 총알 = a · sigmoid(1.5(x − 10)), h 0.0001, 학습률 0.08: a 1 → 손실 90.73, 기울기 −55.4 → a 5.43 → … 6번째 a 6.35 명중.
  - 신경망: sigmoid 뉴런 3개 (수업 코드는 6개, 쇼츠는 3개로 줄임 · 높이 a · 가파름 w · 위치 c, 숫자 9개), 시드 1 랜덤 시작, 학습률 0.01, 800번. 손실 129 (막힘) → 4번째 빗나감 → 34번째 명중 (손실 0.61). 맵 12개 결과는 6개일 때와 같음 (11개 명중, The Wall 만 막힘). 시드 2 · 5 는 맵 6개만 명중 — 시드에 따라 다름.
  - 사람이 직접 쏘기: f = 9·S(2(x−10)) → 빗나감, − 2·S(2(x−15)) 더해 명중 (data.HUMAN).
  - 첫 장면 Graphwar 식 = 클립 입력창 (00:27)에 쓰인 식 그대로.
  - 맵 12개 (LEVELS 1~8 + randomLevel 1~4), 맵마다 처음부터 같은 설정으로 학습: 11개 명중, The Wall 만 막힘 (수업 슬라이드 40과 같음).
- s1 뉴런 6개 그림 = 시드 1 처음 숫자의 모양 (칸마다 크기를 맞춰 모양만 보여 줌).
- 영감: Graphwar (youtu.be/We4mI_a1WhI). 첫 장면(gw)만 이 영상의 플레이 화면 일부(3.3~14.6초, 판 부분만 잘라 1.4배속, 소리 없음, src/assets/graphwar_clip.mp4, 사용자 제공) — 나머지 화면은 수업 게임을 직접 그림. 출처는 캡션에.
