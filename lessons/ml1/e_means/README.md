# e-means

*k-means보다 빠른 군집*

> e-means, Meta FAIR 연구진이 2026년 11월에 낸 k-means 대체 군집 알고리즘. 데이터를 다 본 뒤 한 번 옮기는 대신, 조금 보고 자주 옮겨요

## 영상 내용

- k-means(Lloyd)는 한 번 옮길 때마다 데이터 전체를 봐야 하고, 보통 이걸 25바퀴 반복해요
- k-means는 점마다 모든 중심까지 거리를 재서 가장 가까운 중심에 붙여요. 9만 개를 전부 이렇게 나눈 뒤에야 중심이 한 번 움직여요
- e-means는 작은 묶음(이번 실험 512개)만 꺼내 그 점들만 거리를 재고, 바로 중심을 옮겨요. 그래서 한 바퀴에 182번 움직여요. 실제 첫 세 묶음에서 중심이 움직인 거리는 평균 1.14 → 0.65 → 0.31로 줄었어요
- 얼마나 옮길지는 이동 평균(EMA)으로 정해요. 지금까지 쌓인 평균에 이번 묶음을 처음엔 약 10%만 섞고, 점점 줄여요. 이 비율과 묶음 크기는 점 수와 중심 수로 정하는 공식(스케일링 법칙)이 알아서 정해요
- 직접 돌려 봤어요 (Faiss 1.16의 e-means 코드 그대로, 2차원 점 93,126개 · 중심 200개, 같은 무작위 시작). e-means는 0.1바퀴 만에 손실 2.75로 k-means 1바퀴(3.53)보다 낮았고, 3바퀴에 2.28로 k-means 25바퀴(2.32)보다도 낮았어요. 시작을 5번 바꿔도 5번 모두 그랬어요
- 논문에선 이미지 특징 100억 개를 1,600만 묶음으로 2.5바퀴에 나눴고, k-means 25바퀴의 손실을 1.4~2.6바퀴에 넘어서 GPU에서 10~45배 빨랐다고 해요 (저자들이 잰 값)

**참고**: 손실 = 점마다 가장 가까운 중심까지 거리 제곱의 평균 (화면 숫자는 좌표를 10배 해서 100배한 값). 화면의 점은 93,126개 중 2,500개, 돋보기는 지도 한 구역의 중심 6개와 그 점들, 주황 점은 실제 첫 묶음. 실험 코드: Faiss faiss.contrib.e_means.NumpyEmeans (pip faiss-cpu 1.16.0). 출처: Bessa et al. (2026) "e-means: outperforming k-means (in one-tenth the epochs)" (arXiv 2611.09501), e-means.github.io. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드 없음 (쇼츠 전용, ML1 k-means 차시 보조).
- 논문: Bessa, Mazaré, Szilvasy, Touvron, Picard, Douze, Jégou, "e-means: outperforming k-means (in one-tenth the epochs)", arXiv 2611.09501 (2026-11-06, FAIR at Meta · École des Ponts). 초록·HTML·e-means.github.io 확인 2026-11-12.
  - 초록: "it beats the loss of Lloyd k-means at 25 epochs in 1.4 to 2.6 epochs, which translates to 10-45x GPU wall-clock speedups"
  - 초록: "partitions DINO10B, a dataset of 10 billion DINO embeddings, into 16 million clusters in only 2.5 epochs"
  - 방법: 묶음마다 개수 N_j · 합 S_j 를 이동 평균 (Eq. 2), 걸음 α 코사인으로 α0 → 0.1α0 (Eq. 5), α0 · 묶음 크기 B 는 스케일링 법칙 (Eq. 6 · 7), 죽은 중심은 큰 묶음을 쪼개 되살림 (영상엔 안 넣음).
- 직접 실험 (src/sim.py → src/sim.json, data.py 에 assert): Faiss 1.16.0 (pip faiss-cpu) `faiss.contrib.e_means.NumpyEmeans` 기본 설정 그대로.
  - 데이터: 2차원 가우시안 5개를 ±3 상자로 자른 93,126개 (블로그 첫 그림을 흉내 낸 합성 데이터), k = 200, 두 방법 같은 무작위 시작, 시드 0~4.
  - k-means = 직접 짠 Lloyd 25바퀴 (Faiss 기본 niter 25 와 같은 횟수).
  - e-means 3바퀴: 묶음 512개 · 한 바퀴 이동 182번 · α0 ≈ 0.10 (공식이 정함). 손실(×100) 3바퀴 2.28 vs k-means 25바퀴 2.32, 시드 5개 모두 e-means 3바퀴가 더 낮음 (2바퀴는 4개).
  - 시간은 이 2차원 CPU 실험에선 재지 않음 (영상의 10~45배는 논문 값).
- 화면의 점은 93,126개 중 무작위 2,500개. 돋보기 = 데이터 구역 (17.4, −1.6) ± 7 의 시작 중심 6개와 거기 붙는 화면 점 94개, 거리 숫자는 실제 거리 (×10 좌표).
- e-means 주황 점 = 실제 첫 묶음 512개 (sim.py 가 train() 과 같은 순서로 다시 꺼내 첫 이동 = 묶음 평균으로 확인), 돋보기 안은 그중 6개 중심에 붙은 18 · 17 · 28개, 중심 이동 뒤 위치도 실제 실행 값 (평균 이동 1.14 → 0.65 → 0.31).
- 음성: Typecast 필재. 배경음: Suno "Curious Groove".
