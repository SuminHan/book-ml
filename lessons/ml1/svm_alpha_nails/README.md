# SVM알파와못과스프링

*Lagrange multiplier α*

> SVM의 라그랑주 승수(Lagrange multiplier) α, 못 박힌 판 위에서 스프링이 두 자를 최대한 벌리는 그림으로 보면 서포트 벡터만 남는 이유가 보여요

## 영상 내용

- 빨강 파랑 못이 박힌 판에 자 두 개, 가운데 스프링이 두 자를 밀어 벌리고, 못에 걸리면 이리저리 돌며 더 벌어지는 자리를 찾아요. 두 자 사이 = SVM의 가장 넓은 길. 끝까지 벌리면 자에 닿은 못은 20개 중 3개뿐이에요
- 넓은 길 = ½‖w‖² 최소, 단 모든 점은 길 밖 (y_k D(x_k) ≥ 1). 라그랑주 방법은 조건마다 α_k 를 붙여 L = ½‖w‖² − Σ α_k [y_k D(x_k) − 1] 하나로 만들어요
- 비유: 점 = 못, 길 양쪽 = 자, 스프링 = 길을 넓히려는 힘(½‖w‖² 최소), α = 못이 자를 붙잡는 힘
- 학습 α_k ← max(0, α_k + η(1 − y_k D(x_k))): 처음엔 α 가 모두 0이라 스프링이 길을 끝없이 밀어내요. 스프링은 계속 밀지만, 길 안에 있는 못은 α 가 커지고, α 만큼 자를 당기니까 길이 좁아져요
- 길 밖으로 나간 못은 α 가 줄어 0, 더는 안 당겨요. 2000걸음 뒤엔 자에 닿은 못 3개만 α = 1.11 · 0.55 · 0.55, 양쪽 힘이 같아서(1.11 = 0.55 + 0.55) 멈춰요
- α = 0 인 못 17개는 뽑아도 길이 그대로. 남은 3개가 서포트 벡터예요

**참고**: 점 20개는 수업 예시 데이터, α 는 위 식으로 직접 학습한 값 (η = 0.01, sklearn SVC 와 같은 서포트 벡터·w). 힘 비유는 Burges (1998) SVM 튜토리얼. 음성: Typecast (필재) · 배경음: Suno "Curious Groove" (직접 제작)

## 출처

- 슬라이드: slides/ml1/week02/9_svm_extra 'α 로 학습' · '왜 서포트 벡터만 남나: 고무줄' · '비유: 못 박힌 판 위에서 벌어지는 두 자' · '역학으로 보면' 쪽과 같은 점 20개 · 같은 학습 식.
- 점 20개: 덱 2_svm/data.py RED_PTS · BLUE_PTS (표준화한 예시 데이터). 서포트 벡터 (0.7, 0.2) · (−0.6, −0.4) · (0.1, −1.1) 은 sklearn SVC 와 같음 (src/data.py assert).
- 라그랑주 식: Cortes · Vapnik (1995) Support-vector networks 의 L = ½‖w‖² − Σ α_k [y_k D(x_k) − 1].
- α 학습 (src/data.py): J(α, b) 를 조금씩 키우는 두 줄 α_k ← max(0, α_k + η(1 − y_k D(x_k))), b ← b + η Σ α_k y_k. 덱은 η = 0.05 · 500걸음, 영상은 길이 매끈하게 좁아지도록 η = 0.01 · 2000걸음 (끝 α 같음: 1.11 · 0.55 · 0.55, 나머지 17개 0, 길 폭 1.34). 화면의 걸음 수는 로그 시간으로 재생.
- 비유: 못 = 점, 자 = 길 가장자리, 스프링 = ½‖w‖² 최소 (길 넓히기), α = 못이 자를 붙잡는 힘 — 힘의 비유는 Burges (1998) A Tutorial on Support Vector Machines for Pattern Recognition 의 역학 해석.
- 음성: Typecast 필재. 배경음: Suno "Curious Groove".
