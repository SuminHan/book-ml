# PR-AUC

*쏠린 데이터엔 정밀도 기준으로*

> PR-AUC(Precision-Recall AUC): 쏠린 데이터에서는 ROC-AUC가 너무 좋게 나올 수 있어요. 같은 AI가 ROC-AUC 0.98, PR-AUC 0.85인 이유를 학교 100명 중 독감 10명 예시로 정리했어요.

## 영상 내용

- 독감 10명, 건강 90명처럼 쏠린 데이터에서는 ROC-AUC 0.98도 너무 좋게 보일 수 있어요
- 커트라인 50점에서 헛짚은 학생 4명
- - ROC 방식: 건강한 90명으로 나눠 4% → 작아 보여요
- - PR 방식: AI가 독감이라고 한 12명으로 나눠 4명 틀림 → 정밀도 67%
- PR 곡선: 가로 재현율(놓치지 않았나), 세로 정밀도(AI 말이 맞았나). 커트라인을 내리며 찍은 점들
- PR-AUC = PR 곡선 아래 넓이 = 0.85 (Average Precision). 같은 AI의 ROC-AUC 0.98보다 엄격해요
- 기준선도 달라요: 아무 구분 못 하는 찍기 AI는 ROC-AUC 0.5, PR-AUC는 독감 비율인 0.1
- 정리: ROC는 건강한 학생 기준이라 너그럽고, PR은 AI 말 기준이라 엄격 → 쏠린 데이터엔 PR-AUC도 같이 보기

**참고**: 100명·독감 10명과 점수는 설명을 위한 예시 데이터예요. 모든 수치는 그 예시에서 직접 계산했어요.
