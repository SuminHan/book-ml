# 페이지랭크

*링크를 추천으로 보는 중요도*

> 페이지랭크(PageRank), 논문 인용에서 시작된 구글 검색

## 영상 내용

- 스탠퍼드 대학원생이던 래리 페이지와 세르게이 브린은 구글(Google)을 세웠고, 웹페이지 순위의 힌트를 논문 인용 네트워크에서 찾았어요.

- • 인용 한 번 = 추천 한 표.
- • 그런데 표의 무게가 달라요. 인기 논문의 표는 무겁고, 여러 논문을 인용하면 표가 나눠져요.
- • 중요도 = 참고문헌을 따라 무작위로 읽어 가는 사람이 각 논문에 머무는 비율. 막히거나 가끔(15%) 지루하면 아무 논문이나 새로 펼쳐요(랜덤 점프, 감쇠 계수 0.85).
- • 예시에서 E는 인용이 1번뿐이지만 인기 논문 A(인용 4번)가 인용해서 1등, 무명 논문의 표만 3개 모은 C는 3등이에요.
- • 웹에선 논문 대신 페이지, 인용 대신 링크. 이름은 래리 페이지(Larry Page)에서 따왔어요. 오늘날 구글 검색은 이 밖에도 수많은 신호를 함께 써요.

- 참고: S. Brin & L. Page, "The Anatomy of a Large-Scale Hypertextual Web Search Engine" (1998)

**참고**: 논문 7편과 인용 관계는 설명용 예시, 점수는 실제 계산값

|---|---|---|
| 1 | 구글을 세운 두 대학원생 / 힌트는 논문 인용 네트워크 | 스탠퍼드 대학원생이던 래리 페이지와 세르게이 브린, 이 둘이 구글을 세웠어요. 웹페이지 순위의 힌트는, 논문 인용 네트워크에서 찾았죠. |
| 2 | 인용 한 번 = 추천 한 표 / A 4표 · C 3표 · E 1표 | 인용 한 번은 추천 한 표. A는 네 표, C는 세 표, E는 한 표예요. |
| 3 | 인기 논문의 표는 무겁고 / 여럿을 인용하면 표가 나눠진다 | 그런데 인기 논문의 표는 무겁고, 여럿을 인용하면 표가 나눠져요. |
| 4 | 참고문헌을 따라 / 무작위로 읽어 가는 사람 | 참고문헌을 따라 무작위로 논문을 읽어 가는 사람을 떠올려 봐요. |
| 5 | 막히거나 지루하면 아무 논문이나 펼침 (15%) / 오래 머무는 논문 = 중요한 논문 | 막히거나 지루하면 아무 논문이나 새로 펼쳐요. 이렇게 계속 읽다 보면, 오래 머무는 논문일수록 중요해요. |
| 6 | E는 인용 1번인데 1등 (A가 인용) / C는 3번인데 3등 | 결과는 E가 1등! 인용은 한 번뿐이지만, 인기 논문 A가 인용했거든요. C는 3등. |
| 7 | 논문 → 웹페이지, 인용 → 링크 / PageRank, 구글 검색의 출발점 | 웹에선 논문 대신 페이지, 인용 대신 링크. 래리 페이지의 이름을 딴 페이지랭크, 구글 검색의 바탕이 됐어요. |
| 8 | 인용·링크 = 추천 · 중요한 추천은 무겁다 / 점수 = 무작위로 따라가며 머무는 비율 | 인용과 링크는 추천, 중요한 추천은 더 무겁고, 점수는 무작위로 따라가며 머무는 비율이에요. |
