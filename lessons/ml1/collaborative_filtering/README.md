# 협업 필터링

*별점만으로 추천하기*

> 협업 필터링(Collaborative Filtering), 오디세이 본 사람에게 뭘 추천할까?

## 영상 내용

- 2003년 Amazon이 공개한 추천 방법은 "이걸 산 사람이 함께 산 상품"이에요. 비슷한 사람 대신 함께 소비된 상품끼리 묶는, 아이템 기반 협업 필터링이죠. (Smith, Linden, York, IEEE Internet Computing, 2003)

- • 오디세이를 본 관객 10명 중 같이 본 비율: 스파이더맨 80%, 옵세션 60%
- • 그런데 스파이더맨은 원래 20명 중 16명(80%)이 본 인기작이에요. 오디세이와 상관없이 다들 본 거죠.
- • 반면 옵세션은 20명 중 6명(30%)만 봤어요. 그런데 오디세이 관객 중에서는 60%가 봤죠.
- • 원래 본 비율로 나누면 스파이더맨 80÷80 = 1배, 옵세션 60÷30 = 2배 → 오디세이 관객에게 특별히 끌리는 영화는 옵세션!
- • 실제 서비스에서는 코사인 유사도 같은 방법으로 이런 인기작 효과를 보정해요(이 예시에서도 순위가 같아요).
- • 모든 영화 쌍의 배수 표를 미리 만들어 두면, 무엇을 봤든 바로 추천할 수 있어요 (예: 토이 스토리 5 → 도라에몽 1.5배).

**참고**: 관람 기록은 설명용 예시 데이터, 비율·배수는 실제 계산값이에요.
