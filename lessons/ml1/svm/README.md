# 서포트 벡터 머신

*가장 넓은 길을 내는 분류기*

> SVM(Support Vector Machine), 가장 넓은 길을 내는 분류기

## 영상 내용

- 빨간 점과 파란 점을 가르는 직선은 무수히 많아요. 하지만 점에 바짝 붙은 선은 새 점이 조금만 비껴 와도 틀리죠. 서포트 벡터 머신(SVM, Support Vector Machine)은 양쪽에서 가장 멀리 떨어진 선, 즉 가장 넓은 길을 골라요.

- • 길의 폭 = 마진(margin). SVM은 마진이 최대가 되는 선을 찾아요.
- • 길 가장자리에 닿은 점(서포트 벡터) 몇 개만 선을 결정해요. 멀리 있는 점은 옮겨도 선은 그대로예요.
- • 직선으로 못 가르는 데이터는 가운데서 떨어진 거리²를 높이로 주면 평면 하나로 갈라져요. 내려다보면 경계는 원이에요.
- • 높은 차원으로 실제로 옮기지 않고 이 계산을 해 주는 요령이 커널 트릭이에요.
- • 정리: 마진이 가장 넓은 선을 찾고, 그 선은 서포트 벡터가 정하고, 직선이 안 되면 커널로 휘어진 경계를 만들어요.
