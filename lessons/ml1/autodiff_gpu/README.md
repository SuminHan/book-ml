# 자동미분과 GPU

*loss.backward() 한 줄의 비밀*

> loss.backward() 한 줄, 미분은 누가 했을까? ⚙️

## 영상 내용

- 기호 미분 ✕ · 수치 미분 ✕ → 자동 미분 ✓
- ① 순전파 때 ×, +, σ 같은 작은 연산을 계산 그래프로 기록
- ② 각 연산은 자기 미분 규칙만 안다 (×: 상대편 값, σ: σ(1−σ))
- ReLU의 미분은 계단(양수 1, 음수 0) → grad = grad_out * (x > 0)
- ③ backward = 그래프를 거꾸로 따라가며 연쇄법칙으로 곱하기 → ∂L/∂w = −0.212 (수치 미분과 일치)

- 실제 연산은 대부분 행렬 곱: ∂L/∂W = Xᵀ·∂L/∂Y
- 행렬 곱의 각 칸은 독립 → GPU 수천 개 코어가 동시에 계산
- 배치로 묶으면 행렬이 커져 GPU를 꽉 채운다

| 1 | backward() 한 줄 / 미분은 누가 했을까? | backward 한 줄이면 기울기가 전부 나와요. 미분은 누가 했을까요? |
| 2 | 기호 미분 ✕ · 수치 미분 ✕ / 자동 미분 ✓ | 손으로 미분하지도, 값을 조금씩 바꿔 보지도 않아요. 자동미분이에요. |
| 3 | 순전파 = 작은 연산들을 / 계산 그래프로 기록 | 순전파 때 곱하기, 더하기 같은 작은 연산을 그래프로 기록해요. |
| 4 | 각 연산은 자기 미분 규칙만 안다 | 각 연산은 자기 미분 규칙 하나만 알아요. |
| 5 | ReLU의 미분 = 계단 (0 또는 1) / 기억해 둔 마스크를 곱한다 | ReLU도 간단해요. 미분이 양수면 1, 음수면 0인 계단이라, 기억해 둔 마스크를 곱하면 끝이에요. |
| 6 | 그래프를 거꾸로 따라가며 곱한다 / = 역전파 | backward는 그래프를 거꾸로 따라가며 규칙을 곱해요. 결과는 수치미분과 똑같죠. |
| 7 | 순전파도 역전파도 / 대부분 행렬 곱 | 실제 연산은 대부분 행렬 곱이고, 역전파의 기울기도 행렬 곱이에요. |
| 8 | 각 칸은 독립 / GPU는 모든 칸을 동시에 | 행렬 곱의 각 칸은 서로 독립이라, GPU는 수천 개 코어로 모든 칸을 동시에 계산해요. |
| 9 | 배치로 묶어 큰 행렬로 / → GPU를 꽉 채운다 | 데이터를 배치로 묶으면 행렬이 커져서 GPU를 꽉 채워요. |
| 10 | backward() 한 줄의 비밀 | 작은 규칙, 거꾸로 연쇄법칙, GPU 행렬 곱. 이게 backward의 비밀이에요. |
