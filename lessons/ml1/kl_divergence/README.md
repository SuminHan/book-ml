# KL 발산

*KL Divergence · 교차 엔트로피 · 엔트로피*

> KL 발산(Kullback-Leibler Divergence)은 두 확률 분포가 얼마나 다른지, 틀린 확률을 믿어서 더 놀란 만큼을 재는 숫자예요.

## 영상 내용

- 게임 뽑기 공지 확률 당첨 20%, 실제는 4%라면 당첨까지 평균 5번이 아니라 25번, 돈이 5배
- 놀라움(정보량) I = −log₂(확률): 실제 확률로 재면 당첨 4.64 · 꽝 0.06, 공지 확률로 재면 2.32 · 0.32
- 엔트로피: 실제 확률로 잰 놀라움을 실제 비율로 평균, 4.64×0.04 + 0.06×0.96 = 0.24
- 교차 엔트로피: 놀라움은 공지 확률로 재고 평균은 실제 비율로, 2.32×0.04 + 0.32×0.96 = 0.40
- 그 차이 0.40 − 0.24 = 0.16이 KL 발산. 공지와 실제가 같으면 0, 멀어질수록 커지고 거리와 달리 대칭은 아니에요
- 분류 AI의 교차 엔트로피 손실은 정답과의 KL이고(70% → 95%: 0.51 → 0.07), 챗GPT 같은 RLHF 학습은 원래 모델과의 KL에 벌점을 줘 보상 해킹을 막아요

**참고**: 뽑기 확률과 분류 확률은 설명용 예시(실제 게임 아님)이고, 단위는 비트(log₂)로 직접 계산했어요. 이모지: Twemoji (CC BY 4.0)
