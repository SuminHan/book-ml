# 임베딩

*분류기 출력이 못 보는 것을 벡터 거리로 본다*

> 임베딩(Embedding)이 무엇인지, 고양이·개 분류 CNN의 은닉층 벡터로 직접 확인해 봐요.

## 영상 내용

- CIFAR-10의 고양이·개 사진 1만 장으로 작은 CNN을 학습시켰어요. 출력은 고양이, 개 두 개뿐이에요.

- • 출력층만 보면 처음 보는 호랑이는 평균 81% 고양이, 오렌지도 70% 고양이라고 답해요. 분류기는 둘 중 하나만 고를 수 있으니까요.
- • 출력 직전 은닉층을 꺼내면 사진 한 장이 숫자 64개짜리 벡터가 돼요. 이게 임베딩이에요. 이 공간에서 고양이는 고양이끼리, 개는 개끼리 뭉쳐요.
- • 호랑이 사진(CIFAR-100)은 85%가 고양이 무리 쪽에 찍혀요.
- • 오렌지는 무리 평균 퍼짐의 41배 떨어진 곳에 찍혀요. CIFAR-100 100종 가운데 가장 멀어요. 출력은 고양이라 했지만, 거리는 처음 보는 입력이라는 걸 알려 줘요.
- • 그래서 임베딩은 거리(유클리드 거리, 코사인 유사도)로 써요. 가까운 걸 찾으면 검색·추천, 멀리 떨어진 걸 찾으면 이상 탐지가 돼요.

**참고**: 직접 학습한 소규모 실험 결과예요(마지막 은닉층 64차원, 표준화 후 무리 중심까지 거리). 화면의 2차원 그림은 이해를 돕기 위해 단순화했어요.
- 데이터: CIFAR-10 / CIFAR-100 (A. Krizhevsky, 2009)

## 장면별 자막과 대사

| # | 화면 자막 | 대사 |
|---|---|---|
| 1 | 고양이·개만 배운 신경망에 / 호랑이와 오렌지를 넣으면? | 고양이와 개만 배운 신경망에, 호랑이와 오렌지를 넣으면 뭐라고 할까요? |
| 2 | CIFAR-10 고양이·개 1만 장으로 학습 / 출력은 2개뿐 | 시파 텐 고양이, 개 사진 만 장으로 작은 씨엔엔을 학습시켰어요. 출력은 둘뿐이에요. |
| 3 | 호랑이 → 고양이 81% / 오렌지도 → 고양이 70%?! | 호랑이는 81퍼센트 고양이. 그런데 오렌지도 70퍼센트 고양이래요. |
| 4 | 출력 직전 은닉층 = 64차원 벡터 / = 임베딩 | 출력 직전 은닉층을 꺼내면, 사진 한 장이 숫자 64개짜리 벡터가 돼요. 이게 임베딩이에요. |
| 5 | 벡터 공간에서 / 같은 종류끼리 뭉친다 | 이 공간에서 고양이는 고양이끼리, 개는 개끼리 뭉쳐요. |
| 6 | 호랑이: 85%가 / 고양이 무리 쪽 | 호랑이는 85퍼센트가 고양이 쪽에 찍혀요. |
| 7 | 오렌지: 무리 크기의 41배 바깥 / 출력은 고양이, 거리는 처음 본 것 | 오렌지는 무리 크기의 41배, 백 가지 종류 중 가장 먼 곳에 찍혀요. 출력은 고양이라 했지만, 거리는 처음 보는 거라고 말해 줘요. |
| 8 | 가까움 = 비슷함 / → 검색 · 추천 · 이상 탐지 | 그래서 임베딩은 거리로 써요. 가까운 걸 찾으면 검색, 추천, 이상 탐지가 돼요. |
| 9 | 임베딩 = 입력을 벡터 공간의 한 점으로 / 가까울수록 비슷하다 | 정리하면, 임베딩은 입력을 벡터 공간의 한 점으로 보낸 것. 가까울수록 비슷해요. |
