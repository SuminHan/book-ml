\section*{1. Course Description}

\subsection*{Course Objectives}
On completion of this course, you'll hopefully be able to:
\begin{itemize}[nosep]
\item Formalize a decision-making problem as a Markov Decision Process
  (MDP) and derive the Bellman equations.
\item Implement and compare tabular reinforcement learning algorithms:
  dynamic programming, Monte Carlo methods, and temporal-difference
  learning.
\item Understand and implement deep reinforcement learning methods that
  combine function approximation with neural networks (DQN, policy
  gradient methods, PPO).
\item Understand the principles behind modern applications such as
  imitation learning and RLHF (Reinforcement Learning from Human
  Feedback).
\item Apply reinforcement learning algorithms to a simulated environment
  as a team, following an honest experimental protocol (multiple seeds,
  baseline comparison).
\end{itemize}

\subsection*{Contents}
\begin{itemize}[nosep]
\item Introduction to reinforcement learning and a neural network review
\item Multi-armed bandits
\item Markov Decision Process (MDP) formalization
\item Dynamic programming
\item Monte Carlo methods
\item Temporal-difference learning
\item $n$-step bootstrapping, eligibility traces, and planning
\item \textbf{[Block A Capstone] Team project: tabular reinforcement
  learning}
\item Function approximation and DQN
\item Policy-based reinforcement learning
\item Advanced policy optimization: PPO
\item Imitation learning and RLHF
\item Robot simulation and control basics
\item Advanced simulation: MuJoCo and Isaac Sim
\item Model-based RL and Monte Carlo Tree Search (MCTS)
\item \textbf{[Block B Capstone] Team project: deep reinforcement
  learning}
\end{itemize}

\noindent {\small This course is a follow-up to ``Machine Learning \&
Deep Learning'' and assumes prior familiarity with neural networks.}

\begin{itemize}[nosep]
\item \textbf{Quizzes}: a short True/False quiz each week checking
  conceptual understanding of that week's material.
\item \textbf{Homework}: individual programming assignments implementing
  the reinforcement learning algorithms covered in class.
\item \textbf{Midterm / Final}: written exams covering the theory of
  Block A and Block B respectively.
\item \textbf{Team Project}: two capstone projects (Week 8: tabular RL,
  Week 16: deep RL), each graded on a written report, a presentation,
  and peer-review. The grading emphasizes the \emph{honesty of the
  experimental protocol} (seeds $\ge 3$, baseline comparison against a
  random policy, honest reporting of unstable results) over raw
  performance.
\item \textbf{Make-up exam}: available for officially approved absences
  (e.g. illness, out-of-school competition).
\item \textbf{Late-work policy}: not accepted unless officially approved.
\end{itemize}
