\section*{1. Course Description}

\subsection*{Course Objectives}
On completion of this course, you'll hopefully be able to:
\begin{itemize}[nosep]
\item Understand and implement classical supervised learning (regression,
  classification) and unsupervised learning (clustering, dimensionality
  reduction) methods.
\item Correctly apply model selection and validation principles
  (regularization, cross-validation) to real data.
\item Understand the training principle behind neural networks
  (backpropagation) and design/implement representative deep learning
  architectures such as CNNs, RNNs, and Transformers.
\item Understand the basic principles of generative models and large
  language models, and follow the current landscape of AI technology.
\item Carry out the full pipeline of a machine learning project --- problem
  definition, implementation, honest validation, and presentation --- as a
  team.
\end{itemize}

\subsection*{Contents}
\begin{itemize}[nosep]
\item Regression models (linear regression, logistic regression)
\item Generative-model view of classification (Naive Bayes, GDA)
\item Distance-based models and clustering (kNN, k-means, GMM/EM)
\item Support Vector Machines and kernels
\item Regularization and model selection (Lasso/Ridge, cross-validation)
\item Tree-based models (decision trees through GBDT)
\item \textbf{[Block A Capstone] Team project: classical machine learning}
\item Neural network basics, backpropagation, training techniques
\item Convolutional Neural Networks (CNNs)
\item Sequence models (RNNs)
\item Attention and Transformers
\item Graph representation learning (GNNs)
\item Representation learning (PCA, word2vec, embeddings)
\item Latent-variable generative models (VAE, GAN, Diffusion)
\item \textbf{[Block B Capstone] Team project: deep learning}
\end{itemize}

\begin{itemize}[nosep]
\item \textbf{Quizzes}: a short True/False quiz each week checking
  conceptual understanding of that week's material.
\item \textbf{Homework}: individual programming assignments implementing
  the algorithms covered in class.
\item \textbf{Midterm / Final}: written exams covering the theory of
  Block A and Block B respectively.
\item \textbf{Team Project}: two capstone projects (Week 8: classical ML,
  Week 16: deep learning), each graded on a written report, a
  presentation, and peer-review. The grading emphasizes the
  \emph{honesty of the experimental procedure} (baseline comparisons,
  proper train/validation/test separation, honest reporting of results)
  over raw performance.
\item \textbf{Make-up exam}: available for officially approved absences
  (e.g. illness, out-of-school competition).
\item \textbf{Late-work policy}: not accepted unless officially approved.
\end{itemize}
