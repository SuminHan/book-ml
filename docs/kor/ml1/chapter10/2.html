10.2 풀링과 전형적인 CNN 구조

풀링 (Pooling)

합성곱 다음에는 보통 풀링 층으로 공간 크기를 줄인다. 최대 풀링(max pooling)은 \(2\times2\) 영역마다 최댓값 하나만 남긴다 — 위치가 한두 칸 미세하게 움직여도 같은 최댓값이 뽑힐 가능성이 높아, 작은 이동에 둔감한(translation-invariant) 특징을 만든다. 풀링은 학습 파라미터가 없다 — 순수한 다운샘플링(downsampling) 연산이다.

CNN의 전형적인 구조: LeNet에서 ResNet까지

[합성곱 → 활성함수(ReLU) → 풀링]을 여러 번 쌓아 공간 크기는 줄이고 채널(특징) 수는 늘려가다가, 마지막에 완전연결층 한두 개를 붙여 분류 결과를 낸다. 1998년 얀 르쿤의 LeNet이 손글씨 숫자 인식에 처음 이 패턴을 성공적으로 적용한 이래(Chapter 4.2에서 만난 바로 그 LeNet이다), 얕은 층은 선/모서리 같은 저수준 패턴을, 깊은 층으로 갈수록 눈/코/바퀴 같은 고수준 패턴을 감지하도록 학습되는 이 계층 구조 자체는 지금도 그대로 유지된다 — 허블과 비셀이 관찰한, 단순 세포에서 복합 세포로 이어지는 계층 구조와 같은 원리다.

ResNet과 스킵 연결: 더 깊이 쌓을 수 있게

2015년, 마이크로소프트의 카이밍 허(Kaiming He) 등은 이상한 현상을 발견했다 — CNN을 더 깊게 쌓을수록 성능이 좋아질 줄 알았는데, 어느 지점을 넘어서면 오히려 더 나빠졌다. 이건 과적합 때문이 아니었다(학습 데이터에 대한 성능조차 나빠졌다) — 층을 더해도 그래디언트가 온전히 전달되지 못해, 깊은 층이 사실상 “학습이 안 되는” 문제였다(Chapter 9의 그래디언트 소실이 CNN에서도 그대로 재발한 것이다). 그들의 해법 ResNet(Residual Network)은 놀랍도록 단순했고, 지금 쓰이는 거의 모든 대형 CNN·Transformer 구조의 기본 재료가 됐다.

스킵 연결(skip connection, residual connection)은 이 곱셈 사슬에 지름길을 낸다 — 한 블록의 출력을 그냥 \(F(x)\)로 두는 대신, 입력을 그대로 더한 \(y = F(x) + x\)로 정의한다:

def residual_block(x, F):
    # F: 합성곱 층 몇 개로 이루어진 함수(예: Conv-ReLU-Conv)
    return [F(x)[i] + x[i] for i in range(len(x))]  # F(x) + x

왜 이게 그래디언트를 살리는가(직관): \(y=F(x)+x\)를 \(x\)로 미분하면 \(\frac{\partial y}{\partial x} = \frac{\partial F}{\partial x}

  • 1\)이다. Chapter 9의 \(\prod_l \sigma’(z_l) \cdot W_l\) 곱셈 사슬에서 \(\frac{\partial F}{\partial x}\)가 아무리 작아져도(그래디언트 소실), 더해진 “+1” 항 덕분에 그래디언트가 최소한 1은 유지된 채로 그대로 전달될 길이 남는다 — 입력을 “건너뛰어” 뒤쪽 층으로 그대로 흘려보내는 지름길이 있는 셈이다. 이 아이디어 덕분에 100층이 넘는 CNN도 안정적으로 학습할 수 있게 됐고, Chapter 12에서 배울 Transformer 구조에도 (다른 형태로) 그대로 쓰인다.

실습: PyTorch로 작은 CNN을 만들어 패턴 분류하기

세로줄과 가로줄 이미지(16×16, 잡음 섞임)를 구분하는 아주 작은 CNN을 직접 학습시켜보자:

import torch, torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1, 8, 3, padding=1)
        self.conv2 = nn.Conv2d(8, 16, 3, padding=1)
        self.pool = nn.MaxPool2d(2)
        self.fc = nn.Linear(16*4*4, 2)
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = self.pool(torch.relu(self.conv2(x)))
        x = x.view(x.size(0), -1)
        return self.fc(x)

model = SmallCNN()
opt = torch.optim.Adam(model.parameters(), lr=0.01)
lossfn = nn.CrossEntropyLoss()
# 학습 루프: opt.zero_grad() -> loss = lossfn(model(X), y) -> loss.backward() -> opt.step()

학습 전(무작위 초기화)에는 검증 정확도가 52%(동전 던지기 수준)였지만, 30 에폭 학습 후에는 train 정확도 100%, val 정확도 100%에 도달한다 (스크래치패드에서 실행 검증) — 합성곱 층 두 개와 풀링만으로 “세로줄 vs 가로줄“이라는 위치·잡음에 무관한 패턴을 완벽하게 구분해낸 것이다.

자주 묻는 질문

Q. 왜 풀링 다음에도 계속 합성곱을 쌓나요? 풀링 한 번으로는 부족한가요? 풀링 하나는 공간 크기를 절반으로 줄일 뿐, 감지하는 패턴의 복잡도 자체를 높이지는 않는다. [합성곱→풀링]을 반복해서 쌓아야, 뒤쪽 층의 뉴런 하나가 원본 이미지에서 점점 더 넓은 영역(수용장)을 “보게” 되고, 그 넓어진 수용장 위에서 더 복잡한 패턴(눈, 바퀴 같은 고수준 특징)을 조합해 감지할 수 있게 된다.

Q. ResNet의 “+1“이 그래디언트 폭발을 일으키지는 않나요? 스킵 연결이 매 블록마다 그래디언트에 곱이 아니라 덧셈으로 기여하기 때문에, Chapter 9.2에서 본 “곱이 지수적으로 커지는” 폭발 메커니즘과는 다르다 — 오히려 스킵 연결은 그래디언트가 여러 경로(직접 지름길 + 블록을 통과하는 경로)의 합으로 전달되게 해서 신호를 더 고르게 유지해주는 쪽에 가깝다. 실제로 매우 깊은 ResNet도 적절한 초기화·정규화와 함께 쓰면 그래디언트 폭발 없이 안정적으로 학습된다.
