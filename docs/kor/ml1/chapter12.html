Chapter 12. 생성형 모델 맛보기와 총정리 (Generative Models Preview & Review)

2006년, 제프리 힌턴(Geoffrey Hinton)과 루슬란 살라쿠트디노프(Ruslan Salakhutdinov)는 신경망으로 PCA보다 훨씬 유연한 방식의 차원축소를 할 수 있음을 보였다. 핵심 아이디어는 간단하다: 입력을 압축했다가 다시 원본으로 복원하도록 신경망을 학습시키되, 중간에 병목(bottleneck) — 원본보다 훨씬 좁은 은닉층 — 을 강제로 통과시킨다. 신경망이 병목을 통과하고도 원본을 복원해낸다면, 그 병목의 값이 원본 정보를 압축한 유용한 표현이라는 뜻이다. 이 구조가 오토인코더(Autoencoder)다.

12.1 오토인코더의 구조

두 부분으로 이루어진다:

  • 인코더(Encoder) \(f\): 입력 \(x\)를 저차원 잠재 표현(latent representation) \(z = f(x)\)로 압축.
  • 디코더(Decoder) \(g\): \(z\)로부터 원본을 복원 \(\hat{x} = g(z)\).

손실함수는 복원 오차(reconstruction error), 보통 평균제곱오차를 쓴다:

\[J = \frac{1}{m}\sum_{i=1}^m |x^{(i)} - g(f(x^{(i)}))|^2\]

def autoencoder_forward(x, encoder_weights, decoder_weights):
    z = apply_layer(x, encoder_weights)   # 압축: 입력보다 좁은 은닉층
    x_hat = apply_layer(z, decoder_weights)  # 복원: 다시 원본 차원으로
    return x_hat, z

12.2 왜 병목이 필요한가

만약 은닉층이 입력과 같거나 더 넓다면, 신경망은 그냥 입력을 그대로 복사하는 항등함수(identity function)를 배워버릴 수 있다 — 그러면 복원 오차는 0이 되지만 아무것도 배운 게 없다. 병목(입력보다 훨씬 좁은 은닉층)을 강제하면, 신경망은 원본을 통째로 저장할 수 없으므로 정말로 중요한 정보만 압축해서 담아야 한다.

12.3 PCA와의 관계

Chapter 10에서 배운 PCA도 “고차원 데이터를 정보 손실 최소로 저차원으로 압축한다“는 목표는 같았다. 차이는 PCA가 직선(선형) 투영만 가능한 반면, 오토인코더는 신경망이므로 비선형 압축이 가능하다는 점이다 — 실제로 오토인코더의 인코더가 선형 활성함수만 쓰면, 수학적으로 PCA와 정확히 같은 것을 학습한다는 것이 알려져 있다:

\[\text{선형 오토인코더} \subset \text{비선형 오토인코더}, \qquad \text{선형 오토인코더} \approx \text{PCA}\]

즉 오토인코더는 PCA의 일반화(generalization)라고 볼 수 있다. 비선형 활성함수(ReLU, sigmoid 등)를 인코더/디코더에 추가하면, PCA로는 표현할 수 없는 곡면 모양의 데이터 구조도 압축할 수 있다.

12.4 압축에서 생성으로

오토인코더는 원래 압축(인코딩) 목적으로 만들어졌지만, 흥미로운 질문 하나가 남는다: 병목의 값을 무작위로 하나 골라서 디코더에 넣으면 어떻게 될까? 원본 데이터와 비슷하지만 존재한 적 없는 새로운 데이터가 나올 수도 있지 않을까? 이 질문이 바로 “생성형 모델(generative model)“의 시작이다.

오토인코더를 그대로 “생성 모델“로 쓰려고 하면 문제가 있다: 잠재 공간 \(z\) 위의 어떤 값들이 “그럴듯한” 데이터로 복원되는지 알 수 없다 — 학습 데이터가 차지하는 영역이 잠재 공간에서 듬성듬성하거나 불규칙할 수 있기 때문이다. 변분 오토인코더(Variational Autoencoder, VAE)는 이 문제를 잠재 공간이 매끄러운 확률분포(보통 정규분포)를 따르도록 강제해서 해결한다 — ML2 Chapter 9에서 다룬다. GAN과 Diffusion은 완전히 다른 원리(적대적 학습, 점진적 노이즈 제거)로 같은 목표(그럴듯한 새 데이터 생성)를 이룬다 — ML2 Chapter 10에서 다룬다.
