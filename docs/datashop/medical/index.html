X-ray 사진 한 장에서 폐렴을 찾을 수 있을까?

MedMNIST 공식 페이지
노트북 준비 중 · 데이터 월드컵에서 많이 뽑힌 데이터부터 노트북 · 통계 · 그래프를 만듭니다. 지금은 위 공식 페이지에서 데이터를 직접 볼 수 있습니다.

어떤 문제인가

입력 X흑백 사진 (28×28 또는 더 큰 크기)
→ 모델 →이진 분류 (이미지)
출력 y (기대하는 답)정상 / 폐렴

데이터

MedMNIST (PneumoniaMNIST)

Yang et al. (2023). 의료 영상 데이터를 28×28 등 작은 크기로 맞춘 모음. PneumoniaMNIST 는 소아 흉부 X-ray 5,856장, 정상 / 폐렴. pip install medmnist 로 받는다

문제를 정해 본 예시

① 한 행X-ray 사진 한 장
② 입력 X흑백 사진 (28×28 또는 더 큰 크기)
③ 출력 y정상 / 폐렴
④ 평가지표재현율 (놓친 환자) · ROC-AUC
⑤ 기준선가장 흔한 쪽

평가지표 수식

재현율 (recall)진짜 양성 중 잡아낸 비율 (놓치지 않았나)
\text{Recall} = \frac{TP}{TP + FN}
ROC-AUC양성 하나 · 음성 하나를 뽑았을 때 양성 점수가 더 높을 확률. 0.5 = 동전 던지기
\text{AUC} = P\big(s(x^{+}) > s(x^{-})\big)
