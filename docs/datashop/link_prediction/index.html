연구기관 1,005명이 주고받은 이메일 연결망. 아직 연결 안 된 두 사람, 곧 연락하게 될까?

Colab 에서 열기노트북 받기 (.ipynb)

어떤 문제인가

입력 X지금까지의 연결망 (공통 지인 수, 같은 부서인가 …)
→ 모델 →링크 예측
출력 y (기대하는 답)둘이 연결되는가

문제를 정해 본 예시

① 한 행두 사람의 쌍
② 입력 X지금까지의 연결망 (공통 지인 수, 같은 부서인가 …)
③ 출력 y둘이 연결되는가
④ 평가지표ROC-AUC (진짜 연결을 더 높게 매겼나)
⑤ 기준선무작위 점수 (AUC 0.5)

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

노트북에서 나온 결과 (기준선 vs 모델)

random score           : AUC 0.49
same department        : AUC 0.65
number of common friends: AUC 0.94

평가지표 수식

ROC-AUC양성 하나 · 음성 하나를 뽑았을 때 양성 점수가 더 높을 확률. 0.5 = 동전 던지기
\text{AUC} = P\big(s(x^{+}) > s(x^{-})\big)
