PageValues: 산 방문 vs 안 산 방문

산 방문은 PageValues 가 0 이 아닌 경우가 대부분. 이 값을 방문 도중에 알 수 있을까?

문제를 정해 본 예시 (다섯 칸)

① 한 행방문 세션 하나
② 입력 X본 페이지 수 · 머문 시간 · 이탈률 · 월 · 방문자 유형 …
③ 출력 y구매했나 (Revenue)
④ 평가지표정밀도 · 재현율
⑤ 기준선아무도 안 산다

예시와 다르게 정해도 됩니다. 노트북 맨 끝의 '나의 다섯 칸' 을 채워 보세요.

노트북에서 나온 결과 (기준선 vs 모델)

nobody buys                accuracy 84.5%  precision 0%  recall 0%
with PageValues            accuracy 90.1%  precision 73%  recall 57%
without PageValues         accuracy 84.2%  precision 46%  recall 12%
