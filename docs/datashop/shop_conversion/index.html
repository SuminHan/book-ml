PageValues: 산 방문 vs 안 산 방문

산 방문은 PageValues 가 0 이 아닌 경우가 대부분. 이 값을 방문 도중에 알 수 있을까?

문제를 정해 본 예시

① 한 행방문 세션 하나
② 입력 X본 페이지 수 · 머문 시간 · 이탈률 · 월 · 방문자 유형 …
③ 출력 y구매했나 (Revenue)
④ 평가지표정밀도 · 재현율
⑤ 기준선아무도 안 산다

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

노트북에서 나온 결과 (기준선 vs 모델)

nobody buys                accuracy 84.5%  precision 0%  recall 0%
with PageValues            accuracy 90.1%  precision 73%  recall 57%
without PageValues         accuracy 84.2%  precision 46%  recall 12%

평가지표 수식

정밀도 (precision)'양성' 이라고 한 것 중 진짜 양성의 비율 (헛짚지 않았나)
\text{Precision} = \frac{TP}{TP + FP}
재현율 (recall)진짜 양성 중 잡아낸 비율 (놓치지 않았나)
\text{Recall} = \frac{TP}{TP + FN}
정확도 (accuracy)맞힌 비율. 한쪽이 아주 드물면 '전부 흔한 쪽' 만으로도 높게 나온다
\text{Accuracy} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}[\hat y_i = y_i]
