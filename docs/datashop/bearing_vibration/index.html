베어링 진동으로 고장 진단

진동 · 센서 신호고장 진단상태 기반 정비

모터 베어링에 붙인 진동 센서, 1초에 1만 2천 번. 소리만 듣고 어디가 망가졌는지 알 수 있을까?

Colab 에서 열기노트북 받기 (.ipynb)

어떤 문제인가

입력 X조각의 통계 (RMS · 첨도 · 최댓값 …) 또는 파형 그대로
→ 모델 →신호 분류
출력 y (기대하는 답)정상 / 내륜 / 볼 / 외륜

데이터

CWRU Bearing Data · 약 13MB

Case Western Reserve University Bearing Data Center. 모터 베어링 진동 (12 kHz) 녹음: 정상 · 내륜 · 볼 · 외륜 결함 (지름 0.007인치, 부하 0) 4개 파일

문제를 정해 본 예시

① 한 행진동 조각 하나 (1,024 샘플 ≈ 0.085초)
② 입력 X조각의 통계 (RMS · 첨도 · 최댓값 …) 또는 파형 그대로
③ 출력 y정상 / 내륜 / 볼 / 외륜
④ 평가지표정확도 (네 종류 조각 수가 비슷하다)
⑤ 기준선가장 흔한 종류

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

평가지표 수식

정확도 (accuracy)맞힌 비율. 한쪽이 아주 드물면 '전부 흔한 쪽' 만으로도 높게 나온다
\text{Accuracy} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}[\hat y_i = y_i]
