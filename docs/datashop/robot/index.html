로봇 모방학습

모방학습 (imitation learning)로봇 조작행동 예측

사람의 시범을 보고 로봇이 블록을 T 자리에 밀어 넣을 수 있을까?

Hugging Face lerobot/pusht
노트북 준비 중 · 데이터 월드컵에서 많이 뽑힌 데이터부터 노트북 · 통계 · 그래프를 만듭니다. 지금은 위 공식 페이지에서 데이터를 직접 볼 수 있습니다.

어떤 문제인가

입력 X지금 화면 (또는 블록 · 손의 위치)
→ 모델 →회귀 (행동)
출력 y (기대하는 답)다음 행동 (손을 움직일 x, y)

데이터

LeRobot PushT

Hugging Face LeRobot. 사람이 2차원 화면에서 T 모양 블록을 목표 자리로 미는 시범 기록: 매 순간의 화면 · 상태 (위치) · 행동 (움직일 방향), MIT 라이선스

문제를 정해 본 예시

① 한 행시범 중 한 순간
② 입력 X지금 화면 (또는 블록 · 손의 위치)
③ 출력 y다음 행동 (손을 움직일 x, y)
④ 평가지표행동 오차, 실제로 밀어 넣은 성공률
⑤ 기준선지금 자리에 가만히

평가지표 수식

성공률로봇이 실제로 블록을 자리에 넣은 비율
\text{Success} = \frac{\text{성공한 시도}}{\text{전체 시도}}
MAE평균적으로 얼마나 틀렸나 (y 와 같은 단위)
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n} \lvert y_i - \hat y_i \rvert
