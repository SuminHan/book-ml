데이터

Tox21 (MoleculeNet)

미국 Tox21 프로그램의 독성 실험 결과를 MoleculeNet 이 정리한 것: 분자 약 8천 개 × 독성 실험 12가지 (빈칸 있음). 분자는 SMILES 문자열

문제를 정해 본 예시

① 한 행분자 하나
② 입력 XSMILES 문자열 (또는 원자 · 결합 그래프)
③ 출력 y독성 실험 12가지의 양성 / 음성 (빈칸 있음)

⑤ 기준선모두 음성
