코스피 종가 (10년)

하루 수익률 분포

0 근처에 몰려 있고, 가끔 크게 움직인다 (꼬리가 두껍다)

해마다 '오른 날' 비율

대부분 50% 근처: 내일 오를지 맞히기가 어려운 이유

문제를 정해 본 예시

① 한 행거래일 하루
② 입력 X지난 5일의 수익률 (그날까지 알 수 있는 것만)
③ 출력 y다음 거래일에 오르나 (분류) / 수익률 (회귀)
④ 평가지표정확도 · MAE
⑤ 기준선늘 '오른다' / 늘 0%

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

평가지표 수식

정확도 (accuracy)맞힌 비율. 한쪽이 아주 드물면 '전부 흔한 쪽' 만으로도 높게 나온다
\text{Accuracy} = \frac{1}{n}\sum_{i=1}^{n} \mathbb{1}[\hat y_i = y_i]
MAE평균적으로 얼마나 틀렸나 (y 와 같은 단위)
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n} \lvert y_i - \hat y_i \rvert
