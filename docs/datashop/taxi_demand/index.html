뉴욕 택시 수요 예측 (시공간)

시공간 (spatiotemporal) 수요예측모빌리티 · 배차지도 데이터

뉴욕 택시 한 달 300만 번. 다음 한 시간, 어느 구역에서 택시를 몇 번 부를까?

Colab 에서 열기노트북 받기 (.ipynb)

어떤 문제인가

입력 X그 구역의 지난 1 · 2시간, 어제 · 지난주 같은 시각 승차 수 + 이웃 구역 승차 수 + 시각 · 요일
→ 모델 →회귀 (시공간)
출력 y (기대하는 답)다음 한 시간 승차 수

문제를 정해 본 예시

① 한 행구역 × 한 시간
② 입력 X그 구역의 지난 1 · 2시간, 어제 · 지난주 같은 시각 승차 수 + 이웃 구역 승차 수 + 시각 · 요일
③ 출력 y다음 한 시간 승차 수
④ 평가지표MAE (건)
⑤ 기준선지난 한 시간 그대로 · 지난주 같은 시각

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

평가지표 수식

MAE평균적으로 얼마나 틀렸나 (y 와 같은 단위)
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n} \lvert y_i - \hat y_i \rvert
