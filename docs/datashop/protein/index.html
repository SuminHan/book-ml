단백질 구조 (AlphaFold)

구조 예측과학 AI바이오

아미노산 서열만 보고 3D 구조를 맞힐 수 있을까?

AlphaFold DB
노트북 준비 중 · 데이터 월드컵에서 많이 뽑힌 데이터부터 노트북 · 통계 · 그래프를 만듭니다. 지금은 위 공식 페이지에서 데이터를 직접 볼 수 있습니다.

어떤 문제인가

입력 X아미노산 서열 (글자 20종의 줄)
→ 모델 →구조 예측
출력 y (기대하는 답)원자들의 3D 좌표 + 예측 신뢰도 pLDDT

데이터

AlphaFold Protein Structure Database

EMBL-EBI · Google DeepMind. AlphaFold 가 예측한 단백질 구조 2억 개 이상 (CC BY 4.0). API 로 단백질 하나씩 받을 수 있다 (1주 2차시 실습)

문제를 정해 본 예시

① 한 행단백질 하나
② 입력 X아미노산 서열 (글자 20종의 줄)
③ 출력 y원자들의 3D 좌표 + 예측 신뢰도 pLDDT
④ 평가지표실험 구조와 겹치는 정도 (GDT, lDDT)
⑤ 기준선이전 대회 (CASP) 최고 방법

평가지표 수식

이 데이터는 하나의 정답 지표보다 분석 · 순위로 쓴다. 노트북의 '다른 문제로 바꿔 보기' 에서 지표를 직접 정해 보세요.
