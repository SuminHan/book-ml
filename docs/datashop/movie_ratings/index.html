별점 분포

4점이 가장 많다. 0.5점 단위

영화마다 받은 별점 수

대부분의 영화는 별점이 몇 개뿐이다 (긴 꼬리)

문제를 정해 본 예시 (다섯 칸)

① 한 행(사용자, 영화) 쌍 하나
② 입력 X사용자 번호 · 영화 번호 (+ 장르)
③ 출력 y별점 (0.5~5)
④ 평가지표RMSE (별 몇 개만큼 틀리나)
⑤ 기준선전체 평균 별점

예시와 다르게 정해도 됩니다. 노트북 맨 끝의 '나의 다섯 칸' 을 채워 보세요.

baseline (global mean 3.50): RMSE 1.051
mean + user bias + movie bias : RMSE 0.878
