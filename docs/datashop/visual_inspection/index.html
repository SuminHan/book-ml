금속 너트 사진. 학습용은 정상 220장뿐이다. 처음 보는 불량을 골라낼 수 있을까?

데이터 모양 보기

학습 · 시험 사진 수

학습에는 정상 사진만 있다. 불량은 시험에서 처음 본다

방법별 ROC-AUC (시험 115장)

1 = 불량을 모두 정상보다 높게, 0.5 = 동전 던지기

문제를 정해 본 예시

① 한 행부품 사진 한 장
② 입력 X사진 (학습에는 정상 사진만)
③ 출력 y이상 점수 (높을수록 불량 같음) → 기준을 넘으면 불량
④ 평가지표ROC-AUC, '불량 95% 를 잡을 때 정상을 몇 % 버리나'
⑤ 기준선무작위 점수 (AUC 0.5) · 픽셀 그대로 비교

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

노트북에서 나온 결과 (기준선 vs 모델)

random score (500 draws)     AUC 0.501   good parts rejected at 95% recall 94%
pixels + PCA reconstruction  AUC 0.586   good parts rejected at 95% recall 77%   AUC per defect {'bent': 0.45, 'color': 0.46, 'flip': 1.0, 'scratch': 0.43}
ResNet-18 features + 3-NN    AUC 0.838   good parts rejected at 95% recall 73%   AUC per defect {'bent': 0.77, 'color': 0.71, 'flip': 1.0, 'scratch': 0.87}

평가지표 수식

ROC-AUC양성 하나 · 음성 하나를 뽑았을 때 양성 점수가 더 높을 확률. 0.5 = 동전 던지기
\text{AUC} = P\big(s(x^{+}) > s(x^{-})\big)
재현율 (recall)진짜 양성 중 잡아낸 비율 (놓치지 않았나)
\text{Recall} = \frac{TP}{TP + FN}
