노트북 준비 중 · 데이터 월드컵에서 많이 뽑힌 데이터부터 노트북 · 통계 · 그래프를 만듭니다. 지금은 위 공식 페이지에서 데이터를 직접 볼 수 있습니다.

어떤 문제인가

입력 X컬러 사진 (또는 13개 파장 대역)
→ 모델 →다중 분류 (이미지)
출력 y (기대하는 답)10가지 토지 종류

데이터

EuroSAT

Helber et al. (2019). 유럽우주국 Sentinel-2 위성 사진 27,000장 (64×64), 10종류 (숲 · 강 · 주거지 · 고속도로 …)

문제를 정해 본 예시

① 한 행위성 사진 한 칸 (64×64)
② 입력 X컬러 사진 (또는 13개 파장 대역)
③ 출력 y10가지 토지 종류
④ 평가지표정확도
⑤ 기준선가장 흔한 종류

논문 · 출처

  • Helber et al. (2019) EuroSAT: A Novel Dataset and Deep Learning Benchmark for Land Use and Land Cover Classification, IEEE JSTARS
