어떤 문제인가

입력 X점들의 x, y, z 좌표
→ 모델 →다중 분류 (3D)
출력 y (기대하는 답)40종류 중 무엇 (의자, 비행기, 책상 …)

데이터

ModelNet40

Princeton (Wu et al., 2015). CAD 모델 12,311개, 40종류. 표면에서 점 2,048개를 뽑은 판이 Hugging Face 에 있다 (jxie/modelnet40-2048)

문제를 정해 본 예시

① 한 행물체 하나 (점 2,048개 × 좌표 3개)
② 입력 X점들의 x, y, z 좌표
③ 출력 y40종류 중 무엇 (의자, 비행기, 책상 …)
④ 평가지표정확도
⑤ 기준선가장 흔한 종류
