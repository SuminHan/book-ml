달마다 평균 1박 가격 (취소 안 된 예약)

리조트는 여름에 크게 오른다

며칠 전에 예약했나 → 취소율

일찍 예약할수록 많이 취소한다

문제를 정해 본 예시 (다섯 칸)

① 한 행예약 한 건
② 입력 X예약 시점에 아는 것: 며칠 전 예약 · 인원 · 박 수 · 고객 유형 …
③ 출력 y취소할까 (분류) / 1박 가격 adr (회귀)
④ 평가지표정밀도 · 재현율 / MAE (유로)
⑤ 기준선아무도 취소 안 함 / 같은 달 평균 가격

예시와 다르게 정해도 됩니다. 노트북 맨 끝의 '나의 다섯 칸' 을 채워 보세요.
