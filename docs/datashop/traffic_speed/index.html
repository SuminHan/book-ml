문제를 정해 본 예시

① 한 행센서 × 5분
② 입력 X그 센서의 지난 1시간 속도 + 이웃 센서 속도 + 시각
③ 출력 y15분 뒤 속도 (mph)
④ 평가지표MAE (mph), 막힘 (< 40 mph) 재현율
⑤ 기준선지금 속도 그대로

문제를 정할 때 처음 채워 보는 칸들입니다. 여기서 끝이 아니라, 시험 데이터를 어떻게 나눌지 · 틀렸을 때 손해가 얼마인지 · 예측 시점에 정말 알 수 있는 값인지 같은 칸을 더 붙일수록 좋은 문제가 됩니다.

노트북에서 나온 결과 (기준선 vs 모델)

now                    MAE 1.70 mph   jam (<40) recall 85%
own past hour + time   MAE 1.75 mph   jam (<40) recall 82%
+ neighbours           MAE 1.75 mph   jam (<40) recall 82%

평가지표 수식

MAE평균적으로 얼마나 틀렸나 (y 와 같은 단위)
\text{MAE} = \frac{1}{n}\sum_{i=1}^{n} \lvert y_i - \hat y_i \rvert
재현율 (recall)진짜 양성 중 잡아낸 비율 (놓치지 않았나)
\text{Recall} = \frac{TP}{TP + FN}
