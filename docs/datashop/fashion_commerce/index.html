① 한 행상품 하나 (사진 60×80 + 성별 · 종류 · 색 · 계절)

평가지표 수식

추천 5개 중 같은 종류 비율q = 고른 상품, r_j = 추천한 j번째 상품
\frac{1}{5}\sum_{j=1}^{5} \mathbb{1}[\text{type}(r_j) = \text{type}(q)]
