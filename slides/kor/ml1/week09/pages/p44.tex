\begin{frame}{1/(1-p) 보정이 정확히 보존하는 것}
  \small
  활성값 $a = (1, -2, 3, 4)$, $p = 0.5$ (4개 평균을 내려층으로
  전달한다고 가정):
  \begin{itemize}
    \item \kb{보정 없이}: $\text{E}[\text{출력}] = (1-p)\,a = 0.5\,a$
      — 평균 0.75로 절반. 추론 때는 뉴런 전부 켜 $a$(평균 1.5)를
      사용 $\Rightarrow$ \textbf{학습(0.75)과 추론(1.5)이 $(1-p)$배
      어긋남}
    \item \kb{$/(1-p)$로 보정}: $\text{E}[\text{mask}\cdot a/(1-p)] =
      \text{E}[\text{mask}]\,a/(1-p) = (1-p)\,a/(1-p) = a$ —
      \textbf{학습 때 기댓값이 정확히 추론값과 같음}
  \end{itemize}
  \vskip0.3em
  {\small 실제로 모든 $2^4 = 16$개 마스크 조합의 평균 = \textbf{정확히
  1.5}, 무작위 20만 번 샘플링 = 1.5012 (스크래치패드 검증).
  ``1.5 = 1.5'' — 이 \kb{불변(invariance)}이 inverted dropout의
  정석. \textbf{추론 때는 masking을 아예 끄고, 모든 뉴런을 켜되 각
  출력을 $(1-p)$로 스케일} — 학습 때의 $2^N$ 앙상블 평균을 한 번의
  전파로 근사.}
  \vskip0.3em
  {\footnotesize $p$ 선택: 은닉층 $p = 0.2 \sim 0.5$가 흔함, 과적합이
  심할수록 $p$ 키움. $p \ge 0.7$이면 살아남는 뉴런 부족 $\to$
  \textbf{과소적합} — ``train·val 정확도가 함께 떨어지기 시작하는
  지점''에서 멈춤. 입력층에 dropout을 쓰는 경우는 드묾.}
\end{frame}
