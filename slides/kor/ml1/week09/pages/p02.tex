  \begin{block}{이 주차를 마치면}
    \small
    \begin{itemize}
      \item XOR이 직선 하나로 안 풀리는 이유를 설명하고, 은닉층이 어떻게 푸는지 보여준다
      \item 역전파를 연쇄법칙으로부터 유도하고, 구현을 수치 미분으로 검증한다
      \item 그래디언트 소실·폭발을 진단하고, 활성함수와 초기화를 고른다
      \item 정규화와 학습률 스케줄링을 과적합·불안정 학습 상황에 맞게 적용한다
    \end{itemize}
  \end{block}
  \begin{itemize}
    \item \kb{9.1 퍼셉트론의 한계, 순전파, 역전파} — XOR의 벽, 오차 $\delta$의 역전파,
      2-2-1 손계산, numpy로 XOR 풀기
    \item \kb{9.2 그래디언트 소실·폭발, 활성함수, 초기화} — 연쇄법칙의 곱, ReLU 계열,
      Xavier/He 초기화, ``세 라인 방어선''
    \item \kb{9.3 정규화 기법과 학습률 스케줄링} — dropout, BatchNorm, 가중치 감쇠,
      StepLR/코사인/warmup
  \end{itemize}

  깊어지면 0으로 사라지거나 불어나는(9.2) $\to$ 학습을 안정적으로 끝내는 도구(9.3).
