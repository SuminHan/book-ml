\begin{frame}{결실 사례: ``숫자를 바꾼 리뷰''}
  \begin{alertblock}{발표}
    \small ``흉부 X-광 CNN, test 정확도 \textbf{94\%}. \textbf{증강
    6가지 변형}을 시도해 \textbf{가장 좋은 것을 골랐다}.''
  \end{alertblock}
  \vskip0.3em
  \small
  \begin{itemize}
    \item 리뷰어의 \textbf{3점 질문}: ``6개 변형 중 \textbf{
      test로} 고른 것은 Ch06.3 \textbf{선택 편향} — 후보 6개면
      $\mathbb{E}[\max]\approx0.025$ \textbf{부풀림}. val은
      몇 \%인가?''
  \end{itemize}
  \vskip0.3em
  \begin{block}{팀이 다시 확인해 보면 — 다른 원인이 드러난다}
    같은 \textbf{환자}의 여러 X-광이 train과 test에 \textbf{
    동시에} 들어 있었다(\textbf{그룹 누수}, 6.3). \textbf{환자
    단위}로 다시 나누자 test 정확도 \textbf{94\% $\to$ 88\%}로
    \textbf{떨어짐} — ``94\%'' 발표가 리뷰 한 통으로 ``\textbf{
    88\%, 그 이유까지}''라는 더 좋은 발표로.
  \end{block}
  \vskip0.3em
  \begin{block}{반대의 경고}
    리뷰 후 ``다시 확인''할 때 사람은 원래 \textbf{결론을 더
    쉽게 다시 찾게 된다}(자기에게 유리한 편향) $\Rightarrow$
    보고서에 \textbf{리뷰 답변을 별책으로} 첨부 — ``무엇을
    다시 확인했는지''가 \textbf{기록}이 되어 확인이 \textbf{
    정말로} 일어났는지(숫자가 실제로 바뀌었는지) 추적 가능.
  \end{block}
\end{frame}
