\begin{frame}{왜 서열을 바로 분류하지 않고 구조 그래프를 거치는가}
  \begin{block}{``왜?''를 한 번}
    동일한 기능을 가진 단백질은 \textbf{서열이 많이 달라}도
    \textbf{3차원 형태(구조)는 비슷하게} 유지되는 경우가 흔하다.
  \end{block}
  \vskip0.5em
  \begin{itemize}
    \item 구조 그래프는 ``\textbf{서열과 무관한 기능의 공통 요인}''을
      더 \textbf{직접적으로} 담는 표현.
    \item 같은 구조에 다른 서열의 단백질(\textbf{유사 동종단백질})
      기능을 추론할 때 \textbf{서열 기반 모델보다 유리}.
    \item AlphaFold의 구조 예측이 생물학 난제를 풀기만 한 게 아니라,
      \kq{\textbf{그래프 기반 추론의 입력을 대량으로 공급하는
      인프라}}가 된 이유.
  \end{itemize}
\end{frame}
