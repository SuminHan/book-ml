\begin{frame}{이번 주차 개요}
  \small
  \begin{block}{이 주차를 마치면}
    \begin{itemize}
      \item 마진 $2/\|w\|$ 유도, 마진 최대화 $=$ $\|w\|$ 최소화
      \item \kb{서포트 벡터}를 손으로 확인, 로지스틱회귀와 대비
      \item \kb{힌지 손실}과 $C$: 과적합/과소적합을 조절하는 손잡이
      \item XOR·동심원과 \kb{커널 트릭}: 고차원에서 분리
    \end{itemize}
  \end{block}
  \vskip0.4em
  \begin{itemize}
    \item \textbf{5.1} — 여러 분할 직선 중 ``가장 안전한 하나''를 고른다
    \item \textbf{5.2} — 여유 변수 $\xi$와 $C$ 페널티로 하드 마진 완화
    \item \textbf{5.3} — 커널 함수로 고차원 내적을 우회
  \end{itemize}
  \vskip0.3em
  세 블록의 순서 = \textbf{전제를 하나씩 덜어내는} 과정.
  5.2의 $C$는 6장의 정규화 세기 $\lambda$와 같은 종류의 트레이드오프.
\end{frame}
