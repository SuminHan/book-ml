\begin{frame}{목차}
  \small
  \begin{itemize}
    \item \textbf{고전 ML과 신경망의 역사}: 회귀(1805)$\cdot$SVM(1995)의
      고전 ML 계보와, 퍼셉트론(1950s)에서 LLM(2022$\sim$)까지의
      연표, 1969년과 2012년을 가른 \textbf{두 번의 ``AI 겨울''}, 그리고
      ``왜 하필 2012년이었나''를 \kb{계산성능}과 \kb{데이터} 두 축으로.
    \item \textbf{이번 학기 로드맵}: Block A(고전 ML)와 Block B(신경망 $\to$
      생성모델)의 16개 장이 어떻게 이어지는지, 학기 내내 반복해서 쓸 도구들(numpy $\sim$ PyTorch).
    \item \textbf{문제 정식화}: 알고리즘보다 먼저 문제를 입력 $x$ ·
      출력 $y$ · 가설 $h$ 로 정의하기, 학습 데이터 표기($m$, 위첨자 $(i)$),
      ``정답 라벨은 사람이 정한다''는 라벨의 책임.
    \item \textbf{세 갈래 분류}: 손에 쥔 데이터로 \kb{지도 / 비지도 / 강화}를
      가르는 기준, 지도학습 내부의 판별적 vs 생성적, 그리고
      \textbf{회귀 vs 분류 --- ``같은 모델, 다른 출력''}(항등 링크 vs
      시그모이드).
    \item \textbf{데이터 파이프라인과 세 가지 수학}: 수집 $\to$ 정제 $\to$
      EDA $\to$ 모델링 $\to$ 평가의 흐름과 \textbf{데이터 누수}, 그리고 학기
      전체를 관통하는 \kb{내적 · 연쇄법칙 · 베이즈 정리}.
  \end{itemize}
\end{frame}
