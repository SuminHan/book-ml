\begin{frame}{실무 규칙: StandardScaler를 먼저}
  \begin{itemize}
    \item 키의 분산($\approx 64$)이 몸무게($\approx 36$)보다 크면,
      표준화 없이 돌리면 PC1이 \textbf{거의 키 쪽에 쏠린다} --- 키와
      몸무게가 실제로 얼마나 상관되는지와 \textbf{별개로}.
    \item 데이터가 ``키가 크면 무겁다'' 같은 \textbf{상관 구조}를 담고
      있어도, 분산 크기의 차이가 그것을 가려버린다.
    \item 표준화 \textbf{후}에도 PC1이 45도(91.3\%)를 유지하는 것 =
      ``상관 구조를 정확히 찾았다''.
  \end{itemize}
  \vskip0.6em
  \begin{block}{실무 규칙}
    PCA 전 \textbf{항상} \texttt{StandardScaler}로 각 특징을
    평균 0 · 표준편차 1로 정규화.
    \par 특징들이 이미 같은 단위를 공유할 때(예: 붓꽃, 전부 cm)만
    표준화 생략 가능 --- \textbf{의식적으로} 생략해야지,
    ``잊어서'' 생략하는 것은 아니다.
    \par \texttt{sklearn}의 \texttt{PCA}는 표준화를 \textbf{자동으로
    해주지 않는다}(중심화만) --- 스케일링은 사용자의 몫.
  \end{block}
\end{frame}
