\begin{frame}{자주 묻는 질문 (3): 불균형에서 무엇을 봐야 하나}
  \textbf{Q. 클래스 불균형이 심한 데이터에서 PR-AUC와 ROC-AUC 중
  무엇을 봐야 하나?} $\to$ \kb{PR-AUC 우선}.
  \vskip0.4em
  \begin{itemize}
    \item 양성 15\% 데이터: ``무조건 0'' 모델의
      \textbf{PR-AUC = 0.15}, \textbf{ROC-AUC = 0.5}.
    \item 학습한 모델의 \textbf{PR-AUC = 0.16}이면 ``거의
      무조건 0과 같은 모델''이 \textbf{바로 읽힘}.
    \item 반면 \textbf{ROC-AUC = 0.51}은 ``무작위보다 약간 낫다''로
      해석되어 \textbf{과대평가}되기 쉬움.
    \item 불균형이 심할수록 \textbf{PR-AUC의 기준선(양성
      비율)이 더 ``정직''}.
  \end{itemize}
  \vskip0.4em
  {\footnotesize ROC-AUC는 스크리닝(후보 모델 비교)에는 여전히
  유용하지만, \textbf{최종 선택은 PR-AUC + 비용 곡선}으로.}
\end{frame}
