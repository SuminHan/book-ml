\begin{frame}{파라미터는 어떻게 정해지는가: ``맞춤'' 작업}
  $h_{\boldsymbol{w}}(\boldsymbol{x}) = \boldsymbol{w}^T\boldsymbol{x}$ 에서 우리가 조절할 수 있는 것은
  $\boldsymbol{w} = (w_0, \ldots, w_n)$ 뿐이다.
  \vskip0.8em
  \begin{block}{학습 알고리즘의 임무}
    학습 데이터 $(\boldsymbol{x}^{(i)}, y^{(i)})$ 에 대해 예측값 $h_{\boldsymbol{w}}(\boldsymbol{x}^{(i)})$ 가
    실제 출력 $y^{(i)}$ 에 가깝게 되는 $\boldsymbol{w}$ 를 찾는다.
  \end{block}
  특징이 하나뿐이면 ($n=1$) $h_{\boldsymbol{w}}(\boldsymbol{x}) = w_0 + w_1 x$ 는 \textbf{직선}이다.
  임무는 무수히 많은 직선 중 \textbf{데이터 점들에 가장 잘 들어맞는 한 줄}을
  찾는 \kb{맞춤(fitting)} 작업이 된다.
\end{frame}
