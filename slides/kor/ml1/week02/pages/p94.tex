\begin{frame}{확인 문제: 4문단}
  \begin{enumerate}
    \item $\boldsymbol{w}^T\boldsymbol{x} = -2$ 일 때 $h_{\boldsymbol{w}}(\boldsymbol{x})$ 는 몇이고, 이 예는 음성으로
      예측되는가? $\boldsymbol{w}^T\boldsymbol{x} = 3$ 일 때는?
      (힌트: $\sigma(z)$ 를 대입하고 0.5와 비교.)
    \item ``무조건 음성으로 예측하는 모델''의 ROC-AUC는 항상 0.5인가?
      (힌트: 임계값을 움직여 TPR-FPR 쌍을 그려라.)
    \item Precision=0.5, Recall=0.9 일 때 F1은 몇인가?
      (힌트: 조화평균 공식. 단답.)
    \item ``양성이 5\%인 데이터에서 PR-AUC=0.051이면 이 모델은
      쓸모가 있다''는 진술은 옳은가? (힌트: PR-AUC의 기준선이
      양성 비율임을 떠올려라.)
  \end{enumerate}
\end{frame}
