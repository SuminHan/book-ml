\begin{frame}{증분 갱신식 = 온라인 평균: 귀납으로 증명}
  팔 하나를 $n$번 당겨 관찰한 보상 $R_1, \ldots, R_n$ 일 때
  ($Q_0 = 0$ 에서 시작):
  \vskip0.4em
  \begin{itemize}
    \item \textbf{기초 단계} $n=1$:
      $Q_1 = 0 + \frac{1}{1}(R_1 - 0) = R_1$ = 평균.
    \item \textbf{귀납 단계}: $Q_n = \frac{1}{n}\sum_{i=1}^{n} R_i$ 라고
      가정하고 한 번 더 갱신:
  \end{itemize}
  \vskip0.3em
  \begin{center}
    \[Q_{n+1} = Q_n + \frac{1}{n+1}(R_{n+1} - Q_n)
    = \frac{n}{n+1}Q_n + \frac{1}{n+1}R_{n+1}\]
    \[= \frac{1}{n+1}\sum_{i=1}^{n} R_i + \frac{R_{n+1}}{n+1}
    = \frac{1}{n+1}\sum_{i=1}^{n+1} R_i \quad\blacksquare\]
  \end{center}
  $\frac{1}{n+1}$ 의 가중치가 ``이전 평균에 $n$ 번, 새 관측에 1 번''
  나눠주는 구조.
\end{frame}
