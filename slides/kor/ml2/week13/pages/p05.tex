    \begin{column}{0.46\textwidth}
      팔 끝이 $(x, y)$ 에 있으려면, 팔 끝까지의 거리
      $d = \sqrt{x^2 + y^2}$ 가 두 마디와 팔 마디를 이은 ``삼각형''의
      세 번째 변. 코사인 정리에
      \[
        \cos\theta_2 = \frac{d^2 - l_1^2 - l_2^2}{2 l_1 l_2}
      \]
      \begin{itemize}
        \item \kb{해가 여러 개}: $\theta_2$ 는 $\arccos$ 로 부호($\pm$)가
          자유로움.
        \item \kb{도달 가능 영역}: $|l_1 - l_2| \le d \le l_1 + l_2$.
      \end{itemize}
    \end{column}
  \end{columns}
