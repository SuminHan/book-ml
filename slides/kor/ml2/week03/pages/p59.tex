\begin{frame}{두 방식, 같은 답: 닫힌형 vs 반복 대입}
  \begin{itemize}
    \item 흥미로운 확인 하나 더: 벨만방정식을 $V_0 = V_1 = 0$
      에서 시작해 \textbf{200번 반복 대입}(다음 장 \textbf{정책평가}
      의 예고편)으로 풀어도 \textbf{정확히 같은 값}(14.737, 15.263)
      으로 수렴.
    \item \kb{``무한급수를 닫힌 형태로 직접 계산''과 ``재귀식을 값이
      안 바뀔 때까지 반복 적용''이라는 서로 다른 두 방법이 같은 답에
      도달}한다.
  \end{itemize}
  \vskip0.5em
  {\footnotesize 이 ``같은 답''은 우연이 아니다 --- $\gamma < 1$
  이면 벨만방정식은 \textbf{유일한 고정점}을 갖고, 어떤 초기값에서
  출발해도 그 곳으로 수렴(다음 프레임의 수축 연산 논증).}
\end{frame}
