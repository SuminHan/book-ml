\begin{frame}{닫힌 형태로 잘 풀리는 무한합}
  이 무한합은 실제로 \textbf{닫힌 형태로} 잘 풀린다. $\gamma < 1$
  이면 기하급수의 합 공식을 그대로 쓸 수 있다.
  \vskip0.4em
  \textbf{보상이 매 스텝 같은 값 $R$ 으로 고정된 경우:}
  \[
  G_t = R + \gamma R + \gamma^2 R + \cdots \;=\; \frac{R}{1-\gamma}
  \]
  \begin{itemize}
    \item $\gamma = 0.9$, $R = 1$ 이면 $G_t = \frac{1}{0.1} = 10$ ---
      ``매 스텝 1을 무한히 받는 환경''의 리턴이 10이라는 뜻.
    \item $\gamma$ 가 1에 다가갈수록 이 값은 $\frac{1}{1-\gamma}$
      처럼 \textbf{무한대로 올라간다} --- ``발산''의 구체적 모양.
  \end{itemize}
  \vskip0.5em
  \textbf{보상이 매 스텝마다 다른 일반적 경우}: \textbf{한 에피소드가
  유한한 스텝 $T$ 뒤에 끝나면}(터미널 도달 뒤 보상은 모두 0)
  무한합은 \textbf{유한합으로 잘린다}:
  \[
  G_0 = \sum_{k=0}^{T} \gamma^k R_k
  = R_0 + \gamma R_1 + \gamma^2 R_2 + \cdots + \gamma^T R_T
  \]
  \vskip0.3em
  {\footnotesize ``무한합''이라는 \textbf{모양}만 무서울 뿐, 실제로는
  \textbf{마지막 보상 $R_T$ 의 계수 $\gamma^T$ 가 아주 작으므로}
  유효한 항은 앞에 몇 개뿐이다 --- ``몇 개쯤이 유효한지''를 숫자로
  잡는 것이 바로 다음 절의 \kb{유효 시계}다.}
\end{frame}
