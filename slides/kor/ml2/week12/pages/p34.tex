      {\footnotesize InstructGPT (Ouyang et al., 2022) 3단계 파이프라인:
      SFT $\to$ 보상모델(RM) 학습 $\to$ PPO 강화학습.}
    \end{column}
    \begin{column}{0.43\textwidth}
      \begin{itemize}
        \item ``사람의 선호로 보상모델을 학습하고, 그 보상을 PPO에
          넣어 정책을 최적화'' — LLM 챗봇 훈련의 \textbf{표준}.
        \item \kb{실용적 이유: 주기가 다름}
        \item 비교 \textbf{수집} = 비싸고 느리고, 사람 오프라인 작업.
        \item \textbf{최적화} = 싸고 빠르고, 자동화 RL.
        \item 선호 쌍 한 번 모아두면, 단계 2는 \textbf{사람 없이}
          반복 가능.
      \end{itemize}
    \end{column}
  \end{columns}
