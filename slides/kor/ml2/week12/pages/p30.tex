\begin{frame}[fragile]{선호 기반 학습도 결국 로지스틱회귀}
\begin{lstlisting}
def reward_model_loss(r_win, r_lose):
    # Bradley-Terry: P(y_w > y_l) = sigmoid(r_win - r_lose)
    return -math.log(sigmoid(r_win - r_lose))
\end{lstlisting}
  \vskip0.4em
  \begin{itemize}
    \item BC(12.1)의 \texttt{grad = pred - a}, 여기선
      ``win이 이겼다''가 정답 라벨.
    \item \textbf{패턴의 반복}: 로지스틱회귀 $\to$ BC $\to$
      Bradley-Terry 보상모델. 구조는 늘 ``시그모이드 + 교차엔트로피''.
  \end{itemize}
