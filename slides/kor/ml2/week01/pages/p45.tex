\begin{frame}{활성 함수가 없으면: 두 층이 하나의 선형 변환으로}
  $\sigma$를 빼고 (활성 함수 없는) 2층만 쓰면, 두 층은
  \textbf{하나의 선형 변환으로 완전히 축소}된다:
  \[a_2 = W_2^T(W_1 x + b_1) + b_2 = (W_2^T W_1)\,x
  + (W_2^T b_1 + b_2) \equiv Wx + b\]
  \begin{itemize}
    \item 두 층이 하나의 층으로 \textbf{합쳐져 버림}.
    \item 아무리 층을 쌓아도 \textbf{직선}(회귀) 또는
      \textbf{평행사변형의 경계}(분류)밖에 그릴 수 \textbf{없음}.
    \item 활성 함수가 없으면 층의 ``깊이''라는 개념 자체가 존재하지
      \textbf{않음}.
  \end{itemize}
  \vskip0.4em
  {\footnotesize 이 등식($W_2^T W_1 \equiv W$)을 코드로 직접 확인하는
  것은 1.2 실습 노트북.}
\end{frame}
