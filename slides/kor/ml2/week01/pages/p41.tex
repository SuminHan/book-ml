\begin{frame}{확인 문제 + 자주 묻는 질문}
  \small
  \kb{확인 문제: ``보상''이 ``정답''으로 바뀌면?}
  \begin{itemize}
    \item (a) 성공/실패 \textbf{라벨이 붙은} 영상 10,000개로 패턴 학습
      $\to$ \textbf{지도학습}(시연 데이터) = \kb{모방학습} (12주차).
    \item (b) 시연 \textbf{100개뿐}이고 나머지는 스스로 행동하며 만들면
      $\to$ \textbf{강화학습}, 희박 보상 ``성공 시 $+1$'',
      탐험 vs 활용 딜레마가 \textit{여기서} 등장.
    \item 경계: \textbf{시연이 충분하면 모방, 부족하면 강화}.
  \end{itemize}
  \vskip0.4em
  \kb{자주 묻는 질문}
  \begin{itemize}
    \item ``RL은 지도학습의 특수한 경우?'' $\to$ 아님.
      \textbf{데이터를 누가 만드냐}가 본질적 차이.
    \item ``보상이 희박하면 불가능?'' $\to$ 불가능하진 않으나
      \textit{훨씬} 어려움. 도구: TD(6주차) $\cdot$ 적격흔적(7주차)
      $\cdot$ MCTS(15주차) $\cdot$ \textbf{보상 성형}(13$\sim$14주차).
    \item ``실제 로봇을 다루나?'' $\to$ 아님, \textbf{시뮬레이션}.
      시뮬만으로도 충분한 이유: 실제 로봇 학습은 위험$\cdot$비쌈$\cdot$느리고,
      sim-to-real이 표준 방법이 되었기 때문.
    \item ``모델 안다 vs 모른다?'' $\to$ 지도학습 과목의 생성적 vs 판별적 접근과
      같은 ``중간 모델을 세울 것인가'' 질문. RL에서는
      \kb{모델기반}(15주차) vs \kb{모델프리}(2$\sim$11주차).
    \item ``왜 PPO가 필수?'' $\to$ REINFORCE는 실무에 불안정(한 번에
      너무 많이 바꾸면 발산). PPO는 \textbf{클래핑 + KL 제어}로 잡아준
      실무 표준.
  \end{itemize}
\end{frame}
