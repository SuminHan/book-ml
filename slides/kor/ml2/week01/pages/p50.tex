\begin{frame}{역전파는 왜 필요한가}
  그래디언트를 구하는 방법 = \kb{역전파(backpropagation)} ---
  \textbf{연쇄법칙}을 \textbf{출력에서 입력 방향으로} 거꾸로 적용해,
  각 파라미터가 최종 손실에 얼마나 책임이 있는지 계산.
  \begin{itemize}
    \item 층이 하나면 미분을 손으로 바로 계산 가능.
    \item 층을 여러 개 쌓으면 한 파라미터의 변화가 최종 손실에
      도달하기까지 \textbf{경로가 길어짐}.
    \item 역전파 = 이 긴 경로를 ``출력의 오차를 \textbf{한 층씩 거슬러
      올려보내며}'' 정확하고 효율적으로 계산하는 절차.
  \end{itemize}
  \vskip0.4em
  \kq{그래도 한 번은 숫자로.}
  ``오차를 거슬러 올려보낸다''가 실제로 무슨 뜻인지,
  1-2-1 신경망(입력 1, 은닉 2, 출력 1, ReLU)으로 손계산.
  가중치를 단순하게 골라 \textbf{정수 연산}만으로 끝냄.
\end{frame}
