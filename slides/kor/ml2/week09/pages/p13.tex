\begin{frame}{파라미터 수를 센다: 4,610개}
  \[
  \underbrace{(4 \times 64 + 64)}_{\text{층 1}}
  + \underbrace{(64 \times 64 + 64)}_{\text{층 2}}
  + \underbrace{(64 \times 2 + 2)}_{\text{출력층}} = 4{,}610
  \]
  \begin{itemize}
    \item \textbf{4,610개}의 숫자가 CartPole 4차원 상태 공간 \textbf{전체}에서
      Q함수를 정의. 같은 환경 12등분 표는 20,736칸, 100등분은 $10^8$칸.
    \item ``10억 칸의 표''를 ``4,610개의 가중치''로 대체.
  \end{itemize}
  \vskip0.4em
  \begin{block}{본질}
    \textbf{파라미터 수는 상태 공간의 크기와 무관하게}(입력 차원에만 선형으로)
    결정된다.
  \end{block}
  {\footnotesize 참고: Atari 이미지 7,056원을 완전연결로 넣으면
  455,938개 --- 여전히 미미. 단, 실제 DQN은 \textbf{CNN을 앞단에 붙여}
  특징 수백 개로 압축 (ML1 Week 10).}
\end{frame}
