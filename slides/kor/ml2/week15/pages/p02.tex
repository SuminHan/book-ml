\% ===== roadmap of this week =====
\begin{frame}{이번 주차 개요}
  \small
  \textbf{이 주차를 마치면}
  \begin{enumerate}
    \item 모델기반 RL을 ``모델이 \textbf{어디에서 오느냐}''(known/learned)와
      ``모델을 \textbf{무엇에 쓰느냐}''(학습/계획)의 두 축으로 정리하고,
      가치반복 · Dyna-Q · MCTS · MPC가 표의 어디에 앉는지 설명할 수 있다.
    \item MCTS의 \textbf{네 단계}(선택·확장·시뮬레이션·역전파)가 한 번의
      시뮬레이션에서 각각 무슨 일을 하는지 설명하고, 님 게임에서 직접
      구현해 시뮬레이션 횟수와 탐색 상수 $c$의 영향을 실험으로 확인한다.
    \item 선택 규칙 \kb{UCT}가 Week 2.2의 UCB를 트리 탐색에 적용한 것임을
      설명하고, AlphaGo/AlphaZero가 MCTS에 신경망을 결합한 구조를 짚는다.
    \item (선택) 여러 에이전트가 학습하면 \textbf{비정상성} 문제로 단일
      에이전트의 수렴 보장이 무너지는 이유와, 알고리즘이 같아도
      \textbf{보상 구조}에 따라 결과가 달라지는 이유를 설명한다.
  \end{enumerate}
  \vskip0.5em
  \small
  \begin{itemize}
    \item \kb{15.1} Dyna-Q 재조명: known/learned $\times$ 학습/계획, ``공짜 모델''
    \item \kb{15.2} MCTS: 네 단계 + UCT, 님 실습, 버그 투어, AlphaGo/AlphaZero
    \item \kb{15.3} (선택) 멀티에이전트 RL: 비정상성, 죄수의 딜레마·조율·바위-가위-보
    \item \kb{15.4} World Models: 학습된 모델 안에서 상상하며 계획하기
  \end{itemize}
  \vskip0.4em
  \kq{이 장의 주제 = ``부분 계획'': 전체 상태 공간을 계산하는 대신,
  지금 필요한 갈림길만 깊게 계산한다.}
\end{frame}
