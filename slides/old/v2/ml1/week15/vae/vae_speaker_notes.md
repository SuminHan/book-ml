# 발표자 노트: vae

번호는 슬라이드 하단 번호입니다 (표지 제외).

## 1. 오늘의 질문: 본 적 없는 새 손글씨를 만들려면?

지금까지는 그림을 보고 이름표를 붙이는 분류를 주로 했습니다. 오늘은 반대로 숫자 몇 개에서 새 그림을 만드는 생성을 배웁니다. 출발점은 오토인코더입니다. 인코더가 그림을 숫자 2개로 줄이고, 디코더가 그 숫자 2개에서 다시 그림을 되살리도록 학습합니다. 그러면 디코더에 아무 숫자 2개나 넣으면 새 그림이 나오지 않을까요? 문제는 그 아무 숫자를 어디서 뽑느냐입니다. 손글씨 숫자 1797장으로, 지도처럼 그릴 수 있게 2칸으로 줄여 실험해 봤습니다.

## 2. 오토인코더의 지도: 어디서 뽑아야 할지 모른다

같은 구조로 오토인코더와 오늘 배울 VAE를 학습해 2칸 지도를 그렸습니다. 오토인코더의 지도는 숫자들이 평균 1.1, 3.5, 퍼짐 3.6 근처에 제멋대로 퍼져 있습니다. 이 범위는 학습할 때마다 달라지니, 새 그림을 만들려 해도 어디서 숫자를 뽑아야 할지 모릅니다. VAE의 지도는 평균 0, 퍼짐 0.98, 표준정규분포 N 0 1과 거의 같은 모양입니다. 빨간 점선은 N 0 1의 95퍼센트가 들어가는 원입니다. 그러니 N 0 1에서 뽑으면 됩니다.

## 3. VAE: 점 대신 구름으로 줄인다

VAE, 변분 오토인코더는 2013년 킹마와 웰링이 발표했습니다. 핵심은 그림을 점 하나가 아니라 구름으로 줄이는 겁니다. 인코더는 평균 뮤와 퍼짐 시그마를 내고, 그 구름에서 한 점 z를 뽑아 디코더에 넣습니다. 구름 어디서 뽑아도 같은 그림이 되살아나야 하니, 구름 사이 빈틈도 그럴듯한 그림으로 채워집니다. z를 뮤 더하기 시그마 곱하기 엡실론으로 뽑는 것을 재매개변수화라 하는데, 무작위성이 엡실론에만 있으니 뮤와 시그마로 기울기가 흘러갈 수 있습니다.

## 4. 손실 = 복원 + KL

VAE의 손실은 두 항입니다. 첫째는 오토인코더처럼 원래 그림과 되살린 그림의 차이, 복원 오차입니다. 둘째는 구름과 표준정규분포 사이의 KL 발산입니다. KL은 다음 덱에서 자세히 배우는데, 두 분포가 얼마나 다른지 재는 값입니다. 칸 하나에 대해 2분의 1 곱하기 뮤 제곱 더하기 시그마 제곱 빼기 1 빼기 로그 시그마 제곱입니다. 뮤가 1, 시그마가 0.5면 0.82입니다. 뮤가 0, 시그마가 1이면 0이 됩니다. 구름이 원점에서 멀거나, 점처럼 너무 작아지면 벌점을 받습니다. 그래서 VAE의 지도는 N 0 1 모양이 됩니다.

## 5. 손으로 한 번: 구름에서 뽑기

구름에서 뽑는 걸 직접 해 봅시다. 인코더가 뮤 1, 시그마 0.5를 냈고, 이번에 표준정규분포에서 엡실론 마이너스 0.4를 뽑았습니다. z는 1 더하기 0.5 곱하기 마이너스 0.4, 0.8입니다. 다음 바퀴에는 다른 엡실론이 뽑혀 z가 달라지니, 디코더는 0.8 근처 어디서든 같은 그림을 내도록 배웁니다. 그리고 z를 뮤로 미분하면 1, 시그마로 미분하면 엡실론이니, 무작위로 뽑았는데도 기울기가 뮤와 시그마로 흐릅니다.

## 6. 실험: N(0, 1) 에서 뽑아 되살리기

N 0 1에서 숫자 2개를 2000번 뽑아 디코더로 되살렸습니다. 어떤 숫자인지는 원본 그림으로 학습한 분류기로 판정했습니다. 오토인코더는 0, 7, 9에 몰려 다섯 종류만 나왔습니다. N 0 1의 원이 오토인코더 지도의 한 귀퉁이만 덮기 때문입니다. VAE는 열 종류가 모두 2에서 17퍼센트씩 고르게 나옵니다. 지도 전체가 N 0 1 원 안에 들어 있으니까요.

## 7. VAE 지도 어디를 찍어도 숫자

VAE 지도의 마이너스 2부터 2까지를 9 곱하기 9로 나눠 모두 되살렸습니다. 어디를 찍어도 숫자 모양이 나오고, 옆 칸끼리는 비슷한 그림입니다. 숫자 0들의 평균 위치에서 숫자 1들의 평균 위치로 걸어가면 0이 서서히 1로 바뀝니다. 대가도 있습니다. 구름 어디서 뽑아도 같은 그림을 내야 하니 복원이 조금 흐립니다. 복원 오차는 오토인코더 1.85, VAE 2.10이었습니다.

## 8. 어디에 쓰나

VAE 계열은 그림 압축에 많이 쓰입니다. Stable Diffusion은 512 곱하기 512 그림을 64 곱하기 64 곱하기 4로 줄이는 오토인코더를 쓰는데, VAE와 비슷하게 KL 벌점을 줍니다. 2018년에는 분자를 잠재 공간에 넣고 좋은 성질 쪽으로 걸어가며 새 분자를 설계하는 연구도 나왔습니다. 잘 되살리지 못하는 데이터를 이상한 데이터로 보는 이상 탐지에도 쓰입니다. 약점은 그림이 흐리다는 건데, 선명한 생성은 다음 덱의 GAN과 확산 모델이 맡습니다.

## 9. 문제풀이

1번 답. 뮤 0, 시그마 2면 2분의 1 곱하기 0 더하기 4 빼기 1 빼기 1.386, 약 0.81입니다. 뮤 2, 시그마 1이면 2분의 1 곱하기 4, 2입니다. 2번 답. 1 더하기 0.5 곱하기 2는 2, 마이너스 1 더하기 2 곱하기 0.5는 0, z는 2, 0입니다. 3번 답. 구름을 점으로 줄여도 벌점이 없으니 시그마가 0으로 가서 오토인코더와 같아지고, 지도도 제멋대로 퍼집니다. 4번 답. 모든 구름이 N 0 1에 겹쳐 그림 정보를 담지 못하니, 복원이 모두 비슷한 흐린 평균 그림이 됩니다.

## 10. 실습

실습은 세 부분입니다. 첫째, KL을 손으로 계산하고 재매개변수화를 확인합니다. 둘째, 손글씨 숫자로 오토인코더와 VAE를 학습해 2칸 지도를 비교합니다. 셋째, N 0 1에서 뽑아 되살리고, 지도 격자를 그리고, 0에서 1로 걸어 봅니다.

## 11. 정리

정리합니다. VAE는 그림을 평균과 퍼짐을 가진 구름으로 줄이고, 구름에서 뽑은 점으로 그림을 되살립니다. 손실은 복원 오차와, 구름을 N 0 1 쪽으로 당기는 KL입니다. 그 결과 오토인코더의 지도는 제멋대로였지만 VAE의 지도는 평균 0, 퍼짐 1에 가까워져, N 0 1에서 뽑으면 열 종류 숫자가 모두 나왔습니다. 대가는 조금 흐린 그림입니다.
