\begin{frame}{FAQ: DAgger 13회, 1000개 시연, 셋 비교}
  \small
  \begin{itemize}
    \item \textbf{Q: 교란 실험에서 DAgger도 위험칸에 13번 — 해결이면
      0이 되어야?} A: 해결이 아니라 \textbf{완화}. 15\% 교란은
      5스텝 샘플링에서 지나가지 않은 단일 사건(예: $(1,3)$에서
      'left'로 $(1,2)$ 직행)을 남김. 13회 = \textbf{방문 기반
      라벨링의 본질적 한계} — BC+RL(12.3)이 남은 이유.
    \item \textbf{Q: 시연 1000개 모으는 게 더 간단하지 않나?}
      A: \textbf{누가} 달리는가가 분포를 결정 — 시연 1000개는
      \textit{전문가} 정책의 경로. 학생 정책의 ``(1,3) 벽 막힘''
      패턴은 전문가가 한 번도 빠지지 않으므로 라벨 없음.
      \textbf{비용}도 학생이 방문한 상태 수만큼의 라벨이 훨씬 적음.
    \item \textbf{Q: DAgger(12.1) / 선호 기반(12.2) / BC+RL(12.3)
      정리?} A: 사람이 주는 \textit{것}이 다르면 알고리즘이 다름 —
      (상태, 정답 행동)$\to$DAgger(상한=전문가); (두 시도 중 더
      나은 쪽)$\to$선호 기반 보상모델(PPO로 \textbf{전문가 초월
      가능}); 보상함수만 $\to$순수 RL.
  \end{itemize}
\end{frame}
