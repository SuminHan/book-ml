      \begin{itemize}
        \item (좌) PR 곡선에서 \textbf{점선} = ``무조건 0'' 모델의
          PR-AUC (= 양성 비율 0.15).
        \item (우) ROC 곡선에서 \textbf{점선} = 무작위 모델
          (ROC-AUC=0.5).
        \item 모델 곡선이 점선보다 \textbf{위에 있는지} 보기 ---
          이 차이가 ``모델이 양성의 \textbf{순서}를 얼마나 잘
          짜는지''를 보여준다.
      \end{itemize}
