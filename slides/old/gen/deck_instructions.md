# 주차별 강의 슬라이드 생성 지시 (KSA ML1/ML2, 한국어)

너는 교재 본문 마크다운을 **한 주차(=한 챕터) 분량의 beamer 강의 슬라이드**
`.tex` 파일 하나로 변환한다. 이 파일에 적힌 규칙을 그대로 따르고, **결과로
`.tex` 파일 하나만** 지정된 경로에 쓴다. 설명/잡담 출력 금지.

## 분량 (중요)

- 한 챕터 = **3차시 = 3시간** 수업. 각 차시(= `chapterNN/1.md`, `2.md`, `3.md`
  … 각 파일)는 **1시간 분량**.
- 차시 1개당 **본문 프레임 16~22개**. 3차시면 **총 50~66 프레임** 목표
  (4차시 챕터는 65~85). 제목/섹션 구분 슬라이드는 이 수에 안 셈.
- 절대 20~30장으로 축소하지 말 것. 교재의 모든 `###` 소제목은 최소 1프레임,
  긴 소제목(설명 30줄 이상)은 2~3프레임으로 나눈다.

## 파일 골격 (이 그대로, 다른 패키지 추가 금지)

```
\documentclass[aspectratio=169,11pt]{beamer}
\input{../theme/ksa-theme.tex}

\title{<챕터 제목에서 "Chapter N." 떼고 한국어 부분만>}
\subtitle{<차시 3개를 " · "로 이은 한 줄 요약>}
\author{<Machine Learning 1 또는 2> \,\textperiodcentered\, <N>주차}
\institute{한국과학영재학교 (KSA)}
\date{Chapter <N>}

\begin{document}
\begin{frame}[plain,noframenumbering]\titlepage\end{frame}

\begin{frame}{이번 주차 개요}
  ... 개요 파일(chapterNN.md)의 "이 챕터를 마치면 …" 목표 + 세 차시 한 줄 요약 ...
\end{frame}

\section{<N.1 차시 제목>}
  ... 16~22 프레임 ...
\section{<N.2 차시 제목>}
  ... 16~22 프레임 ...
\section{<N.3 차시 제목>}
  ... 16~22 프레임 ...

\begin{frame}{이번 주차 정리}
  ... 차시별 핵심 2~3개씩 + 다음 주차 예고 ...
\end{frame}
\end{document}
```

- `\section{}` 은 차시(하위 .md 파일) 1개당 정확히 1개. 제목은 교재 절 번호를
  살려서 예: `\section{2.1 선형회귀: 모델, 비용함수, 경사하강법}`.
- 테마(`../theme/ksa-theme.tex`)가 폰트·색·푸터·섹션 구분 슬라이드를 전부
  제공한다. **네가 `\usepackage`, `\setbeamer*`, 색 정의를 추가하면 안 된다.**

## 내용 변환 규칙 (교재에 충실하게)

- 교재 문장을 슬라이드 불릿으로 압축하되 **개념·예시·수치·역사 일화·"자주 하는
  실수"·실습**을 빠뜨리지 말 것. 새로운 내용을 지어내지 말 것.
- 프레임당 불릿 5~8줄, 한 줄 25자 이내 권장. 길면 프레임을 쪼갠다.
- 프레임 제목은 짧게(한 줄). 교재 `###` 소제목을 다듬어 쓴다.
- **수식**: 교재의 `\\( ... \\)` → `$ ... $`, `\\[ ... \\]` → `\[ ... \]`.
  수식 내용은 그대로. 깨진 이스케이프 고칠 것(`\\_` → `_`).
- **표**: 교재의 마크다운 표는 `tabular`(booktabs: `\toprule\midrule\bottomrule`)
  로 옮긴다. 열이 많으면 `\small`/`\scriptsize`.
- **코드**: 교재의 python 코드블록은 `\begin{frame}[fragile]` + `lstlisting`
  으로 **거의 그대로**. 한 프레임에 안 들어가면 핵심 부분만.
- **비교/대조**(생성 vs 판별, MC vs TD, B/D/E …)는 `columns` 2단으로.
- **정의·핵심 요약·원칙**은 `block` 환경으로.
- **핵심 질문**(교재에서 굵게 강조된 질문)은 `\kq{...}` (빨강).
  **핵심 용어 최초 등장**은 `\kb{...}` (파랑).
- **각주 참조 `[^xxx]` 는 전부 삭제**. 교재가 특별히 강조한 논문만
  본문에 "(저자, 연도)" 로 짧게. 그 외 참고문헌 나열 금지.

## 그림

- 교재 본문의 `![설명](../../images/NAME.svg)` 또는 `.png` 만 사용 가능.
  슬라이드엔 `\includegraphics[width=...\linewidth]{NAME.png}` 로 쓴다
  (확장자는 항상 `.png`, 경로 접두사 없이 파일명만).
- 스케줄러가 `NAME` 을 `../kor/src/images/` 에서 찾아 흰 배경 PNG로 변환한다.
  **교재에 실제로 링크된 그림만** 참조할 것. 없는 파일명 지어내면 빌드 깨짐.
- Colab 배지(`colab.research.google.com/...`) 는 그림이 아니므로 무시.
- 그림은 보통 2단 레이아웃의 한 열에 넣고, 옆 열에 1~2줄 캡션/해설.

## 반드시 지킬 것 (빌드 안정성)

- `lstlisting` 있는 프레임엔 **반드시 `[fragile]`**.
- `%`, `&`, `_`, `#`, `$` 등 특수문자를 본문 텍스트로 쓸 땐 이스케이프.
- **수식 명령은 수식 안에서만**: `\to \Rightarrow \mid \times \le \ge \sim \cdot
  \quad \; ^ _ \leftrightarrow` 등을 본문(수식 밖)에 쓰지 말 것. 필요하면
  `$\to$`, `$\Rightarrow$` 처럼 `$...$` 로 감싼다. 구분자는 본문에선 그냥 `|` 나
  `,` 를 써라.
  - **특히 `\;\Rightarrow\;` / `\;\to\;` 같은 화살표 연결어를 본문에 쓰지 말 것**
    — 반드시 `$\Rightarrow$` (앞뒤 공백은 보통 띄어쓰기로 충분). `\;` 는 절대
    본문에 단독으로 쓰지 마라 (컴파일이 깨진다).
- **`\texttt{...}` 안의 `_` `#` `%` `&` 는 반드시 이스케이프**:
  `\texttt{env.action\_space.sample()}` (raw `_` 금지). `\pi^*` 는 `\pi^{*}` 로.
- **`\verb` 를 프레임 제목(`\begin{frame}{...}`)에 쓰지 마라** — `\texttt{}` 를 써라.
  `\verb` / `lstlisting` 을 쓰는 프레임은 반드시 `\begin{frame}[fragile]{...}`.
- 프레임이 넘치면(내용 과다) 나눈다. `\small`/`\scriptsize` 로 우겨넣지 말 것.
- 출력은 지정 경로의 `.tex` **파일 하나뿐**. 컴파일·그림 변환은 스케줄러가 한다.

## 스타일 예시

`gen/REFERENCE-deck.tex` 가 이 테마로 만든 짧은 예시 덱이다(1차시 분량, 20프레임).
프레임 구성·매크로 사용법·표/코드/2단/블록 패턴을 여기서 참고하되, **분량은 이보다
2.5~3배로**(위 "분량" 규칙) 만든다.
