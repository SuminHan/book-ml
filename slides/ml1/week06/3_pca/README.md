# PCA 주성분 분석

- 원본 쇼츠: [`lessons/ml1/pca/`](../../../../../lessons/ml1/pca/README.md)
- 구성: 학생 20명 수학 · 물리 → 그림자 (수학 축 59% vs 대각선 95%) → 각도별 퍼짐 곡선 → PC1 · PC2 의 뜻 → 식 Su = λu (λ 351.2 · 19.0, 손 계산 2×2) → 절차 · 표준화 (붓꽃 97.8% vs 95.9%) → 붓꽃 평면 → 숫자 64 → 21개 90%, 2개 28.5% → 고유얼굴 · 유전체 · 한계 + 문제풀이
- 상태: 13쪽. 데이터는 data.py 안에서 바로 계산 (sklearn iris · digits)
- 실습: 각도별 퍼짐 · 직접 고유분해 · sklearn 비교 · 붓꽃 표준화 전후 · 숫자 압축 복원
