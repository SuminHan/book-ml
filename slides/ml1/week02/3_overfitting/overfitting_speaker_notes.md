# 발표자 노트: overfitting

번호는 슬라이드 하단 번호입니다 (표지 제외).

## 1. 오늘의 실험 질문

오늘 3차시는 실험 시간입니다. 1차시에 선형회귀로 직선을 그었고, 오늘은 곡선을 점점 복잡하게 만들어 봅니다. 화면의 빨간 곡선은 측정한 점 10개를 하나도 빠짐없이 지나갑니다. 측정 데이터에서는 오차가 0입니다. 그러면 이 모델이 처음 보는 속도의 제동거리도 잘 맞힐까요? 오늘은 제가 답을 알려 주지 않고, 여러분이 실험으로 찾습니다. 끝나면 결과 표 하나와 해석 한 문단을 냅니다.

## 2. 실험 재료: 제동거리 데이터

실험 재료는 자동차 제동거리입니다. 속도를 바꿔 가며 10번 잰 측정 데이터가 있고, 모델을 다 만든 뒤에 새로 잰 데이터 6개가 따로 있습니다. 측정 데이터로 모델을 만들고, 새 데이터로 시험합니다. 회색 점선은 물리 법칙인데, 오늘은 이 법칙을 모른다고 치고 점만 보고 모델을 고릅니다. 30킬로에서 0미터처럼 이상한 점도 있는데, 실제 측정에도 이런 잡음은 늘 섞입니다.

## 3. 실험 전에: 가설을 먼저 적습니다

실험을 시작하기 전에 가설을 먼저 적습니다. 직선, 2차 곡선, 9차 곡선 중 새 데이터를 가장 잘 맞힐 모델은 무엇일까요? 고른 모델과 이유 한 줄을 노트북 맨 위 가설 칸에 적으세요. 틀려도 감점은 없습니다. 다만 실험 후에 고치면 안 됩니다. 가설과 결과가 다를 때 왜 달랐는지를 쓰는 게 오늘 해석 문단의 핵심입니다. 논문도 이렇게 씁니다.

## 4. 실험 절차 (50분)

실험은 세 개입니다. 실험 1에서는 다항식 차수를 1차부터 9차까지 올리면서 측정 데이터 오차와 새 데이터 오차를 표에 적습니다. 실험 2에서는 새 데이터가 아직 없다고 치고, 측정 데이터만으로 차수를 고르는 방법을 해 봅니다. 실험 3에서는 1920년대에 실제로 잰 자동차 50대 데이터에서 같은 방법으로 차수를 고릅니다. 마지막 5분은 해석을 씁니다. 오차는 평균 절대 오차로 잽니다. 예측과 실제의 차이에 절댓값을 씌워 평균 낸 값이라, 단위가 미터 그대로입니다.

## 5. 실험 1 & 2: 이 표를 채웁니다

실험 1과 2에서 채울 표입니다. 노트북은 1차부터 9차까지 전부 출력하지만, 표에는 1, 2, 3, 9차만 옮겨 적습니다. 실험 1이 끝나면 측정 데이터 오차에서 1등인 모델과 새 데이터 오차에서 1등인 모델이 같은지 확인해 보세요. 같지 않다면, 왜 다른지가 오늘의 핵심 질문입니다.

## 6. 실험 2의 방법: 5겹 교차 검증

실험 2의 방법입니다. 실제로 모델을 고를 때는 새 데이터가 아직 없습니다. 미래의 데이터니까요. 그래서 가진 데이터 일부를 숨겨 두고, 나머지로 학습한 다음 숨긴 데이터로 시험합니다. 점이 10개뿐이라 한 번만 숨기면 운에 따라 결과가 크게 바뀌니까, 2개씩 5조각으로 나눠서 돌아가며 숨깁니다. 다섯 번의 오차 평균이 교차 검증 오차입니다. 노트북에서 이 반복문의 빈칸 두 줄을 채우면 됩니다. 교차 검증 오차가 실험 1의 새 데이터 오차와 비슷한 모양을 그리는지 보세요.

## 7. 제출: 결과 표 + 해석 한 문단

제출물은 결과 표와 해석 한 문단입니다. 해석 문단에는 네 가지가 들어갑니다. 가설과 결과를 비교하고, 왜 그런 결과가 나왔는지 쓰고, 교차 검증이 무엇을 골랐는지, 실제 자동차 데이터에서는 어땠는지. 화면의 틀을 그대로 써도 됩니다. 숫자는 반드시 직접 실행한 결과를 씁니다. 이게 프로젝트 보고서의 결과와 분석 절을 아주 작게 연습하는 것입니다.

## 8. 실험이 끝난 뒤: 여러분이 본 것의 이름

실험이 끝난 뒤에 보여 주는 쪽입니다. 여러분이 표에서 본 것에 이름을 붙입니다. 직선은 측정 데이터 오차도 새 데이터 오차도 둘 다 컸습니다. 너무 단순해서 가진 데이터조차 못 따라간 것이고, 이걸 과소적합이라고 합니다. 9차 곡선은 측정 데이터 오차가 0인데 새 데이터 오차가 컸습니다. 측정한 점을 외워 버린 것이고, 이걸 과대적합이라고 합니다. 가운데 2차 곡선이 그 사이의 알맞은 복잡도입니다.

## 9. 실험 후: 차수를 1부터 9까지 놓고 보면

1차부터 9차까지 한 그래프에 모았습니다. 측정 데이터 오차는 차수를 올릴수록 계속 줄어서 9차에서 0이 됩니다. 반면 교차 검증 오차는 U자 모양이고, 3차가 2.5미터, 2차가 3.3미터로 바닥입니다. 점이 10개뿐이라 이 정도 차이는 잡음 수준이고, 비슷하면 더 단순한 2차를 고르는 게 보통입니다. 실제 물리 법칙도 2차입니다. 새 데이터 오차도 같은 U자를 그립니다. 교차 검증이 새 데이터 오차를 잘 흉내 낸다는 뜻입니다. 학습에 쓴 데이터의 오차로는 모델을 고를 수 없다, 이게 오늘의 결론입니다.

## 10. 더 생각해 볼 것: 9차를 넘어 계속 키우면?

질문 하나를 남깁니다. 9차가 새 데이터에서 9.1미터로 가장 나빴으니 더 키우면 더 나빠질까요? 실제로 해 보면 그렇지 않습니다. 10차부터는 계수가 점보다 많아서 모든 점을 지나는 곡선이 무수히 많고, 그중 계수가 가장 작은 곡선을 고르면 새 데이터 오차가 16차에서 3.9미터까지 다시 내려갑니다. 이걸 이중 하강이라고 부르고, 15주차에 큰 신경망과 함께 다시 다룹니다.

## 11. 정리

정리합니다. 과소적합은 너무 단순해서 가진 데이터도 못 따라가는 것, 과대적합은 가진 데이터를 외워서 새 데이터를 틀리는 것입니다. 학습에 쓴 데이터의 오차는 외울수록 작아지니까 모델을 고르는 기준이 될 수 없고, 그래서 교차 검증으로 고릅니다. 5주차에 정규화와 함께 교차 검증을 다시 자세히 다룹니다.
