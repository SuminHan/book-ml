# 커널 SVM (2차시)

- 1차시 선형 SVM 덱 [`../2_svm/`](../2_svm/README.md) 의 커널 부분을 나눠 만든 덱 (2026-11-21). 기준은 1차시와 같다 (‖w‖ = 1, α 는 부호 포함).
- 구성 (27쪽): 지난 시간 그림 세 장 (경계 값 = 거리 · 최대 마진 0.67 · 소프트 마진 λ = 5) → 오늘의 질문 (원 데이터, 직선 SVM 59%) → 1차원 x → (x, x²) (높이 0.5 직선 = 원래 자리 ±0.71 구간) → 2차원 → 3차원 높이 → w 는 학습 점을 더한 것 = 지난 시간 학습을 α 로 (민 양, 안 미는 점은 0 으로) → α 가 쌓이는 그림 (0.74 · −0.37 · −0.37) → w = 서포트 벡터끼리의 화살표 0.37 [(r − b1) + (r − b2)] → w = Σα x 를 분류기에 (★ 0.18) → 커널 K (두 길 그림 25) → 커널 SVM 학습 (점곱 자리에 K, 원 · 다항 마진 0.20 = sklearn) → 자주 쓰는 커널 → 선형 · 다항 · RBF 특징 수 2 · 6 · ∞ → (1 + x·x′)² 펼치기 → 1차원 커널 식 풀기 (점 2개 → 0.75 − x − x², 차원 올리는 계산 없음) → α 3개 → 계수 6개 (0.6, −0.2, 2.2, −1.3, 0.8, 2.1, 확인 4.2) → A 특징 직접 (w 6개) vs B 커널 (α 120개, 0 아닌 것 21개) 같은 w → RBF 펼치기 → RBF 언덕 → 언덕 150 → 39 → 테일러 → γ 와 차수 → γ → 장단점 → 실습 → 정리
