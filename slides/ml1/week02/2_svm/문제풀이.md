# 02-2 SVM 문제풀이 (덱에서 뺀 것)

덱 기준: 점은 z-score 한 값, 경계 w·x + b = 0 에서 ‖w‖ = 1 (값 = 경계까지 거리), 학습률 η 하나.
덱 원본 프레임은 `_이전/svm_문제풀이_frames_v1.tex`.

## 문제

1. 1차원 점: 빨강 x = 0.5, 1.5, 파랑 x = −1.5, −0.5.
   (a) 최대 마진 경계와 마진 m 은? (b) 서포트 벡터는?
2. 경계 0.6x1 + 0.8x2 − 1 = 0.
   (a) ‖w‖ 는? (b) 점 (1, 1) 에서 경계까지 거리는?
3. 학습 정확도 100%, 검증 정확도 70% 인 RBF SVM. sklearn 의 C 와 γ 를 어느 쪽으로 바꿔 보겠나?
4. x = (2, 0), x′ = (1, 3) 일 때 (x·x′)² 와 φ(x)·φ(x′) 를 각각 계산해 같은지 확인하라. (φ(x) = (x1², √2·x1x2, x2²))
5. 클래스 5개를 SVM 으로 분류한다. 일대일 · 일대다는 각각 SVM 이 몇 개 필요한가?

### 학습 한 걸음 손으로

빨강 (y = +1): A(1.5, 0), B(0, 1.5) / 파랑 (y = −1): C(0, −1.5)
지금 선: w = (0, 1), b = 0.5 (x2 = −0.5), η = 0.5

- (a) 세 점의 값 yᵢ(w·xᵢ + b) 와 m 은? 어느 점이 미나?
- (b) w′ = w + η·y_k·x_k, b′ = b + η·y_k 를 계산하라.
- (c) ‖w′‖ 는? 길이 1 로 맞추면 w, b 는?
- (d) 새 선에서 세 점의 값과 m 은? 다음 걸음엔 어느 점이 미나?

## 답

1. 가장 가까운 두 점이 −0.5 와 0.5 → 경계 0, m = 0.5, 길 폭 1. 서포트 벡터는 −0.5 와 0.5.
2. ‖w‖ = √(0.36 + 0.64) = 1 → 값이 곧 거리: 0.6 + 0.8 − 1 = 0.4.
3. 과대적합 → C 와 γ 를 둘 다 줄여 본다.
4. x·x′ = 2 → 제곱 4. φ(x) = (4, 0, 0), φ(x′) = (1, 3√2, 9) → 점곱 4. 같다.
5. 일대일 5·4/2 = 10개, 일대다 5개.

학습 한 걸음:

- (a) A: 0 + 0.5 = 0.5, B: 1.5 + 0.5 = 2, C: −(−1.5 + 0.5) = 1 → m = 0.5, A 가 민다.
- (b) w′ = (0, 1) + 0.5·(1.5, 0) = (0.75, 1), b′ = 0.5 + 0.5 = 1.
- (c) ‖w′‖ = √(0.5625 + 1) = 1.25 > 1 → w = (0.6, 0.8), b = 0.8. 선 0.6x1 + 0.8x2 + 0.8 = 0.
- (d) A: 0.9 + 0.8 = 1.7, B: 1.2 + 0.8 = 2, C: −(−1.2 + 0.8) = 0.4 → m = 0.4 로 오히려 줄었다 (A 에서 너무 멀리 밀어 C 쪽으로 넘어감). 다음엔 C 가 민다. 그래서 학습률을 걸음마다 줄인다.
