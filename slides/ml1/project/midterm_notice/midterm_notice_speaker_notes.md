# 발표자 노트: midterm_notice

번호는 슬라이드 하단 번호입니다 (표지 제외).

## 1. 프로젝트 한눈에 보기

중간 프로젝트를 공지합니다. 실제 표 데이터 하나를 골라서, 1주차부터 7주차까지 배우는 고전 머신러닝 모델을 적용하고 비교하는 팀 프로젝트입니다. 도구는 사이킷런 안에서 해결합니다. 신경망도 사이킷런의 MLP까지는 써도 됩니다. 목표는 높은 성능이 아닙니다. 성능 숫자를 정직하게 얻는 절차를 직접 해 보고, 이 숫자를 믿어도 되는지 스스로 따져 보는 것입니다. 진행은 데이터 선정, Abstract, 구현과 검증, 보고서, 동료평가 순서입니다.

## 2. 일정과 마감

일정입니다. 1, 2주차에 팀을 만들고 KSA Review에 회원가입하고, 데이터 후보를 두세 개 찾습니다. 3주차에 Abstract 한 쪽을 냅니다. 4주차와 5주차에 구현하고 검증하는데, test는 마지막에 딱 한 번만 씁니다. 6주차에 보고서와 코드를 내고, 7주차에 배정된 보고서를 읽고, 8주차에 두 팀의 보고서를 심사합니다. 마감 시각과 제출 방법은 따로 안내하겠습니다.

## 3. 꼭 지켜야 할 다섯 가지

꼭 지켜야 할 것이 다섯 가지 있습니다. 첫째, 정형 데이터 하나를 고릅니다. 이미지나 텍스트는 기말 프로젝트에서 합니다. 둘째, 서로 다른 모델 두 가지 이상을 같은 데이터, 같은 분할, 같은 지표로 비교합니다. 셋째, 결과를 수식으로 설명하는 부분이 하나 이상 있어야 합니다. 넷째, 데이터를 셋으로 나누고, 전처리는 학습 데이터로만 맞추고, test는 딱 한 번만 씁니다. 다섯째, 학습 곡선을 반드시 넣습니다. 최종 숫자만 있으면 하이퍼파라미터를 어떻게 골랐는지 확인할 수 없기 때문입니다.

## 4. 데이터 고르기: 다섯 가지 기준

데이터를 고를 때 다섯 가지를 먼저 봅니다. 행 하나가 무엇인지 한 문장으로 말할 수 있어야 합니다. 같은 사람이나 같은 물건이 여러 행에 나오면, 무작위로 나눌 때 같은 대상이 학습과 시험에 함께 들어가서 누수가 생깁니다. 이때는 그룹 단위로 나눕니다. 시간 순서가 있으면 시간 순서대로 나눕니다. 클래스 비율이 한쪽으로 크게 치우쳤으면 정확도 대신 PR-AUC나 재현율을 씁니다. 크기는 500에서 1만 행 정도가 다루기 편합니다.

## 5. 데이터는 어디서 찾나: 데이터샵과 데이터 월드컵

데이터는 데이터샵에서 찾는 걸 추천합니다. 신용카드 연체, 통신사 이탈, 호텔 예약 같은 산업 현장의 데이터가 있고, 데이터마다 행의 단위, 라벨, 크기, 클래스 비율, 알려진 함정이 정리되어 있습니다. 노트북을 받아서 직접 열어 보세요. 뭘 고를지 모르겠으면 데이터 월드컵에서 32개 데이터를 이상형 월드컵처럼 비교하고, 우승과 4강 데이터를 팀 회의 후보로 쓰면 됩니다. 캐글이나 UCI에서 찾은 데이터도 같은 다섯 가지 기준으로 직접 확인합니다.

## 6. 3주차 Abstract (1쪽)에 들어갈 것

3주차에 내는 Abstract에는 다섯 가지가 들어갑니다. 문제 정의, 데이터, 베이스라인, 계획, 예상되는 위험입니다. 특히 베이스라인이 중요합니다. 항상 다수 클래스로 답하는 모델이 몇 점인지 알아야, 우리 모델이 의미 있는 일을 했는지 판정할 수 있습니다. 익명 심사이므로 팀원 이름은 적지 않습니다. 형식은 샘플을 참고하세요.

## 7. 6주차 보고서의 구조

6주차에 내는 보고서의 구조입니다. 일곱 개 절과 부록입니다. 각 절에 무엇을 쓰는지, 분량은 어느 정도인지 표에 정리했습니다. 7절 한계는 필수입니다. 잘 안 된 게 없었다면, 시도했다가 안 된 것을 적으세요. 부록에는 AI 사용 내역과 인용 근거 표를 붙이는데, 쪽수에는 넣지 않습니다. 자세한 작성법은 보고서 작성 가이드에 있습니다.

## 8. 채점 기준: 다섯 항목 각 20%

채점은 다섯 항목을 20퍼센트씩 봅니다. 주장의 명확성, 비교 대상, 확장성, 재현성, 한계의 솔직함입니다. 성능 점수 항목은 없습니다. 오히려 성능이 낮아도 한계를 정직하게 진단하면 높은 점수를 받습니다. 반대로 숫자가 좋아 보여도 test를 두 번 썼거나, 비교 대상이 없거나, 재현이 안 되면 크게 감점합니다. 이 다섯 항목은 동료평가에서 리뷰어가 보는 기준과 같습니다.

## 9. 8주차 동료평가

8주차에는 동료평가를 합니다. 배정된 다른 팀 보고서 두 편을 KSA Review에서 심사합니다. 리뷰 양식은 요약, 장점, 약점, 질문, 점수, 확신도이고, 필수 확인 두 가지가 있습니다. 핵심 인용 하나를 원문에서 확인하고, 그 팀의 Colab을 실행해서 숫자 하나를 재현해 봅니다. 리뷰 점수는 리뷰를 받은 팀이 매기는 도움 점수와 필수 확인, 수업 중 무작위 확인으로 정합니다. 자세한 방법은 리뷰 가이드에 있습니다.

## 10. 팀 구성 · 제출 방법 · 함께 볼 자료

팀 구성과 제출 방법, 마감 시각은 따로 안내하겠습니다. 이 공지와 함께 볼 자료가 세 가지 있습니다. 보고서 작성 가이드, 리뷰 가이드, 그리고 Abstract와 보고서, 리뷰를 어떤 형식으로 쓰는지 보여 주는 샘플입니다. 모두 수업 홈페이지 오른쪽 일정 줄에 있습니다.
