# 4.2 정책 반복과 GridWorld 실습

### 정책 반복

**정책 반복**(Policy Iteration)은 최적해를 향해 두 단계를 번갈아
반복한다:

1. **정책평가**: 현재 정책 \\(\pi\\)의 \\(V^\pi\\)를 계산한다(4.1절).
2. **정책개선**: 각 상태에서, \\(V^\pi\\) 기준으로 더 나은 행동이 있으면
   정책을 그 행동으로 바꾼다: \\(\pi'(s) = \arg\max_a[R(s,a) + \gamma
   \sum_{s'} P(s'|s,a) V^\pi(s')]\\).

정책이 더 이상 안 바뀔 때까지 반복하면 최적 정책에 도달한다.

### 실습: 5칸짜리 GridWorld에서 정책 반복 직접 돌려보기

한 줄로 늘어선 5개의 칸(0~4) 위에서, 왼쪽/오른쪽으로만 움직일 수 있고
칸 4에 도달하면 끝나는(보상 0) 아주 작은 GridWorld를 만들어보자. 그
외의 모든 이동은 보상 -1이다(한 걸음씩 벌점을 받는 셈이라, 최단
경로로 목표에 도달하는 정책이 최적이 된다).

```python
n_states, n_actions, gamma = 5, 2, 0.9  # action 0=left, 1=right
P, R = {}, {}
for s in range(n_states):
    P[s], R[s] = {}, {}
    for a in range(n_actions):
        if s == 4:
            P[s][a], R[s][a] = [(1.0, 4)], 0.0   # 목표 칸은 종료 상태
        else:
            ns = max(0, s-1) if a == 0 else min(4, s+1)
            P[s][a], R[s][a] = [(1.0, ns)], -1.0

def policy_iteration(P, R, n_actions, gamma):
    policy = [1] * n_states  # 처음엔 무조건 오른쪽으로만 가는 정책에서 시작
    while True:
        V = policy_evaluation(P, R, policy, gamma)
        stable = True
        for s in range(n_states):
            best_a = max(range(n_actions),
                         key=lambda a: R[s][a] + gamma * sum(p*V[ns] for p, ns in P[s][a]))
            if best_a != policy[s]:
                policy[s] = best_a
                stable = False
        if stable:
            return V, policy
```

실행 결과(스크래치패드에서 검증):

```
V = [-3.439, -2.710, -1.900, -1.000, 0.000]
policy = [1, 1, 1, 1, 0]  # 모든 칸에서 "오른쪽"이 최적(목표 칸 0은 종료라 의미 없음)
outer 반복 횟수: 2,  내부 정책평가 sweep 총합: 10
```

시작 정책이 이미 "무조건 오른쪽"이라 사실 첫 정책평가에서 곧바로
최적 정책이 나왔고, 정책개선 단계에서 "더 바꿀 게 없다"는 것만 한
번 더 확인하고 끝났다 — 정책 반복이 얼마나 빨리 수렴하는지는 초기
정책을 얼마나 잘 골랐는지에 따라 크게 달라진다는 것을 보여주는
예시이기도 하다. \\(V(0)=-3.439\\)는 칸 0에서 목표(칸 4)까지 최단
경로로 4번 이동해야 하는 비용(\\(-1-0.9-0.81-0.729\approx-3.439\\))과
정확히 일치한다 — 손으로 검산해볼 만하다(연습문제 2번과 같은 구조).

### 자주 묻는 질문

**Q. 정책개선 단계에서 "더 나은 행동"이 여러 개 동점이면 어떻게
하나요?** 이론적으로는 동점인 행동 중 아무거나 골라도 정책개선의
성질(가치가 감소하지 않는다)은 그대로 유지된다. 실전 구현에서는
`max`가 첫 번째로 만나는 최댓값을 반환하므로, 행동 순서에 따라 결과
정책이 달라질 수 있지만 그 가치(\\(V\\))는 항상 같다.

**Q. 정책 반복은 항상 정책평가를 끝까지(수렴할 때까지) 해야 하나요?**
아니다 — 정책평가를 완전히 수렴시키지 않고 몇 번만 돌린 뒤 바로
정책개선으로 넘어가도 여전히 결국 최적 정책에 수렴한다는 것이 알려져
있다(**수정된 정책 반복**, modified policy iteration). 극단적으로
정책평가를 **딱 한 번**만 하고 바로 개선하는 것을 반복하면, 다음
절에서 배울 가치반복과 정확히 같아진다.
