# Introduction

**Machine Learning 2**는 KSA의 3-1-3 심화 선택 과목으로, [Machine
Learning 1](https://smhanlab.com/book-ml/kor/ml1/)의 신경망 기초를 이어
받는 후속 과목이다. 이 교재는 한국어판이며, 같은 구조의 [English
edition](https://smhanlab.com/book-ml/eng/ml2/)이 별도로 있다 — 어느
쪽을 읽어도 같은 내용을 배운다. ML1을 듣지 않고 이 과목을 바로 들어도
무방하다 — 1주차가 이 학기에서 필요한 신경망 기초를 압축해서 다시 짚어준다.

## 이 과목에서 배우는 것

**ML2**는 강화학습을 멀티암 밴딧과 MDP부터 제대로 시작해, 동적계획법 →
몬테카를로 → 시간차 학습 → n-step/적격흔적/Dyna-Q로 표 기반 방법의
이론을 다진다. 이어서 함수근사와 DQN, 정책기반 강화학습(REINFORCE,
Actor-Critic), PPO로 심층강화학습을 배우고, 모방학습·인간 피드백
(RLHF)까지 다룬 뒤, 이 모든 걸 로봇 시뮬레이션(MuJoCo, Isaac Sim)이라는
실제 무대에 적용한다. 마지막엔 모델기반 강화학습과 몬테카를로 트리
탐색(MCTS, AlphaGo/AlphaZero)으로 마무리한다. 이 과목은 강화학습·로봇
시뮬레이션 전용이며, 지도학습·비지도학습·생성모델은 [Machine Learning
1](https://smhanlab.com/book-ml/kor/ml1/)에서 다룬다.

## 이 교재의 구성

각 장은 하나의 페이지 안에 번호가 매겨진 절(예: 2.1, 2.2, ...)로 이루어진
진짜 교과서 형태를 따른다 — 절 번호는 그 장이 다루는 실제 주차 번호를
따르며, 사이드바에 표시되는 챕터 번호와는 무관하다.

각 장은 다음 흐름을 따른다:

- **도입부**: 그 장에서 배우는 개념이 왜 중요한지 보여주는 짧은 실제
  사례나 역사적 일화.
- **본문 절들**: 개념·수식·예시 코드를 순서대로 쌓아가는 설명.
- **연습문제**: 장 끝에 코딩 문제(빈칸 채우기 스텁)와 손유도 과제가
  실습시간 1학점 분량으로 정리돼 있다.

## 손유도 과제 난이도 등급

연습문제의 손유도 과제는 난이도에 따라 세 등급으로 나뉜다:

| 등급 | 의미 |
|---|---|
| **Tier A** (자유 유도) | 선수지식으로 충분히 감당 가능 — 그대로 진행 |
| **Tier B** (적정하나 주의) | 진행하되 힌트를 제공 |
| **Tier C** (폴백 필요) | 자유 유도 버전과 빈칸채움형 워크시트 버전을 모두 준비 — 학생 반응을 보고 선택 |

## 평가

In-class 20% + Assignment 20% + Final 50% + Attendance 10%. 기말고사는
CS1/2식 "빈칸채우기 코드완성"에 더해, 최소 2~3문항은 그래디언트 유도·
손실함수 성질 증명·알고리즘 정확성 논증 같은 증명형 문항으로 구성된다.
