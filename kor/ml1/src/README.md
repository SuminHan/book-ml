# Introduction

**Machine Learning 1**은 KSA의 3-1-3 심화 선택 과목으로, CS1/CS2와 Math
for ML(선형대수·확률통계 기초)을 선수과목으로 삼는다. 이 교재는
한국어판이며, 같은 구조의 [English
edition](https://smhanlab.com/book-ml/eng/ml1/)이 별도로 있다 — 어느
쪽을 읽어도 같은 내용을 배운다. 이 과목의 후속 과목인 [Machine Learning
2](https://smhanlab.com/book-ml/kor/ml2/)는 완전히 독립된 교재로 이어진다.

## 이 과목에서 배우는 것

**ML1**은 데이터사이언스 파이프라인에서 시작해 classical ML(선형/로지스틱
회귀, 나이브베이즈/GDA, kNN/k-means, SVM, 정규화, 트리 기반 모델/GBDT)을
다지고, 신경망·역전파의 기초부터 CNN, 시퀀스 모델(RNN/LSTM), 어텐션과
트랜스포머, LLM(사전학습·프롬프팅·정렬)까지 심화한다. 마지막엔 표현학습
(PCA, word2vec, Node2Vec, PageRank)과 잠재변수 생성모델(EM/GMM, VAE,
GAN, Diffusion)로 마무리한다. 강화학습과 로봇공학은 이 과목에서 다루지
않으며, [Machine Learning 2](https://smhanlab.com/book-ml/kor/ml2/)에서
전용으로 다룬다.

## 이 교재의 구성

각 장은 하나의 페이지 안에 번호가 매겨진 절(예: 2.1, 2.2, ...)로 이루어진
진짜 교과서 형태를 따른다 — 절 번호는 그 장이 다루는 실제 주차 번호를
따르며, 사이드바에 표시되는 챕터 번호와는 무관하다.

각 장은 다음 흐름을 따른다:

- **도입부**: 그 장에서 배우는 개념이 왜 중요한지 보여주는 짧은 실제
  사례나 역사적 일화.
- **본문 절들**: 개념·수식·예시 코드를 순서대로 쌓아가는 설명.
- **연습문제**: 장 끝에 코딩 문제(빈칸 채우기 스텁)와 손유도 과제가
  실습시간 1학점 분량으로 정리돼 있다.

## 손유도 과제 난이도 등급

연습문제의 손유도 과제는 난이도에 따라 세 등급으로 나뉜다:

| 등급 | 의미 |
|---|---|
| **Tier A** (자유 유도) | 선수지식으로 충분히 감당 가능 — 그대로 진행 |
| **Tier B** (적정하나 주의) | 진행하되 힌트를 제공 |
| **Tier C** (폴백 필요) | 자유 유도 버전과 빈칸채움형 워크시트 버전을 모두 준비 — 학생 반응을 보고 선택 |

## 평가

In-class 20% + Assignment 20% + Final 50% + Attendance 10%. 기말고사는
CS1/2식 "빈칸채우기 코드완성"에 더해, 최소 2~3문항은 그래디언트 유도·
손실함수 성질 증명·알고리즘 정확성 논증 같은 증명형 문항으로 구성된다.
