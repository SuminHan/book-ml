# 1.1 머신러닝 문제 정식화와 세 갈래 분류

### 문제를 푸는 게 아니라, 먼저 문제를 "정의"하는 것부터

머신러닝을 처음 배울 때 흔히 하는 착각은 "어떤 알고리즘을 쓸까"부터 고민하는
것이다. 실전에서는 순서가 반대다 — 알고리즘을 고르기 전에, 문제 자체를 다음
세 가지로 명확히 정의해야 한다:

1. **입력(input) \\(x\\)**: 무엇을 특징(feature)으로 쓸 것인가? (예: 집의 평수,
   방 개수, 지어진 연도)
2. **출력(output) \\(y\\)**: 무엇을 맞히고 싶은가? 연속값(회귀)인가, 범주(분류)인가?
3. **가설(hypothesis) \\(h\\)**: 입력에서 출력으로 가는 함수를 어떤 형태로 근사할
   것인가? (직선? 트리? 신경망?)

이 세 가지가 정해지지 않은 채로 "머신러닝으로 풀어보자"고 덤비면, 데이터를
아무리 모아도 무엇을 목표로 학습시켜야 하는지조차 불분명해진다. 부동산 가격을
예측하고 싶다면, \\(x\\)는 평수·방 개수·위치 같은 특징, \\(y\\)는 실제 거래
가격(연속값), \\(h\\)는 이 학기 초반에 배울 선형 함수부터 시작할 수 있다.

**학습(training)**이란, 주어진 데이터 \\((x^{(1)}, y^{(1)}), \ldots,
(x^{(m)}, y^{(m)})\\)에 대해 \\(h(x^{(i)})\\)가 \\(y^{(i)}\\)에 최대한
가깝도록 \\(h\\)의 파라미터를 조정하는 과정이다. 여기서 위 첨자 \\((i)\\)는
"\\(i\\)번째 데이터 샘플"을 가리키는 표기로, 이 학기 내내 반복해서 쓰인다 —
\\(x^{(3)}\\)이라면 세 번째 집의 특징 벡터라는 뜻이다.

### 세 갈래 분류: 무엇을 데이터로 갖고 있는가

머신러닝 문제는 크게 세 갈래로 나뉜다 — 그리고 이 분류는 알고리즘의 이름이
아니라, **어떤 형태의 데이터를 갖고 있고 어떤 신호로 학습하는가**로 갈린다.

| | 데이터 형태 | 목표 | 이번 학기 예시 |
|---|---|---|---|
| 지도학습 | \\((x, y)\\) 쌍 | 새 \\(x\\)에 대한 \\(y\\) 예측 | 회귀·분류, kNN, SVM, 트리, 신경망 |
| 비지도학습 | \\(x\\)만 | 데이터의 숨은 구조 발견 | k-means, PCA, EM/GMM |
| 강화학습 | 상태·행동·보상 | 누적 보상을 최대화하는 정책 | 이번 학기(ML1)에서는 다루지 않음 — 강화학습·로봇 시뮬레이션을 전문으로 다루는 ML2에서 |

- **지도학습**(Supervised Learning): 입력과 정답이 쌍으로 주어진다 — "이 집의
  평수/방 개수를 보고 가격을 맞혀라"(회귀), "이 이메일이 스팸인지 아닌지
  맞혀라"(분류). ML1의 거의 모든 장이 여기 속한다. 지도학습 안에서도 다시 두
  갈래가 갈린다 — **판별적**(discriminative) 접근은 \\(P(y|x)\\)(x가 주어졌을
  때 y의 확률)를 곧바로 학습하고(회귀·로지스틱회귀·SVM·신경망), **생성적**
  (generative) 접근은 \\(P(x|y)\\)(각 클래스가 데이터를 어떻게 만들어내는지)를
  먼저 학습한 뒤 베이즈 정리로 뒤집어 \\(P(y|x)\\)를 얻는다(Chapter 3의
  나이브베이즈·GDA). 같은 문제를 정반대 방향에서 접근하는 이 두 철학의 차이는
  Chapter 3에서 자세히 다룬다.
- **비지도학습**(Unsupervised Learning): 정답 없이 데이터의 구조만 주어진다 —
  "이 고객들을 비슷한 성향끼리 묶어라"(군집화), "1000개 특징을 정보 손실 최소로
  10개로 줄여라"(차원축소). Chapter 14~15에서 다룬다.
- **강화학습**(Reinforcement Learning): 정답이 아니라 보상만 주어지고, 에이전트가
  시행착오로 좋은 행동을 스스로 찾아야 한다 — 체스나 바둑에서 "이 수가
  정답이다"라고 알려주는 사람은 없지만, "이겼다/졌다"는 신호는 있다. **이번
  학기(ML1)에서는 다루지 않는다** — ML1과 ML2는 서로 독립된 과목이고, ML2가
  강화학습과 로봇 시뮬레이션을 처음부터 끝까지 전문으로 다룬다(ML2를 듣기
  위해 ML1을 먼저 들을 필요는 없다).

### 회귀 vs 분류: 같은 모델, 다른 출력

지도학습은 다시 출력이 연속값이냐 범주냐로 나뉜다: **회귀**(regression)는 숫자를
예측한다(집값, 기온), **분류**(classification)는 범주를 예측한다(스팸/정상,
개/고양이/새). 같은 선형 모델 \\(w^Tx + b\\)라도, 출력을 그대로 쓰면 회귀가 되고,
시그모이드를 씌워 0~1 확률로 해석하면 분류가 된다(둘 다 Chapter 2에서 다룬다) —
앞으로 몇 장 동안 이 패턴이 반복해서 나온다: **모델 구조는 비슷한데, 출력을
해석하는 방식과 손실함수(loss function)만 문제에 맞게 바뀐다.** 같은 알고리즘이
두 문제 모두에 쓰이는 경우가 많으므로, 이 둘을 구분하는 눈은 이번 학기 내내
필요하다.

지금부터 배우는 거의 모든 알고리즘은 다음 두 단계 틀을 따른다: (1) 모델이
얼마나 틀렸는지를 숫자 하나로 요약하는 **손실함수** \\(J(w)\\)를 정의하고,
(2) \\(J(w)\\)를 최소화하는 \\(w\\)를 찾는다(대개 경사하강법, Chapter 2).
회귀의 손실함수(평균제곱오차)와 분류의 손실함수(교차 엔트로피)는 형태가
다르지만, "모델의 틀린 정도를 수치화하고 그걸 줄인다"는 구조 자체는 동일하다 —
이 공통 언어 하나가 이번 학기 14개 챕터를 관통하는 뼈대다.
