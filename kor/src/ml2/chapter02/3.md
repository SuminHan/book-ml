# 2.3 밴딧 vs 완전한 MDP: 다음 장으로 가는 다리

밴딧 문제에는 **상태**가 없다 — 팔을 당겨도 "다음 상태"로 넘어가지
않는다. 매번 같은 \\(k\\)개의 팔 중에서 고르는, 시간이 흘러도 상황이
전혀 안 바뀌는 세계다. Chapter 3부터 배울 **MDP**(Markov Decision
Process)는 여기에 결정적인 것 하나를 추가한다 — **지금 한 행동이
다음에 어떤 상태를 보게 될지에 영향을 준다.** 슬롯머신을 당기는 것과,
체스에서 한 수를 두는 것의 차이를 생각해보라: 체스에서는 지금 둔 수가
판의 배치(상태)를 바꾸고, 그 배치가 다음에 무엇을 할 수 있는지를
결정한다. 밴딧에서 배운 탐험-활용의 딜레마는 그대로 남지만, 이제
"지금 선택이 미래의 선택지 자체를 바꾼다"는 완전히 새로운 문제가
겹쳐진다.

**밴딧은 강화학습에서 상태와 전이를 걷어내고 남은 최소 뼈대다 —
\\(\varepsilon\\)-greedy, 낙관적 초기화, UCB, 이 세 가지 탐험 전략은
형태만 바뀐 채 이 학기 내내(특히 Chapter 6의 ε-greedy) 반복해서
등장한다.**

**2. (개념 서술)** \\(\varepsilon\\)를 0으로 고정하면(순수 탐욕적
선택) 어떤 문제가 생기는지, 반대로 \\(\varepsilon=1\\)로 고정하면(순수
무작위 선택) 어떤 문제가 생기는지 각각 설명하라. 학습이 진행될수록
\\(\varepsilon\\)을 점점 줄여나가는 것(decay)이 왜 합리적인 절충안인지도
논하라.

**3. (손유도, Tier B — 힌트 제공)** 팔 하나를 \\(n\\)번 당겨서 얻은 보상이
\\(R_1, \ldots, R_n\\)일 때, 증분 갱신식 \\(Q_{n+1} = Q_n +
\frac{1}{n}(R_n - Q_n)\\)을 \\(n=1\\)부터 반복 전개하면
\\(Q_{n+1} = \frac{1}{n}\sum_{i=1}^n R_i\\)(단순 평균)와 정확히 같아짐을
보여라.

**힌트**: \\(Q_1 = 0\\)에서 시작해 \\(n=1, 2, 3\\)에 대해 직접 전개해보고
패턴을 관찰한 뒤(예: \\(Q_2 = R_1\\), \\(Q_3 = R_1 + \frac{1}{2}(R_2-R_1) =
\frac{R_1+R_2}{2}\\)), 수학적 귀납법으로 일반적인 \\(n\\)에 대해
증명하라.

**정확성 확인**: 이 결과가 왜 "증분 갱신식이 그냥 평균을 온라인(데이터가
하나씩 들어올 때마다)으로 계산하는 것과 수학적으로 동일하다"는 것을
의미하는지 한 문장으로 설명하라.
