# 13.3 연속제어환경에 PPO 적용하기

Chapter 11의 PPO는 이산 행동(softmax 정책)뿐 아니라 연속 행동에도
자연스럽게 확장된다 — 신경망이 각 행동 차원마다 정규분포의 평균과
표준편차를 출력하도록 하면 된다:

\\[\pi_\theta(a|s) = \mathcal{N}(a; \mu_\theta(s), \sigma_\theta(s)^2)\\]

로그 확률 \\(\log \pi_\theta(a|s)\\)은 정규분포의 확률밀도함수에서
바로 계산되며, Chapter 10.1의 로그미분 트릭과 Chapter 11.2의 클리핑
목적함수는 이산/연속 여부와 무관하게 형태가 그대로 유지된다 — "행동을
어떻게 파라미터화하는가"만 바뀔 뿐, 그 뒤의 최적화 기계는 동일하다는
것이 정책기반 방법의 큰 장점이다.

```python
import math

def gaussian_log_prob(action, mu, sigma):
    # 연속 행동에 대한 로그 확률 -- softmax 대신 정규분포를 쓴다는 점만 다르다
    return -0.5 * math.log(2 * math.pi * sigma**2) - (action - mu)**2 / (2 * sigma**2)
```

### 실습: Reacher 로봇팔에서 PPO 학습시키기

Chapter 11.2의 Pendulum PPO 실습과 완전히 같은 코드(`GaussianPolicy`,
`ValueNet`, GAE, 클리핑 손실)를 이번 절에서 다룬 `Reacher-v5`(2관절
로봇팔이 목표에 끝을 맞추는 과제)에 그대로 적용해보자 — 환경 이름만
바뀔 뿐 알고리즘 코드는 한 줄도 안 바뀐다는 것이 정책기반 방법의
범용성을 다시 한번 보여준다. 100번의 반복(반복당 200 스텝, 총 2만
스텝) 학습시키면(스크래치패드에서 실행 검증):

```
무작위 정책 평균 리턴(10 에피소드):    -43.72
학습 전 10 에피소드 평균 리턴:         -45.85
학습 후 마지막 10 에피소드 평균 리턴:  -37.40
```

무작위 정책(-43.72)과 학습 극초반(-45.85)이 거의 비슷한 수준에서
시작해, 2만 스텝의 짧은 학습만으로도 -37.40까지 개선됐다 — 약
18% 향상이다. Chapter 11.2의 Pendulum 실습(12만 스텝, 약 30%
개선)과 비교하면 개선 폭이 더 작은데, 이는 Reacher가 상태·행동공간이
더 복잡하고(13.2절에서 확인한 대로) 목표 지점이 매 에피소드 무작위로
바뀌어 문제 자체가 더 어렵기 때문이다 — 실전 로봇 학습에서 수백만
스텝 단위의 훈련 시간을 계획하는 이유가 바로 이렇게 문제가 복잡해질수록
필요한 데이터도 함께 늘어나기 때문이다.

### 자주 묻는 질문

**Q. 왜 같은 PPO 코드를 Pendulum과 Reacher에 그대로 쓸 수 있나요?**
PPO의 신경망 구조(`GaussianPolicy`, `ValueNet`)는 입력 차원(상태
차원)과 출력 차원(행동 차원)만 환경에 맞게 바뀌면 되고, 나머지
로직(GAE 계산, 클리핑 손실)은 상태·행동이 무엇을 의미하는지 전혀
몰라도 작동한다 — Chapter 9.1에서 배운 "함수근사"의 일반성이 여기서도
그대로 발휘된다. 이것이 심층강화학습이 다양한 로봇 문제에 재사용 가능한
이유다.

**Q. 학습 스텝을 늘리면 얼마나 더 좋아질까요?** 일반적으로 계속
개선되지만 수익 체감(diminishing returns)이 있다 — 처음 몇만 스텝은
"완전히 무작위" 상태에서 "그럴듯한" 상태로 빠르게 개선되지만, 그
이후 "그럴듯함"에서 "정교함"으로 가는 데는 훨씬 더 많은 스텝이
필요한 경우가 많다. 실전에서는 검증 곡선이 평평해지는 지점을 보고
학습을 멈추거나(Chapter 6(ML1)의 조기 종료와 같은 원리), 계산 예산
안에서 가능한 만큼 학습시킨다.

**로봇 시뮬레이션은 지금까지 배운 알고리즘(DQN, PPO)을 "실제 물리
법칙이 지배하는 연속 행동공간"이라는 더 현실적인 무대로 옮기는 시험대다
— 다음 장에서는 이 시뮬레이션을 더 정교한 물리엔진으로, 그리고 대규모
GPU 가속 환경으로 확장한다.**
