# Chapter 4. LLM 맛보기 (LLM Preview)

의대생은 처음부터 특정 질병 하나만 배우지 않는다 — 먼저 해부학, 생리학,
약리학 같은 방대한 기초를 몇 년에 걸쳐 익힌 뒤에야, 특정 전공(예:
심장내과)을 짧은 기간 집중적으로 훈련받는다. 대규모 언어모델(LLM)이
학습되는 방식도 놀랍도록 비슷하다: 먼저 인터넷의 방대한 텍스트로 "다음
단어를 예측하는" 아주 단순한 과제를 통해 언어와 세상에 대한 폭넓은 지식을
흡수하고(**사전학습, pretraining**), 그 다음 특정 목적(대화, 코드 작성,
요약)에 맞춰 비교적 적은 데이터로 다듬는다(**파인튜닝, fine-tuning**).

## 4.1 언어모델링: 다음 토큰 예측

LLM은 텍스트를 **토큰**(token)(단어 전체이거나, 더 흔하게는 단어의 일부
조각)의 시퀀스로 다룬다. 사전학습의 목표는 지금까지의 토큰들이 주어졌을
때, 다음 토큰의 확률분포를 예측하는 것이다:

\\[P(x_t \mid x_1, x_2, \ldots, x_{t-1})\\]

"프랑스의 수도는 ___"이라는 문장을 잘 완성하려면, 모델은 "파리"라는
사실을 어딘가에 담고 있어야 한다. 이런 문장이 수십억 개 쌓이면, "다음
단어 맞히기"라는 단순한 목표를 잘 해내기 위해 모델은 자연스럽게 문법,
사실 지식, 심지어 어느 정도의 추론 능력까지 습득하게 된다.

이 확률은 Chapter 3에서 배운 Transformer(정확히는 미래 토큰을 보지
못하게 마스킹한 decoder-only Transformer)로 계산된다. 학습은 실제 다음
토큰과 예측 확률분포 사이의 교차 엔트로피 손실(ML1 Chapter 3.3에서 섀넌의
정보이론으로부터 도입한 그 손실과 정확히 같은 형태)을 최소화하는 방향으로
진행된다. 이 손실에 밑을 \\(e\\) 대신 2로 바꿔 지수를 취하면 **퍼플렉시티**
(perplexity)라는 지표가 되는데, "모델이 다음 토큰을 고를 때 평균적으로 몇
개의 선택지를 두고 헤매는 것과 같은가"를 뜻한다 — 낮을수록 모델이 확신을
갖고 예측한다는 뜻이다.

```python
def next_token_probs(logits):
    # logits: 어휘 사전의 각 토큰에 대한 원점수(raw score)
    # softmax를 적용하면 "다음 토큰이 각각일 확률"이 된다
    return softmax(logits)
```

## 4.2 사전학습 vs 파인튜닝

| | 사전학습(Pretraining) | 파인튜닝(Fine-tuning) |
|---|---|---|
| 데이터 | 인터넷 규모의 방대한 텍스트 | 특정 목적에 맞는 비교적 적은 데이터 |
| 목표 | 다음 토큰 예측(비지도) | 특정 작업(대화, 지시 따르기 등)에 맞춘 지도학습 |
| 결과 | 폭넓지만 다듬어지지 않은 능력 | 목적에 맞게 다듬어진 행동 |

사전학습은 계산 비용이 막대하지만(수천 개의 GPU로 몇 주~몇 달),
파인튜닝은 상대적으로 적은 자원으로 가능하다 — "기초를 다시 배우지
않고, 이미 아는 것을 특정 방향으로 다듬는다"는 것이 파인튜닝의 효율성의
핵심이다.

## 4.3 프롬프팅: 다시 학습시키지 않고 행동을 바꾸기

파인튜닝은 모델의 가중치 자체를 바꾸는 것이지만, **프롬프팅**(prompting)은
가중치를 전혀 바꾸지 않고 입력(지시문, 예시)만으로 모델의 출력을 원하는
방향으로 유도하는 방법이다.

- **Zero-shot**: 예시 없이 지시문만 주고 바로 요청("이 문장을 한국어로
  번역해줘: ...").
- **Few-shot**: 몇 개의 입출력 예시를 프롬프트에 포함시켜, 모델이 패턴을
  파악하고 따라하게 유도.
- **Chain-of-Thought**: "단계별로 생각해봐"처럼, 최종 답 전에 중간 추론
  과정을 출력하도록 유도 — 복잡한 추론 문제에서 정답률을 크게 높이는
  경우가 많다.

몇 가지 예시를 프롬프트에 포함시키는 것만으로 모델이 새로운 형식의
작업을 수행하게 만들 수 있다는 사실(few-shot prompting)은, 사전학습이
얼마나 폭넓은 능력을 모델 안에 압축해뒀는지를 보여주는 증거이기도 하다.

## 4.4 왜 프롬프팅이 통하는가

사전학습 데이터에는 "질문-답변", "예시-패턴" 형태의 텍스트가 이미
무수히 포함돼 있다. 모델은 "다음 토큰 예측"을 통해 이런 패턴 자체를
이미 학습해뒀으므로, 프롬프트 안에 비슷한 패턴을 보여주면 그 패턴을
이어가는 방향으로 다음 토큰을 예측한다 — 새로운 지식을 학습하는 게
아니라, **이미 갖고 있는 능력 중 어떤 것을 꺼내 쓸지를 프롬프트가
가리키는 것**에 가깝다.

## 4.5 한계

LLM은 사실이 아닌 그럴듯한 문장을 자신 있게 만들어내기도 한다(**환각,
hallucination**) — "다음 토큰으로 그럴듯한 것"을 예측하도록 학습됐을
뿐, 사실 여부를 검증하는 과정이 내장돼 있지 않기 때문이다. 이 한계는
지금도 활발히 연구되는 문제이며, 이 학기의 범위를 넘어선다 — 다만 "왜
이런 한계가 생기는가"를 사전학습 목표(다음 토큰 예측) 자체에서 짚어낼
수 있다는 점은 기억해둘 만하다.

**LLM 자체는 새로운 알고리즘이 아니라, 지금까지 배운 Transformer를
극단적으로 큰 규모(파라미터 수, 데이터 양)로 학습시킨 결과다 — "왜
크기가 커지면 새로운 능력이 생기는가"는 지금도 활발히 연구되는 질문이다.**
