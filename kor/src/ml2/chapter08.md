# Chapter 8. Block A 캡스톤: 팀 프로젝트와 총정리 (Block A Capstone: Team Project & Review)

Chapter 2~7은 밴딧, MDP, 동적계획법, 몬테카를로, 시간차 학습, n-step까지
강화학습의 표 기반(tabular) 이론 전체를 훑었다. 이번 장은 새 개념 대신,
이 이론들을 Gymnasium의 표 기반 환경에서 직접 구현해보고 비교하며,
중간고사를 준비하는 자리다.

## 8.1 프로젝트 구조

- **환경**: Gymnasium의 표 기반(이산 상태·행동) 환경 중 하나를 고른다
  — `FrozenLake-v1`, `CliffWalking-v0`, `Taxi-v3` 등이 좋은 후보다.
- **적용**: Chapter 4~7의 알고리즘 중 **최소 두 가지**(예: Q-learning과
  SARSA, 또는 MC 제어와 n-step TD)를 같은 환경에 적용하고 학습 곡선과
  최종 정책을 비교한다.
- **필수 요구사항 — 수식적 정당화 최소 1개**: 예를 들어 (1) Q-learning과
  SARSA를 비교했다면 Chapter 6.3~6.4의 on-policy/off-policy 차이로 두
  정책이 왜 다르게 학습됐는지 설명, (2) \\(\varepsilon\\)이나 \\(\alpha\\)를
  바꿔가며 실험했다면 Chapter 6.5의 수렴 조건과 연결지어 설명, (3)
  Dyna-Q를 썼다면 Chapter 7.3의 계획 스텝 수와 학습 속도의 관계를 직접
  측정해서 제시.

## 8.2 발표 (블록 1)

팀당 5~7분: 문제 정의(환경 설명, 1분) → 적용한 알고리즘과 이유(2분) →
학습 곡선/최종 정책 비교와 수식적 정당화(2~3분) → 잘 안 됐던 부분과
원인 진단(1분).

## 8.3 Peer-Review (블록 2)

다른 두 팀의 발표를 다음 체크리스트로 평가한다:

| 항목 | 확인할 것 |
|---|---|
| 환경 설명 | 상태·행동·보상이 명확히 정의됐는가 |
| 알고리즘 선택 | 표 기반 환경에 적합한 방법을 골랐는가 |
| 수식적 정당화 | 요구사항을 충족했고, 실제로 관찰한 결과와 일치하는가 |
| 결과의 정직성 | 학습이 불안정했던 구간을 숨기지 않고 원인을 분석했는가 |

## 8.4 중간고사 대비 총정리 (블록 3)

| 장 | 핵심 질문 | 다시 봐야 할 개념 |
|---|---|---|
| Ch02 | 상태 없이도 탐험-활용 딜레마가 존재하는가 | ε-greedy, 낙관적 초기화, UCB |
| Ch03 | 강화학습 문제를 어떻게 수학적으로 정식화하는가 | MDP 5요소, 마르코프 성질, 할인율 |
| Ch04 | 모델을 알 때 최적 정책을 어떻게 계산하는가 | 벨만방정식, 정책반복/가치반복, 축소 사상 |
| Ch05 | 모델 없이, 에피소드 결과만으로 배울 수 있는가 | 첫방문 MC, MC 제어, 중요도 샘플링 |
| Ch06 | 에피소드가 끝나길 기다리지 않고 배울 수 있는가 | TD 오차, Q-learning vs SARSA |
| Ch07 | MC와 TD 사이, 그리고 경험 재사용은 어떻게 하는가 | n-step TD, 적격흔적, Dyna-Q |

중간고사는 이 여섯 장의 개념을 새로운 MDP에 적용하는 문제(손유도
포함)로 구성된다 — 특히 "벨만방정식을 터미널부터 거꾸로 대입해서
직접 풀기"(Chapter 4)와 "TD 오차의 수렴 조건 논증하기"(Chapter 6)
패턴이 다른 MDP에도 그대로 적용되는지 확인하는 것이 좋은 복습이다.

**Chapter 2~7에서 배운 모든 알고리즘은 결국 하나의 질문에 대한 답이다
— "미래의 불확실한 보상을 지금 어떻게 수치화할 것인가?" 이제 이
질문에 신경망을 결합해서, 표에 담을 수 없을 만큼 큰 문제로 나아갈
차례다.**
