# 4.1 벨만 최적방정식과 정책평가

### 복습: 가치함수와 벨만 기대방정식

Chapter 3.3에서 정의했듯, 정책 \\(\pi\\)를 따를 때 상태 \\(s\\)의
가치는 그 상태에서 시작해 앞으로 받을 할인된 누적 보상의 기댓값이고:

\\[V^\pi(s) = \mathbb{E}\_\pi\left[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) \,\middle|\,
s_0 = s\right]\\]

이 무한합은 재귀적 관계(벨만 기대방정식)로 다시 쓸 수 있다:

\\[V^\pi(s) = R(s, \pi(s)) + \gamma \sum_{s'} P(s'|s,\pi(s)) V^\pi(s')\\]

직관: "지금 상태의 가치 = 지금 당장 받는 보상 + 할인된, 다음에 갈
상태들의 가치의 기댓값." 이 통찰 덕분에, "게임이 끝날 때까지"를 통째로
계산하는 대신, 한 스텝 앞만 내다보는 계산을 반복하는 것만으로 정확한
답에 도달할 수 있다.

### 반복적 정책평가

상태가 많으면, 다음을 값이 더 이상 바뀌지 않을 때까지 반복해서 근사한다:

```python
def policy_evaluation(P, R, policy, gamma, theta=1e-6):
    n_states = len(P)
    V = [0.0] * n_states
    while True:
        delta = 0
        for s in range(n_states):
            a = policy[s]
            v_new = R[s][a] + gamma * sum(prob * V[next_s] for prob, next_s in P[s][a])
            delta = max(delta, abs(v_new - V[s]))
            V[s] = v_new
        if delta < theta:
            break
    return V
```

매 반복마다 모든 상태의 \\(V(s)\\)를 벨만방정식 우변으로 갱신하는데,
우변에 쓰이는 \\(V(s')\\)도 (아직 정확한 값이 아니라) 지금까지 추정한
값이다 — 그런데도 이 반복은 \\(\gamma < 1\\)이기만 하면 정확한 \\(V^\pi\\)로
수렴한다는 것이 증명돼 있다(**수축 사상**, contraction mapping 성질 —
4.3절에서 다시 다룬다).

### 벨만 최적방정식

지금까지는 "주어진 정책을 평가하는 법"을 배웠다. 강화학습이 정말로 풀고
싶은 문제는 "가장 좋은 정책을 찾는 것"이다. 최적 가치 \\(V^*(s)\\)를
다음 **벨만 최적방정식**으로 정의한다 — 각 상태에서, 그 이후를 최적으로
이어갔을 때 가치가 가장 커지는 행동을 골랐다고 가정했을 때 나오는 가치다:

\\[V^*(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^*(s')\right]\\]

벨만 **기대**방정식과 형태는 거의 같지만, 특정 정책 \\(\pi(s)\\)가
고른 행동 하나 대신 **가능한 모든 행동 중 최선**을 취한다는 점이
다르다(\\(\max_a\\)) — 이 한 글자짜리 차이(정책을 따르는 것 vs 최댓값을
취하는 것)가 "이 정책이 얼마나 좋은가 평가하기"와 "가장 좋은 정책
찾기"라는 서로 다른 두 문제를 가른다.

### 자주 묻는 질문

**Q. 정책평가는 왜 한 번에 안 풀고 반복으로 근사하나요?** 사실 상태
수가 적으면 벨만 기대방정식을 상태 개수만큼의 연립 **일차방정식**으로
보고 한 번에 풀 수도 있다(Chapter 2.2의 정규방정식처럼 닫힌 형태
해가 있다). 하지만 상태가 많아지면 그 연립방정식을 직접 푸는 비용
(행렬 역산, \\(O(n^3)\\))이 반복법보다 오히려 비싸지는 경우가 많아,
실전에서는 반복적 정책평가를 표준으로 쓴다.

**Q. `policy_evaluation`의 `theta`는 무엇을 조절하나요?** 수렴
판정 기준이다 — 한 번의 전체 반복(sweep) 동안 어떤 상태의 값도
`theta`보다 적게 바뀌면 "충분히 수렴했다"고 보고 멈춘다. Chapter
2.1의 경사하강법이 정해진 에폭 수만큼 반복했던 것과 달리, 여기서는
"더 이상 의미 있게 바뀌지 않을 때"를 직접 감지해서 멈춘다는 차이가
있다.
