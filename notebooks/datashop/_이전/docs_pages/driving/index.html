어떤 문제인가

입력 X지난 궤적 + 주변 차들의 위치 · 차선
→ 모델 →회귀 (궤적)
출력 y (기대하는 답)앞으로 3초의 위치 (x, y) 30개

데이터

NGSIM 차량 궤적 · Waymo Open Motion Dataset

NGSIM: 미국 교통부가 고속도로 (US-101 등) 를 카메라로 찍어 차량마다 0.1초 간격 위치를 기록한 공개 데이터. Waymo Open Motion: 실제 자율주행차가 본 주변 차량 · 보행자 궤적 (Google 계정 · 이용 동의 필요)

문제를 정해 본 예시

① 한 행차 한 대의 지난 몇 초 (0.1초 간격 위치)
② 입력 X지난 궤적 + 주변 차들의 위치 · 차선
③ 출력 y앞으로 3초의 위치 (x, y) 30개
④ 평가지표평균 · 마지막 위치 오차 (ADE · FDE, 미터)
⑤ 기준선지금 속도 그대로 직진

평가지표 수식

평균 위치 오차 (ADE)앞으로 T 걸음 동안 예측 위치와 실제 위치의 거리 평균 (미터)
\text{ADE} = \frac{1}{T}\sum_{t=1}^{T} \lVert \hat{\mathbf p}_t - \mathbf p_t \rVert_2
