# Chapter 1. ML1 Review & Roadmap

ML1's last chapter ended with the autoencoder raising a question: "how does
compression lead to generation?" ML2 picks up exactly where that question
left off — but first, let's firmly re-establish the two results from ML1
that this entire semester leans on: **what a neural network can do**
(forward propagation) and **how to train it** (backpropagation).

## 1.1 Neural Network Review: Forward and Backward Propagation

Let's re-derive the core of ML1 Chapter 8. In a network with \\(L\\)
layers, layer \\(l\\)'s pre-activation and activation are:

\\[z_l = W_l a_{l-1} + b_l, \qquad a_l = \sigma(z_l)\\]

Backpropagation carries the error \\(\delta_L\\) computed at the output
layer backward toward the input:

\\[\delta_l = (W_{l+1}^T \delta_{l+1}) \odot \sigma'(z_l), \qquad
\frac{\partial J}{\partial W_l} = \delta_l \cdot a_{l-1}^T\\]

These two equations recur, in various forms, throughout the entire
semester — an RNN unrolls this same chain across time as well (BPTT,
Chapter 2), and a Transformer's attention is ultimately just a composition
of differentiable operations, trained the same way.

## 1.2 Why Review This Again

The backpropagation we covered in ML1 dealt with a single small two-layer
network. In ML2, we apply this exact same principle to far more complex
structures — RNNs that process sequences, Transformers that use attention,
reinforcement learning agents that teach themselves to play games,
generative models that draw new images. The structure is new every time,
but the underlying principle — "carry the output's error backward through
the chain rule to compute each parameter's share of responsibility" —
never changes, not once, all semester.

## 1.3 Why "Sequences" Are a New Problem

Every model we covered through ML1 (MLP, CNN) had a fixed input size — an
image always has the same resolution, a feature vector always has the same
length. But a sentence ("I go to school") varies in length every time, and
reordering it completely changes its meaning ("school goes to me" is a
different sentence). None of the fixed-input-size structures we've used so
far can solve this problem — Chapter 2 tackles it head-on.

## 1.4 Why "Reward" Is a New Problem

Reinforcement learning, which ML1 only previewed conceptually, has one more
decisive difference beyond the lack of correct answers: the data isn't
given in advance — it's **generated by the agent's own actions**. Which
action you take now affects what data (what states) you'll see in the
future — this creates an entirely new dilemma that didn't exist in
supervised learning: **exploration vs. exploitation**. Starting in Chapter
5, we formalize this with the Bellman equation.

## 1.5 Roadmap for This Semester

- **Chapters 2-4**: how to handle ordered data (sequences) — starting from
  RNNs, moving to Attention/Transformer (the core of modern deep
  learning), and up to LLMs built on top of it.
- **Chapters 5-8**: reinforcement learning done properly, starting from
  MDPs — from a table-based method (Q-learning), to deep RL that
  combines it with neural networks (DQN), to methods that learn a policy
  directly (Policy Gradient).
- **Chapter 9**: post-training a pretrained LLM in the direction people
  actually want (RLHF, DPO) — also a chance to put Chapter 8's PPO to
  real use.
- **Chapters 10-11**: the three principles of generative models —
  likelihood-based (VAE), adversarial (GAN), and score-based
  (Diffusion) — covered in sequence. Learning only one of them makes it
  hard to see why the other two exist, so we learn all three side by
  side, comparing them.
- **Chapters 12-13**: the semester wraps up with a team project.

## 1.6 Readiness Checklist

To follow along this semester, you should be comfortable with: (1)
computing gradients via the chain rule (ML1 Chapter 8), (2) matrix-vector
products and dot products (used continuously since ML1 Chapter 2), (3) the
basic operations of probability — expectation, conditional probability
(especially important in Chapter 5's MDPs and Chapter 10's VAE). If you're
unsure about any of these three, it's worth reviewing them during this
chapter's recitation time.

**Neural networks themselves were already finished in ML1 — ML2 is a
semester about asking what more can be built with the same principle.**
