## 손유도 과제 — 두 가지 버전 중 택1 (교원 판단)

다음 3-state MDP를 놓고 각 상태의 가치 \\(V(s)\\)를 구한다:

- State 0: 항상 State 1로 이동, 보상 -1
- State 1: 항상 State 2로 이동, 보상 -1
- State 2: 종료 상태(terminal), \\(V(2) = 0\\)

할인율 \\(\gamma = 0.9\\).

### [버전 A] 자유 계산 (Math for ML이 재귀적 정의를 편하게 다룰 경우)

벨만방정식 \\(V(s) = R(s) + \gamma V(s')\\)을 이용해, \\(V(2)=0\\)부터 시작해
거꾸로 대입하며 \\(V(1)\\)과 \\(V(0)\\)을 직접 계산하라.

### [버전 B] 빈칸채움형 계산 워크시트 (폴백)

```
V(2) = 0   [터미널 상태]

V(1) = R(1) + gamma * V(2)
     = -1 + 0.9 * 0
     = ______________

V(0) = R(0) + gamma * V(1)
     = -1 + 0.9 * ______________
     = ______________
```

**정확성 확인**: 문제 1의 `episode_return([-1, -1, 0], gamma=0.9)`가 State 0에서
시작한 한 에피소드의 실제 누적 보상을 계산한 것이다. 이 값이 위에서 손으로 계산한
\\(V(0)\\)과 (거의) 일치하는지 확인하고, 왜 "가치함수 \\(V(s)\\)"와 "실제 한 번의
에피소드에서 얻은 누적 보상"이 같은 개념을 가리키는지 한 문장으로 설명하라.
