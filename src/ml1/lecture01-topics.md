## 머신러닝 문제 정식화

머신러닝 문제를 풀기 전에 먼저 세 가지를 정해야 한다:

1. **입력(input) \\(x\\)**: 무엇을 특징(feature)으로 쓸 것인가? (예: 집의 평수, 방
   개수, 지어진 연도)
2. **출력(output) \\(y\\)**: 무엇을 맞히고 싶은가? 연속값(회귀)인가, 범주(분류)인가?
3. **가설(hypothesis) \\(h\\)**: 입력에서 출력으로 가는 함수를 어떤 형태로 근사할
   것인가? (직선? 트리? 신경망?)

학습(training)이란, 주어진 데이터 \\((x^{(1)}, y^{(1)}), \ldots, (x^{(m)}, y^{(m)})\\)에
대해 \\(h(x^{(i)})\\)가 \\(y^{(i)}\\)에 최대한 가깝도록 \\(h\\)의 파라미터를 조정하는
과정이다.

## 지도 / 비지도 / 강화학습

| | 데이터 형태 | 목표 | 이번 학기 예시 |
|---|---|---|---|
| 지도학습 | \\((x, y)\\) 쌍 | 새 \\(x\\)에 대한 \\(y\\) 예측 | 선형회귀, 로지스틱회귀, kNN, 트리, 신경망 |
| 비지도학습 | \\(x\\)만 | 데이터의 숨은 구조 발견 | k-means, PCA |
| 강화학습 | 상태·행동·보상 | 누적 보상을 최대화하는 정책 | ML2 W05~W08 |

## 회귀 vs 분류: 같은 모델, 다른 출력

같은 선형 모델 \\(w^Tx + b\\)라도, 출력을 그대로 쓰면 회귀(W02), 시그모이드를 씌워
0~1 확률로 해석하면 분류(W03)가 된다 — 앞으로 몇 주간 이 패턴이 반복해서 나온다: **모델
구조는 비슷한데, 출력을 해석하는 방식과 손실함수(loss function)만 문제에 맞게
바뀐다.**

## 손실함수(Loss Function)라는 공통 언어

지금부터 배우는 거의 모든 알고리즘은 다음 틀을 따른다:

1. 모델이 얼마나 틀렸는지를 숫자 하나로 요약하는 **손실함수** \\(J(w)\\)를 정의한다.
2. \\(J(w)\\)를 최소화하는 \\(w\\)를 찾는다 — 대개 경사하강법(W02)으로.

회귀의 손실함수(평균제곱오차)와 분류의 손실함수(교차 엔트로피)는 형태가 다르지만, "모델의
틀린 정도를 수치화하고 그걸 줄인다"는 구조 자체는 동일하다.

## Python/NumPy 준비

이번 학기 코딩 문제는 순수 Python(리스트 기반)과 `numpy`(벡터/행렬 연산) 둘 다 사용한다.
`numpy`가 왜 필요한지는 다음 예시로 감을 잡을 수 있다:

```python
import numpy as np

X = np.array([[1.0, 2.0], [3.0, 4.0]])  # 2x2 행렬
w = np.array([0.5, -0.5])               # 길이 2 벡터
print(X @ w)   # 행렬-벡터 곱: [-0.5, -0.5]
```

`X @ w`(행렬곱)는 앞으로 매주 나오는 `w^T x` 형태의 계산을 한 줄로 표현해준다 — for 루프로
직접 짜는 것보다 빠르고 읽기 쉽다.
