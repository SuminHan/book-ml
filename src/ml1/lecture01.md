# Orientation

2012년, ImageNet 대회에서 AlexNet이라는 신경망이 등장하기 전까지, 컴퓨터에게 "이 사진에
고양이가 있는가"를 알려주는 방법은 사람이 직접 특징을 설계하는 것이었다 — 가장자리 검출기,
색 히스토그램, 특정 모양의 필터를 손으로 조합해서 "고양이스러움"을 수치로 정의하려 했다.
AlexNet은 그런 손설계 없이, 수백만 장의 사진과 정답 라벨만 보고 스스로 무엇을 봐야 하는지
학습해서, 기존 방법들을 압도적인 차이로 이겼다.

이게 이 두 과목이 다루는 질문이다: **정답이 있는 데이터로부터, 규칙을 사람이 짜는 대신
기계가 데이터에서 직접 찾아내게 하려면 어떻게 해야 하는가?**

## 지도학습 · 비지도학습 · 강화학습

머신러닝 문제는 크게 세 갈래로 나뉜다.

- **지도학습**(Supervised Learning): 입력과 정답이 쌍으로 주어진다 — "이 집의 평수/방
  개수를 보고 가격을 맞혀라"(회귀), "이 이메일이 스팸인지 아닌지 맞혀라"(분류). ML1의
  거의 모든 주차가 여기 속한다.
- **비지도학습**(Unsupervised Learning): 정답 없이 데이터의 구조만 주어진다 — "이
  고객들을 비슷한 성향끼리 묶어라"(군집화), "1000개 특징을 정보 손실 최소로 10개로
  줄여라"(차원축소). ML1 W10에서 다룬다.
- **강화학습**(Reinforcement Learning): 정답이 아니라 보상만 주어지고, 에이전트가 시행착오로
  좋은 행동을 스스로 찾아야 한다 — 체스나 바둑에서 "이 수가 정답이다"라고 알려주는 사람은
  없지만, "이겼다/졌다"는 신호는 있다. ML1에서는 개념만 예고하고, ML2에서 본격적으로
  다룬다.

## 회귀 vs 분류

지도학습은 다시 출력이 연속값이냐 범주냐로 나뉜다: **회귀**(regression)는 숫자를
예측한다(집값, 기온), **분류**(classification)는 범주를 예측한다(스팸/정상,
개/고양이/새). 같은 알고리즘이 두 문제 모두에 쓰이는 경우가 많으므로(예: 선형회귀 →
로지스틱회귀), 이 둘을 구분하는 눈은 이번 학기 내내 필요하다.

## 이번 학기 로드맵

W02~W06은 신경망 없이도 강력한 classical ML 모델들(선형/로지스틱 회귀, kNN, 트리 기반
모델, GBDT)을 다룬다 — 지금도 정형(tabular) 데이터에서는 이 모델들이 신경망보다 자주
이긴다. W07부터는 신경망으로 넘어가 역전파의 원리를 손으로 유도하고, 실제로 그 원리 위에
CNN 같은 구조를 얹는다. 마지막 두 주차는 비지도학습과 RL/생성형 모델을 살짝 맛본다 —
둘 다 ML2에서 본격적으로 다시 만난다.

**어떤 모델을 쓸지보다 먼저 물어야 할 질문은 항상 같다: 이 문제는 무엇을 데이터로 갖고
있고, 무엇을 맞히고 싶은가.**
