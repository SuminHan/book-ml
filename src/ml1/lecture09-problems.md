## 손유도 과제 (실습시간, Tier A — 자유 유도)

### 합성곱 출력 크기 공식 유도 & 파라미터 수 계산

**1단계**: 입력 크기 \\(n \times n\\), 필터 크기 \\(k \times k\\), 패딩 \\(p\\),
스트라이드 \\(s\\)일 때 출력 크기 공식

\\[n_{\text{out}} = \left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1\\]

을, 필터가 이미지 위에서 이동할 수 있는 위치의 개수를 직접 세는 방식으로 유도하라.
(힌트: 패딩을 더한 뒤 유효 입력 크기는 \\(n+2p\\)이다. 필터가 한쪽 끝에서 반대쪽 끝까지
이동하려면 몇 칸을 \\(s\\)씩 건너뛰어야 하는지 세어보라.)

**2단계**: 다음 CNN의 각 층에서 출력 크기와 파라미터 수를 계산하라 — 입력: 32×32×3,
Layer 1: 필터 5×5, 출력 채널 6, 패딩 0, 스트라이드 1. Layer 2(풀링): 2×2 최대풀링.
Layer 3: 필터 5×5, 출력 채널 16, 패딩 0, 스트라이드 1.

**정확성 확인**: 2단계에서 구한 최종 출력 크기(공간×채널)를 코드로 확인하고 싶다면,
문제 1의 `conv2d`를 여러 채널로 확장하면 검증할 수 있다는 점을 논하라(직접 구현할
