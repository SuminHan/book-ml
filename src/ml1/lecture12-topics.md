## 오토인코더(Autoencoder)의 구조

두 부분으로 이루어진다:

- **인코더(Encoder)** \\(f\\): 입력 \\(x\\)를 저차원 잠재 표현(latent representation)
  \\(z = f(x)\\)로 압축.
- **디코더(Decoder)** \\(g\\): \\(z\\)로부터 원본을 복원 \\(\hat{x} = g(z)\\).

손실함수는 복원 오차(reconstruction error), 보통 평균제곱오차를 쓴다:

\\[J = \frac{1}{m}\sum_{i=1}^m \|x^{(i)} - g(f(x^{(i)}))\|^2\\]

```python
def autoencoder_forward(x, encoder_weights, decoder_weights):
    z = apply_layer(x, encoder_weights)   # 압축: 입력보다 좁은 은닉층
    x_hat = apply_layer(z, decoder_weights)  # 복원: 다시 원본 차원으로
    return x_hat, z
```

## 왜 병목이 필요한가

만약 은닉층이 입력과 같거나 더 넓다면, 신경망은 그냥 입력을 그대로 복사하는 항등함수
(identity function)를 배워버릴 수 있다 — 그러면 복원 오차는 0이 되지만 아무것도
배운 게 없다. 병목(입력보다 훨씬 좁은 은닉층)을 강제하면, 신경망은 원본을 통째로
저장할 수 없으므로 **정말로 중요한 정보만 압축해서 담아야** 한다.

## PCA와의 관계

인코더와 디코더가 둘 다 활성함수 없이 순수 선형변환(\\(z = Wx\\), \\(\hat{x} =
W'z\\))이고 손실함수가 MSE라면, 이 오토인코더가 학습하는 최적해는 PCA가 찾는 주성분
공간과 (회전을 제외하면) 동일하다는 것이 알려져 있다. 즉:

\\[\text{선형 오토인코더} \subset \text{비선형 오토인코더}, \qquad
\text{선형 오토인코더} \approx \text{PCA}\\]

비선형 활성함수(ReLU, sigmoid 등)를 인코더/디코더에 추가하면, PCA로는 표현할 수 없는
곡면 모양의 데이터 구조도 압축할 수 있다.

## 압축을 넘어 생성으로: 무엇이 더 필요한가

오토인코더를 그대로 "생성 모델"로 쓰려고 하면 문제가 있다: 잠재 공간 \\(z\\) 위의
어떤 값들이 "그럴듯한" 데이터로 복원되는지 알 수 없다 — 학습 데이터가 차지하는
영역이 잠재 공간에서 듬성듬성하거나 불규칙할 수 있기 때문이다. **변분 오토인코더
(Variational Autoencoder, VAE)**는 이 문제를 잠재 공간이 매끄러운 확률분포(보통
정규분포)를 따르도록 강제해서 해결한다 — ML2 W09에서 다룬다. GAN과 Diffusion은
완전히 다른 원리(적대적 학습, 점진적 노이즈 제거)로 같은 목표(그럴듯한 새 데이터
생성)를 이룬다 — ML2 W10에서 다룬다.
