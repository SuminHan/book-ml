# Topics Covered

## 발표 체크리스트

- **문제 정의** (1분): 무엇을 풀려고 했는가? 왜 그 문제가 흥미로운가?
- **방법론** (2~3분): 어떤 모델/알고리즘을 썼고, 왜 그것을 선택했는가?
- **수식적 정당화** (2분): 지난주 리포트에 담은 정당화 1개 이상을 발표에서도
  반드시 짚는다.
- **결과** (2분): 정량적 결과(수치, 그래프)와 정성적 결과(예시)를 함께 보여준다.
- **한계와 회고** (1~2분): 무엇이 잘 안 됐고, 왜 그랬다고 생각하는가? 시간이
  더 있었다면 무엇을 시도했을 것인가?

## ML2 개념 지도 (총정리)

| 주차 | 배운 것 | 핵심 질문 |
|---|---|---|
| W02 | RNN | 순서가 있는 데이터를 어떻게 기억하며 처리하는가 |
| W03 | Attention/Transformer | 순차 처리 없이 어떻게 문맥을 한 번에 파악하는가 |
| W04 | LLM | 다음 토큰 예측이 어떻게 폭넓은 능력으로 이어지는가 |
| W05 | MDP/정책평가 | 미래의 불확실한 보상을 지금 어떻게 계산하는가 |
| W06 | Q-learning | 환경 모델 없이 어떻게 최적 행동을 배우는가 |
| W07 | DQN | 신경망과 강화학습을 어떻게 안정적으로 결합하는가 |
| W08 | Policy Gradient | 연속적 행동공간에서 정책을 어떻게 직접 학습하는가 |
| W09 | VAE | 계산 불가능한 우도를 어떻게 우회해서 최적화하는가 |
| W10 | GAN/Diffusion | 적대적 학습과 점진적 노이즈 제거는 어떻게 다른 원리로 같은 목표를 이루는가 |

## ML1 → ML2를 관통하는 하나의 패턴

두 학기 24주 전체를 관통하는 구조를 마지막으로 정리한다:

1. **모델을 정의한다**: 입력을 출력으로 매핑하는 함수의 형태를 정한다 (직선,
   트리, 신경망, Transformer, ...).
2. **틀린 정도를 수치화한다**: 손실함수(MSE, 교차 엔트로피, TD 오차, ELBO, min-max
   목적함수, ...) — 형태는 매번 다르지만 역할은 항상 같다.
3. **그 손실을 줄이는 방향으로 파라미터를 조정한다**: 경사하강법(직접 또는
   역전파를 통해) — 이 학기 배운 모든 알고리즘의 마지막 단계는 결국 이것이다.

새로운 논문이나 모델을 마주칠 때마다, "이 세 가지 질문에 각각 뭐라고 답하는가"로
분해해서 읽는 습관이, 이 두 과목이 남기고자 하는 가장 오래가는 도구다.

## 발표 후: 다음 단계

이 두 과목을 마친 뒤 더 깊이 파고들고 싶다면, 각 주차에서 "이 학기 범위를
넘어선다"고 언급됐던 부분들(LSTM/GRU의 게이트 수식, Actor-Critic의 상세 유도,
diffusion의 스코어 매칭 이론 등)이 자연스러운 다음 목표가 된다 — 이 학기가 그
개념들을 처음 마주쳤을 때 무섭지 않게 만드는 것이 목표였다면, 그다음은 각자의
관심에 따라 깊이를 더해가는 몫이다.
