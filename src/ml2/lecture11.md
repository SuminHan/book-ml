# Team Project: Implementation

지금까지 10주 동안 배운 모든 것 — 손실함수를 정의하고, 그래디언트를 유도하고, 모델을
구현하고, 그 정확성을 논증하는 것 — 은 각각 독립된 주차의 문제로 다뤄졌다. 마지막
두 주는 이 조각들을 하나의 완성된 프로젝트로 직접 조립해보는 시간이다.

## 왜 팀 프로젝트인가

실제 머신러닝 문제는 "이 주차는 로지스틱회귀, 저 주차는 CNN" 식으로 깔끔하게
나뉘어 있지 않다. 데이터를 정제하고, 어떤 모델이 적합한지 판단하고, 학습이 잘 안
될 때 원인을 진단하고(과적합인가? 그래디언트 소실인가? 데이터 자체의 문제인가?),
결과를 남에게 설명하는 것까지 — 이 모든 과정을 스스로 겪어보는 것이 지난 10주의
개별 주제를 하나로 통합하는 가장 확실한 방법이다.

## 프로젝트 주제 후보

자유 주제이지만, 다음과 같은 방향을 참고할 수 있다:

- **그래프 이상탐지**: 공개 합성 데이터를 이용해, 그래프신경망(GNN, 이번 학기
  범위 밖이지만 W10의 임베딩 개념과 이어진다)이나 전통적 방법으로 비정상 노드/엣지를
  탐지.
- **이미지 분류 응용**: W09(CNN)에서 배운 구조를 실제 이미지 데이터셋에 적용,
  전이학습(transfer learning) 시도.
- **간단한 챗봇/LLM 활용 프로젝트**: W02~W04(LLM 파트)에서 배운 프롬프팅 기법을
  실제 과제(요약, 분류, 검색)에 응용.

## 요구사항: 수식적 정당화 최소 1개

프로젝트 보고서에는 반드시 **수식적으로 정당화되는 선택 1개 이상**이 포함돼야
한다 — 예: "왜 이 손실함수를 골랐는가"를 그래디언트 성질로 논증, "왜 이 정규화
기법을 썼는가"를 과적합 방지 원리로 설명, "이 모델의 파라미터 수가 왜 이렇게
계산되는가"를 직접 유도. 이는 이번 학기 내내 강조된 "정확히 맞히는 코드"와 "왜
그렇게 작동하는지 아는 것"의 구분을, 프로젝트라는 더 큰 스케일에서도 유지하기
위함이다.

## 외부 제출 가능한 수준으로

이 프로젝트는 **코드 + 리포트 + 포스터** 3종 세트로 표준화해서 준비한다 — 나중에
외부 기관(대학 등)이 자료를 요청할 경우 즉시 제시할 수 있는 수준을 목표로 한다.
