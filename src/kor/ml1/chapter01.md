# Chapter 1. Orientation

2012년, ImageNet 대회에서 AlexNet이라는 신경망이 등장하기 전까지, 컴퓨터에게 "이
사진에 고양이가 있는가"를 알려주는 방법은 사람이 직접 특징을 설계하는 것이었다 —
가장자리 검출기, 색 히스토그램, 특정 모양의 필터를 손으로 조합해서 "고양이스러움"을
수치로 정의하려 했다. AlexNet은 그런 손설계 없이, 수백만 장의 사진과 정답 라벨만
보고 스스로 무엇을 봐야 하는지 학습해서, 기존 방법들을 압도적인 차이로 이겼다. 이게
이 두 과목이 다루는 질문이다: **정답이 있는 데이터로부터, 규칙을 사람이 짜는 대신
기계가 데이터에서 직접 찾아내게 하려면 어떻게 해야 하는가?**

## 1.1 머신러닝 문제 정식화

머신러닝 문제를 풀기 전에 먼저 세 가지를 정해야 한다:

1. **입력(input) \\(x\\)**: 무엇을 특징(feature)으로 쓸 것인가? (예: 집의 평수,
   방 개수, 지어진 연도)
2. **출력(output) \\(y\\)**: 무엇을 맞히고 싶은가? 연속값(회귀)인가, 범주(분류)인가?
3. **가설(hypothesis) \\(h\\)**: 입력에서 출력으로 가는 함수를 어떤 형태로 근사할
   것인가? (직선? 트리? 신경망?)

학습(training)이란, 주어진 데이터 \\((x^{(1)}, y^{(1)}), \ldots, (x^{(m)},
y^{(m)})\\)에 대해 \\(h(x^{(i)})\\)가 \\(y^{(i)}\\)에 최대한 가깝도록 \\(h\\)의
파라미터를 조정하는 과정이다.

## 1.2 지도학습 · 비지도학습 · 강화학습

머신러닝 문제는 크게 세 갈래로 나뉜다.

| | 데이터 형태 | 목표 | 이번 학기 예시 |
|---|---|---|---|
| 지도학습 | \\((x, y)\\) 쌍 | 새 \\(x\\)에 대한 \\(y\\) 예측 | 선형회귀, 로지스틱회귀, kNN, 트리, 신경망 |
| 비지도학습 | \\(x\\)만 | 데이터의 숨은 구조 발견 | k-means, PCA |
| 강화학습 | 상태·행동·보상 | 누적 보상을 최대화하는 정책 | ML2 Ch05~Ch08 |

- **지도학습**(Supervised Learning): 입력과 정답이 쌍으로 주어진다 — "이 집의
  평수/방 개수를 보고 가격을 맞혀라"(회귀), "이 이메일이 스팸인지 아닌지
  맞혀라"(분류). ML1의 거의 모든 장이 여기 속한다.
- **비지도학습**(Unsupervised Learning): 정답 없이 데이터의 구조만 주어진다 —
  "이 고객들을 비슷한 성향끼리 묶어라"(군집화), "1000개 특징을 정보 손실 최소로
  10개로 줄여라"(차원축소). ML1 Chapter 10에서 다룬다.
- **강화학습**(Reinforcement Learning): 정답이 아니라 보상만 주어지고, 에이전트가
  시행착오로 좋은 행동을 스스로 찾아야 한다 — 체스나 바둑에서 "이 수가
  정답이다"라고 알려주는 사람은 없지만, "이겼다/졌다"는 신호는 있다. ML1에서는
  개념만 예고하고, ML2에서 본격적으로 다룬다.

## 1.3 회귀 vs 분류: 같은 모델, 다른 출력

지도학습은 다시 출력이 연속값이냐 범주냐로 나뉜다: **회귀**(regression)는 숫자를
예측한다(집값, 기온), **분류**(classification)는 범주를 예측한다(스팸/정상,
개/고양이/새). 같은 선형 모델 \\(w^Tx + b\\)라도, 출력을 그대로 쓰면 회귀(Chapter
2), 시그모이드를 씌워 0~1 확률로 해석하면 분류(Chapter 3)가 된다 — 앞으로 몇 장
동안 이 패턴이 반복해서 나온다: **모델 구조는 비슷한데, 출력을 해석하는 방식과
손실함수(loss function)만 문제에 맞게 바뀐다.** 같은 알고리즘이 두 문제 모두에
쓰이는 경우가 많으므로, 이 둘을 구분하는 눈은 이번 학기 내내 필요하다.

## 1.4 손실함수라는 공통 언어

지금부터 배우는 거의 모든 알고리즘은 다음 틀을 따른다:

1. 모델이 얼마나 틀렸는지를 숫자 하나로 요약하는 **손실함수** \\(J(w)\\)를
   정의한다.
2. \\(J(w)\\)를 최소화하는 \\(w\\)를 찾는다 — 대개 경사하강법(Chapter 2)으로.

회귀의 손실함수(평균제곱오차)와 분류의 손실함수(교차 엔트로피)는 형태가 다르지만,
"모델의 틀린 정도를 수치화하고 그걸 줄인다"는 구조 자체는 동일하다.

## 1.5 Python/NumPy 준비

이번 학기 코딩 문제는 순수 Python(리스트 기반)과 `numpy`(벡터/행렬 연산) 둘 다
사용한다. `numpy`가 왜 필요한지는 다음 예시로 감을 잡을 수 있다:

```python
import numpy as np

X = np.array([[1.0, 2.0], [3.0, 4.0]])  # 2x2 행렬
w = np.array([0.5, -0.5])               # 길이 2 벡터
print(X @ w)   # 행렬-벡터 곱: [-0.5, -0.5]
```

`X @ w`(행렬곱)는 앞으로 매장 나오는 \\(w^Tx\\) 형태의 계산을 한 줄로 표현해준다 —
for 루프로 직접 짜는 것보다 빠르고 읽기 쉽다.

## 1.6 이번 학기 로드맵

Chapter 2~6은 신경망 없이도 강력한 classical ML 모델들(선형/로지스틱 회귀, kNN,
트리 기반 모델, GBDT)을 다룬다 — 지금도 정형(tabular) 데이터에서는 이 모델들이
신경망보다 자주 이긴다. Chapter 7부터는 신경망으로 넘어가 역전파의 원리를 손으로
유도하고, 실제로 그 원리 위에 CNN 같은 구조를 얹는다. 마지막 두 장은 비지도학습과
RL/생성형 모델을 살짝 맛본다 — 둘 다 ML2에서 본격적으로 다시 만난다.

**어떤 모델을 쓸지보다 먼저 물어야 할 질문은 항상 같다: 이 문제는 무엇을 데이터로
갖고 있고, 무엇을 맞히고 싶은가.**
