# Introduction

**Machine Learning 1**과 **Machine Learning 2**는 KSA의 3-1-3 심화 선택 과목으로,
CS1/CS2와 Math for ML(선형대수·확률통계 기초)을 선수과목으로 삼는다.

## 두 과목의 관계

**ML1**은 classical ML(선형/로지스틱 회귀, kNN, 트리 기반 모델, GBDT)부터 신경망·역전파의
기초까지 다룬다. 강화학습과 생성형 모델은 개념만 예고 수준으로 살짝 맛본다.

**ML2**는 ML1의 신경망 기초를 이어받아 시퀀스/어텐션 아키텍처(RNN → Transformer → LLM)로
심화하고, 강화학습을 MDP부터 제대로 시작해 Q-learning → DQN → Policy Gradient까지, 생성형
모델을 Autoencoder → VAE → GAN → Diffusion 순서로 세 가지 원리를 모두 훑는다. 마지막 두
주차는 팀 프로젝트로 마무리한다.

한 과목에 이 모든 내용을 몰아넣기엔 너무 방대해서, 딥러닝의 "기초"와 "응용"으로 자연스럽게
양분한 구조다.

## 이 자료의 구성

각 주차는 세 부분으로 이루어진다:

- **Opener** — 그 주에 배우는 개념이 실제로 왜 중요한지를 보여주는 짧은 도입.
- **Topics Covered** — 그 주의 핵심 개념과 수식, 예시 코드를 정리한 강의 노트.
- **Problem Set** — 코딩 문제(빈칸 채우기 스텁)와, 실습시간에 진행하는 **손유도 과제**
  (수식을 손으로 유도하거나 알고리즘의 정확성을 논증하는 문제).

## 손유도 과제 난이도 등급

실습시간에 진행하는 손유도 과제는 난이도에 따라 세 등급으로 나뉜다:

| 등급 | 의미 |
|---|---|
| **Tier A** (자유 유도) | 선수지식으로 충분히 감당 가능 — 그대로 진행 |
| **Tier B** (적정하나 주의) | 진행하되 힌트를 제공 |
| **Tier C** (폴백 필요) | 자유 유도 버전과 빈칸채움형 워크시트 버전을 모두 준비 — 학생 반응을 보고 선택 |

Tier C 문제는 두 버전이 함께 제시된다: 심화 버전(처음부터 끝까지 직접 유도)과 워크시트
버전(핵심 트릭 하나만 채워 넣으면 되도록 구조를 이미 제공하는 버전).

## 평가

In-class 20% + Assignment 20% + Final 50% + Attendance 10%. 기말고사는 CS1/2식
"빈칸채우기 코드완성"에 더해, 최소 2~3문항은 그래디언트 유도·손실함수 성질 증명·알고리즘
정확성 논증 같은 증명형 문항으로 구성된다.
