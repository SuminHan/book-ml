# Introduction

**Machine Learning 1**과 **Machine Learning 2**는 KSA의 3-1-3 심화 선택
과목으로, CS1/CS2와 Math for ML(선형대수·확률통계 기초)을 선수과목으로
삼는다. 이 교재는 국문판(한국어)과 영문판(English)이 같은 구조로 나란히
들어 있다 — 어느 쪽을 읽어도 같은 내용을 배운다.

## 두 과목의 관계

**ML1**은 classical ML(선형/로지스틱 회귀, kNN, 트리 기반 모델, GBDT)부터
신경망·역전파의 기초까지 다룬다. 강화학습과 생성형 모델은 개념만 예고
수준으로 살짝 맛본다.

**ML2**는 ML1의 신경망 기초를 이어받아 시퀀스/어텐션 아키텍처(RNN →
Transformer → LLM)로 심화하고, 강화학습을 MDP부터 제대로 시작해
Q-learning → DQN → Policy Gradient까지, 생성형 모델을 Autoencoder → VAE
→ GAN → Diffusion 순서로 세 가지 원리를 모두 훑는다. 마지막 두 장은 팀
프로젝트로 마무리한다.

## 이 교재의 구성

각 장은 하나의 페이지 안에 번호가 매겨진 절(예: 2.1, 2.2, ...)로 이루어진
진짜 교과서 형태를 따른다 — 절 번호는 그 장이 다루는 실제 주차 번호를
따르며, 사이드바에 표시되는 챕터 번호와는 무관하다(국문판/영문판이 한
책 안에 같이 있어서 사이드바 번호가 이어지기 때문).

각 장은 다음 흐름을 따른다:

- **도입부**: 그 장에서 배우는 개념이 왜 중요한지 보여주는 짧은 실제
  사례나 역사적 일화.
- **본문 절들**: 개념·수식·예시 코드를 순서대로 쌓아가는 설명.
- **연습문제**: 장 끝에 코딩 문제(빈칸 채우기 스텁)와 손유도 과제가
  실습시간 1학점 분량으로 정리돼 있다.

## 손유도 과제 난이도 등급

연습문제의 손유도 과제는 난이도에 따라 세 등급으로 나뉜다:

| 등급 | 의미 |
|---|---|
| **Tier A** (자유 유도) | 선수지식으로 충분히 감당 가능 — 그대로 진행 |
| **Tier B** (적정하나 주의) | 진행하되 힌트를 제공 |
| **Tier C** (폴백 필요) | 자유 유도 버전과 빈칸채움형 워크시트 버전을 모두 준비 — 학생 반응을 보고 선택 |

## 평가

In-class 20% + Assignment 20% + Final 50% + Attendance 10%. 기말고사는
CS1/2식 "빈칸채우기 코드완성"에 더해, 최소 2~3문항은 그래디언트 유도·
손실함수 성질 증명·알고리즘 정확성 논증 같은 증명형 문항으로 구성된다.
